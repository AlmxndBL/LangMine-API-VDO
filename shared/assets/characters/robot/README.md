## กติกาการใช้งาน
อ้างชื่อไฟล์จริงใน storyboard และ manifest รายตอน ตรวจภาพเต็มของ pose ที่จะใช้
วัดพื้นที่ตัวละครที่มองเห็นและแนวฐานเท้า ไม่ใช้ขนาด canvas เท่ากันเป็นหลักประกันว่าขนาดตัวละครเท่ากัน
รักษาสัดส่วน สีและรายละเอียด; หลีกเลี่ยงขยายภาพเล็กจนแตก ตรวจขอบ alpha บนพื้นจริงและที่มือถือ
motion ของภาพท่าคงที่เป็น translation/scale/pose cut ไม่อ้างว่าเป็น skeletal animation หรือ lip sync
ก่อนกลับด้านตรวจสัญลักษณ์ที่อกและอุปกรณ์ ไม่แก้ไฟล์ต้นฉบับ; derivative แยกชื่อและบันทึกเหตุผล
