## การวางในคลิป

คงสัดส่วน สี และข้อความ LANG MIND ตามต้นฉบับ ไม่ยืด บิด ครอปสัญลักษณ์/ตัวอักษร เปลี่ยนสี หรือให้ตัวละครบังโลโก้ เลือกขนาดที่ชื่ออ่านได้บนมือถือ ใช้พื้นสีอ่อนหรือแผ่นรองเมื่อจำเป็นให้ตัวอักษรดำเห็นชัด ตรวจ alpha/พื้นหลังจริงก่อนจัดวาง ไม่ถือว่าภาพ preview บอก transparency ได้ครบ

ทุกคลิปต้องมีโลโก้ เสนอวางในฉากแนะนำหรือปิดท้าย ไม่จำเป็นต้องเป็น watermark ทุกฉาก ตำแหน่งและเวลาแสดงสุดท้ายตรวจใน style frame ไม่ให้แย่งพื้นที่ demo

ถ้าเครื่องมือผลิตต้องคัดลอกเข้า video project ให้ใช้สำเนาจากไฟล์กลางนี้และบันทึกต้นทาง รุ่น และ hash ของไฟล์ที่ใช้กับตอนนั้น ไม่แก้สำเนาให้กลายเป็นโลโก้อีกรุ่น
