## สิทธิ์และขอบเขต
ผู้ใช้ให้ปรับโครง/บท/storyboard ขยายเวลา เพิ่มภาพและลูกเล่น และทำคลิปอีกรอบ ใช้ antislop AFTER ต่อจาก audit 001: คำสั่งล่าสุดอนุมัติให้แก้ประเด็นเสียง บท และ timing ทั้ง 4 ข้อ พร้อม ui-ux-pro-max ผู้ใช้เลือกทดลอง Edge TTS ภาษาไทยผู้หญิง ไม่ใช้ LangMind live API ไม่สร้าง provider resources ไม่ publish

## Blast radius
เพิ่ม video-v2 แยกจาก sample เดิม เก็บภาพ/เสียง/source/หลักฐานใหม่ เพิ่มบทและ storyboard v2 ปรับ README ตอนและสถานะกลางให้ชี้งานใหม่ บันทึก follow-up audit ไม่เขียนทับหลักฐาน v1 และไม่แก้ API snapshot

## ลำดับและเกณฑ์
ตรวจ source claims → บทพูดครบเหตุผล → screen/asset designs → ภาพจำเป็น → เสียงต่อเนื่องต่อย่อหน้า trim padding → timeline ตามเสียง → ตรวจเฟรม/seek/audio metrics → render draft
ไม่ล็อกเวลา 33s หรือ 80–100s แต่ละช่วงเพิ่มความเข้าใจและมีเหตุการณ์ภาพ เสียงใหม่ยังต้องผ่านการฟังโดยผู้ใช้ ไม่อ้างค่าความดังแทนการฟัง

## แกนเรื่อง
แอปต้องการผู้ช่วย → API คือช่องทางและกติกาการขอใช้บริการ → คำขอมีผู้ช่วย/คำถาม/สิทธิ์ → LangMind มี chat, knowledge, conversation, voice ตาม snapshot → เตรียมข้อมูลก่อน → ตามคำถามหนึ่งรอบ → ข้อมูลกลับไม่เท่ากับหน้าจอ → งาน developer และความล้มเหลว → สรุป

## Design Read
Explainer ภาษาไทยสำหรับคนไม่รู้ API, editorial paper / sage ink, ENERGY 2 / RHYTHM 3 / MOTION 2. กระดาษเชื่อมภาพเดิม สีเขียวเน้น active item; teal แยกขากลับ; Noto Sans Thai อ่านไทย; พื้นที่ว่างแยกเหตุการณ์ หนึ่งจุดสนใจต่อจังหวะ ไม่มี decorative loops
ui-ux-pro-max: เลือกใช้ progressive disclosure, hierarchy, motion meaning และ spatial continuity; ไม่ใช้ native app interaction checklist กับ MP4

## Assets ที่ออกแบบก่อนเจน
- ILLUSTRATION-KNOWLEDGE: ภาพประกอบ 3:2, พื้น ivory, เอกสารสามแผ่นไหลเข้าแฟ้มเขียวแล้วไปสู่หน้าต่างผู้ช่วยว่าง ไม่มีข้อความ/ตัวเลข/โลโก้/คน/robot. ใช้ภาพนี้อธิบายการเตรียมข้อมูล ไม่ใช่ official UI หรือผล API. กลางภาพเป็น folder, ขอบซ้ายและขวา crop-safe 8%; แยก diagram labels ภาษาไทยไว้ HTML นอกภาพ
- APP-FOLLOWUP: raster portrait 4:5, ใช้ APP-A v1 เป็น reference และคง header/service/question/answer เดิม เพิ่มคำถามต่อ “แล้วต้องจองเวลาก่อนไหม?” และคำตอบสมมติ “ติดต่อเจ้าหน้าที่เพื่อเลือกเวลาปรึกษา” ใต้ข้อความเดิม, ลดพื้นที่ว่างแทนลดฟอนต์; คงภาพจำลอง ใช้เฉพาะอธิบาย conversation continuity ไม่อ้างเป็น live result. ข้อมูลตั้งต้นสมมติเพิ่ม: การเลือกเวลาต้องติดต่อเจ้าหน้าที่. ต้องดูภาพจริงตรวจคำไทยก่อนใช้
- Reuse APP-Q/APP-A, logo และ robot จาก v1/shared; ไม่สร้างผู้เล่าใหม่
