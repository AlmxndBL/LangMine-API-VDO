# Project brief — LangMind API Video

## เป้าหมายระดับโปรเจกต์
สร้างซีรีส์คลิปภาษาไทยที่ช่วยให้ developer และผู้สนใจ AI เห็นว่าความสามารถ LangMind API นำไปใช้เป็นฟีเจอร์ได้อย่างไร แยกบทบาทบริการ API ออกจากแอปที่เราสร้าง และแยกภาพอธิบายออกจากผลทดสอบจริง
คลิปตอบคำถามที่คนดูอาจมีผ่าน use case อธิบายว่าต้องเตรียมอะไร เรียก API ตรงไหน และนำผลไปใช้อย่างไร โดยใช้ภาพจำลอง ไม่จำเป็นต้องพัฒนาระบบจริงขึ้นมาทุกคลิป
ทุกคลิปต้องมีเหตุผลในการดูที่ชัด ระบุผู้ชม ความต้องการ/จุดติดขัด พื้นฐานที่ต้องรู้ และสิ่งที่ดูจบแล้วนำไปทำต่อได้ เลือกคำถามหลักและตัดเรื่องที่ไม่ช่วยตอบออก

ชื่อผลิตภัณฑ์คือ LangMind (https://langmind.in.th) โฟลเดอร์ LangMine-API-VDO เป็นชื่อเดิม โปรเจกต์แยกจาก AlmondChat

## ข้อตกลงที่มี
- ใช้ HyperFrames ในการผลิต สำรวจ Catalog เป็นฐานความรู้กลาง แล้ววางโครงซีนคร่าว ๆ พร้อมแบ่งหน้าที่ภาพ/เสียง/ข้อความก่อนเลือก Catalog รายคลิปและทำ storyboard ละเอียด
- หน้าจอ demo เป็น generated raster ที่นำมาใช้จริง HTML ใช้จัดฉากและอธิบายได้
- หน้าจอทุกภาพต้องมีแบบรายภาพก่อนเจน รวมข้อความ สถานะ layout ขนาด crop/zoom และ continuity; ตรวจผลเจนจริงก่อนใช้
- ใช้ [robot 44 ท่า](../shared/assets/characters/robot/README.md) ที่ผู้ใช้ให้เป็นตัวละครกลางสำหรับงานใหม่ โลโก้ใช้ [ต้นฉบับกลาง](../shared/assets/brand/README.md)
- Robot เป็นตัวประกอบ เลือกท่าตามเรื่อง ไม่ใช้บุคลิก robot กำหนดคลิปหรือ art direction
- ใช้ Catalog เป็นฐานหลัก ปรับและเลือกตามคลิป ทำ custom เฉพาะช่องว่างจำเป็น ตรวจภาพนิ่งก่อน motion sample แล้วจึงขยายการผลิต
- Reference เป็นแนวหน้าจอเด่น กรอบและป้ายมีบุคลิกแบบวาดมือ ตัวละครช่วยพาสายตา ไม่คัดลอก assets ของผู้สร้าง
- ภาษาไทยเป็นหลัก เสียงผู้ชายไทยโทนคุยเป็นทิศทางที่เคยเลือก ยังไม่มีเสียงบันทึกของ EP01 รอบใหม่
- ปัจจุบันผู้ใช้ให้เริ่ม EP01 ใหม่เพื่อทดลอง workflow สถานะตอนอยู่ README ตอน

## ขอบเขตรอบจัดระบบ
รวมการวิเคราะห์เอกสาร ปรับกติกาและ workflow กำหนดวิธีสำรวจ Catalog ข้อกำหนด storyboard/prompt เกณฑ์ตรวจรับ และนำเข้า robot
รอบปัจจุบันเริ่มวางแผน EP01 ใหม่แล้ว แต่ยังไม่เจนภาพ ประกอบ timeline render เรียก live/paid API สร้าง resources หรือ publish

## สิ่งที่ยังเปิด
ความยาว จำนวนซีน ช่องทางเผยแพร่ palette/font ขั้นสุดท้าย ชุด Catalog ที่จะใช้ และเรื่องเล่ารายตอนยังต้องออกแบบตาม workflow ไม่ใช้ค่าจากรุ่นเดิมเป็นข้อบังคับซีรีส์
9:16, 1080×1920/30fps เป็นค่าตั้งต้นจากงานเดิม ปรับเมื่อมีข้อกำหนดช่องทาง
ยังไม่มี agent/dataset/live API evidence; demo จริงเป็นเส้นทางเพิ่มเติมเมื่อโจทย์และสิทธิ์พร้อม ไม่เป็น prerequisite ของคลิปอธิบายจำลองทุกคลิป
