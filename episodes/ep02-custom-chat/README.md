# EP02 — เว็บแชทของเราเองด้วย LangMind Agent

อัปเดต 7 พฤศจิกายน 2026 (Asia/Bangkok)

## สถานะ

คำสั่งใหม่: ทำภาพ B06–B12 ใหม่ตาม reference กระดาษ/กรอบดำ/ป้ายสี ใช้ฟอนต์ไทยมีหัว โลโก้และ robot กลาง พร้อม Dart Cursor จาก Catalog และซ่อนข้อมูลโปรไฟล์/ปักหมุดในภาพกับ footage เท่านั้น เริ่ม [รุ่น r2](video-sample-r2/REVIEW.md) แล้ว แต่ยังไม่เสร็จและยังไม่แทนที่โครงเดิมด้วย Catalog ครบ

**อัปเดตล่าสุด:** ผู้ใช้เลื่อนเสียงไปทำภายหลังใน LangMind Voice Studio และให้ทำภาพก่อน มี [ภาพร่างเงียบ B06–B12](video-sample-b06-b12/visual-draft-b06-b12.mp4) สำหรับตรวจลำดับเท่านั้น ยังไม่เสร็จ: motion ของ Catalog ยังไม่เชื่อมจริงและยังไม่มี footage สร้าง key ดู [ผลตรวจและรายการค้าง](evidence/sample-b06-b12/README.md#อัปเดตภาพร่างเงียบ) ก่อนทำต่อ

**สถานะล่าสุด 7 พฤศจิกายน 2026:** เริ่มเตรียม sample B06–B12 ตามขอบเขตสื่ออธิบาย ไม่สร้างแอปจริง ลบตัวอย่างแอปที่สร้างจากคำสั่งก่อนหน้าแล้ว ติดตั้ง Catalog source สำหรับทดลอง และสร้างเสียงตัวอย่างสองเสียงเพื่อให้เลือกก่อนทำเสียงเต็ม ช่วง sample ยังไม่ประกอบหรือ render ดู [หลักฐานรอบเตรียม sample](evidence/sample-b06-b12/README.md) สถานะในย่อหน้าประวัติด้านล่างเป็นข้อมูลก่อนรอบนี้

ผู้ใช้อนุมัติโครงเรื่องที่เสนอในแชต: เริ่มจากประสบการณ์ ChatGPT → แอปแชทของเรา → frontend/server/Agent → เตรียม Agent และ API → โค้ด → ถามต่อ → blocking/streaming → การต่อยอด พร้อมเพิ่ม Multi Device Splay และปิดด้วย Extruded Logo กับโลโก้จริง

จัดทำ [แบบผลิตฉบับออกแบบ r2](DESIGN.md) แล้ว: บทเต็ม 16 beats, storyboard, แบบหน้าจอ/footage, โค้ดบนภาพ, Catalog 9 รายการที่เลือกในแบบ และ 2 ตัวเลือกสำรอง/ยังไม่เลือก และแผน assets/เสียง ดู [แผนและประวัติขอบเขต](PLAN.md) ประกอบ ยังไม่อ้างว่าผู้ใช้ตรวจรับแบบใหม่หรือภาพสุดท้ายแล้ว และยังไม่มี timeline, sample เสียง, integration หรือ MP4 ของตอนนี้

ปรับ r2 สำหรับผู้ชม 24–48 ปีที่พื้นฐานยังไม่แน่น ใช้หลัก “เวลาเราทำสื่อ ทำคลิป ต้องคิดในมุมคนดู ว่าเหตุผลอะไรถึงดูคลิปนี้” เดินตามการส่งข้อความจริง เติม key → env → code เพิ่มภาพแยกตำแหน่งโค้ด ลด streaming และสรุปวงจรก่อนปิด ยังไม่สร้างแอปหรือประกอบ

## ขอบเขต

- ตัวอย่างหลัก: ผู้ช่วยร่างข้อความสำหรับผู้ขายออนไลน์ ตั้งคำถามแรกแล้วขอปรับคำตอบในแชทเดิม
- ใช้ Catalog แชทโดยตรงตามคำสั่งเฉพาะ EP02 แทนกติกา generated raster สำหรับ UI ส่วนที่ใช้ block; ไม่สร้าง UI ใหม่โดยไม่มีเหตุจำเป็น
- เพิ่มช่วงออกแบบหน้าตาเองด้วยมือถือ/แท็บเล็ต/เดสก์ท็อป และประโยคส่งท้ายก่อนฉากโลโก้
- ไม่แก้ EP01 และไม่คืนไฟล์ knowledge sample เดิมที่ถูกลบอยู่ก่อนงานรอบนี้
- ไม่เรียก live/paid API สร้าง provider resources หรือ publish จากการอนุมัติแนวเรื่อง
