# EP10 — บทสำหรับสร้างเสียง (Inbox API & LINE Channel)

เมื่อพร้อมสร้างเสียง ให้ใช้บทนี้สร้างไฟล์ wav/mp3 ใส่ใน `assets/voice/` แล้วรัน `node build.mjs`

## b1 → assets/voice/b1.wav
เมื่อเรานำ Agent ไปเชื่อมต่อกับลูกค้าทาง LINE คำถามที่ทีมหลังบ้านมักเจอคือ จะดึงรายการแชทมาดูในระบบของตัวเองได้ไหม รู้ได้อย่างไรว่าเคสไหนมีแอดมินคุยแทน AI อยู่ และจะดึงประวัติแชทออกมาเป็นไฟล์ Excel ได้อย่างไร ถ้าอยากทำทั้งหมดนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ภาพรวมของฟีเจอร์นี้เชื่อมระหว่างแชทจากช่องทางภายนอก เช่น LINE กล่องข้อความ Inbox ของ LangMind และระบบหลังบ้านของคุณ โดยระบบหลังบ้านจะเรียกอ่านข้อมูลสามจุดหลัก คือ ดึงรายการเธรดและจำนวนแชทแยกช่องทาง เช็กสถานะแอดมินรับสาย และสั่ง Export ประวัติเป็นไฟล์ครับ

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือ Agent ที่เปิดใช้งานช่องทาง LINE เรียบร้อยแล้ว อย่างที่สองคือ API Key ที่มีสิทธิ์ inbox read สำหรับอ่านข้อมูลกล่องข้อความ และถ้าต้องการส่งข้อความแชทในนาม LINE user ผ่าน API ด้วย ก็เพิ่มสิทธิ์ chat invoke อย่างที่สามคือระบบหลังบ้านสำหรับเก็บ Key ครับ

## b4 → assets/voice/b4.wav
มาดูการเชื่อมครั้งที่หนึ่ง การดึงรายการเธรดและจำนวนแยกช่องทาง เรียก GET ไปที่ agents ตามด้วย agent ID และ inbox threads โดยกรอง channel เป็น line ได้ ระบบจะคืนรายการเธรดพร้อมชื่อแสดงผลและรูปโปรไฟล์ที่ดึงสดจาก LINE รวมถึงคืนค่า channel counts ที่นับจำนวนเธรดรวมของทุกช่องทางมาให้ในครั้งเดียว นำไปทำป้ายบอกจำนวนแชทได้ทันทีโดยไม่ต้องยิงซ้ำครับ

## b5 → assets/voice/b5.wav
ครั้งที่สอง การเช็กสถานะแอดมินรับสาย หรือ human handover เรียก GET ไปที่ inbox threads ตามด้วยรหัสเธรดและ handover ถ้าค่า active เป็น true พร้อมเวลาที่เหลือ expires in sec แปลว่าตอนนี้มีแอดมินคุมสายอยู่ ตัว AI จะหยุดตอบอัตโนมัติจนกว่าจะหมดเวลาหรือแอดมินกดจบงานครับ

## b6 → assets/voice/b6.wav
ครั้งที่สาม การ Export ประวัติการสนทนา เรียก GET ไปที่ inbox export พร้อมระบุ format เป็น xlsx หรือ csv และเลือกกรองช่องทางหรือช่วงวันที่ได้ ระบบจะคืนไฟล์ไบนารีกลับมาให้ดาวน์โหลดตรงๆ สูงสุดสองหมื่นแถวต่อครั้งครับ

## b7 → assets/voice/b7.wav
ผลที่ได้ช่วยให้เราทำหน้ามอนิเตอร์หลังบ้านและสรุปรายงานประจำวันได้สะดวกมาก และถ้าต้องการดึงข้อความรายบรรทัดในเธรด ก็เรียกที่ messages ซึ่งมีโครงสร้างเดียวกับ Chat API ทุกประการ แต่ข้อควรจำสำคัญคือ API Key ใช้ได้เฉพาะส่วนอ่านเท่านั้น การส่งข้อความตอบกลับลูกค้า หรือการกดเริ่มและจบ handover ต้องล็อกอินทำผ่านหน้าเว็บ เพื่อความปลอดภัยครับ

## b8 → assets/voice/b8.wav
สรุปครับ เตรียม Agent ที่เปิดช่องทาง LINE และ API Key สิทธิ์ inbox read เชื่อมสามจุด คือดูรายการเธรดที่ threads เช็กแอดมินรับสายที่ handover และดึงไฟล์รายงานที่ export ช่วยให้ทีมดูแลลูกค้าติดตามงานได้ครบทุกช่องทางครับ

## b9 → assets/voice/b9.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้าง Agent เชื่อมต่อช่องทางแชทของคุณได้ที่ LangMind ดอท อิน ดอท ทีเอช
