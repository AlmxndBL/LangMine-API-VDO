2เชื่อมครั้งที่ 1 · รายการเธรด

LINE แชท Inbox 1 · ดึงเธรด หลังบ้าน
?channel=line&limit=25 · กรองเฉพาะ LINE
GETสิทธิ์ inbox:read
/api/agents/{agent_id}/inbox/threads?channel=line
Authorization: Bearer $LM_TOKEN
Query: channel=line, page=1, limit=25
ดึงชื่อ (display_name) และรูปโปรไฟล์สดจาก LINE อัตโนมัติ
{ "items": [{ "display_name": "คุณสมชาย", "channel": "line", "message_count": 6 }],
  "channel_counts": { "line": 1, "web": 0 }
}คืน channel_counts รวมทุกช่องทาง ทำ badge ได้ทันที

2เชื่อมครั้งที่ 2 · สถานะรับสาย

LINE แชท Inbox 2 · Handover หลังบ้าน
เธรดคุณสมชาย · conversation_id: c_9X1...
GETสิทธิ์ inbox:read
/api/agents/{agent_id}/inbox/threads/{cid}/handover
Authorization: Bearer $LM_TOKEN
cid: "c_9X17kL4..."
active: true = มีแอดมินคุมสายอยู่ (AI จะหยุดตอบอัตโนมัติ)
{ "active": true, "expires_in_sec": 1420 }
✓ แอดมินกำลังคุยแทน AI อยู่ (เหลือ 1,420 วินาที)

3ใช้ผลขอบเขตและความปลอดภัย

มอนิเตอร์แชทหลังบ้านแสดงรายการเธรด LINE พร้อมรูปโปรไฟล์และ badge จำนวนแยกช่องทาง
อ่านข้อความในเธรดเรียก GET .../inbox/threads/{cid}/messages (โครงสร้างเดียวกับ Chat API)
สิทธิ์ API Key ปลอดภัยสิทธิ์ inbox:read อ่านข้อมูลและ export ได้เท่านั้น
ข้อควรจำสำคัญ:

ภาพรวมเชื่อมระหว่างแชทภายนอก เช่น LINE
Inbox ของ LangMind และระบบหลังบ้าน
โดยระบบหลังบ้านจะเรียกอ่านข้อมูล 3 จุดหลัก
1. รายการเธรด → 2. สถานะ Handover
→ 3. สั่ง Export ประวัติเป็นไฟล์
สิ่งที่ต้องเตรียม อย่างแรกคือ Agent
ที่เปิดใช้งานช่องทาง LINE เรียบร้อยแล้ว
อย่างที่สอง API Key สิทธิ์ inbox:read
(และ chat:invoke เมื่อส่งแชทผ่าน API)
อย่างที่สาม ระบบหลังบ้านสำหรับเก็บ Key ปลอดภัย
ครั้งที่ 1 ดึงรายการเธรดและจำนวนแยกช่องทาง
GET .../inbox/threads?channel=line
คืนรายการเธรดพร้อมชื่อแสดงผล (display_name)
และรูปโปรไฟล์สดจาก LINE
และคืนค่า channel_counts รวมทุกช่องทาง
นำไปทำป้ายบอกจำนวนแชทได้ทันทีโดยไม่ต้องยิงซ้ำ
ครั้งที่ 2 เช็กสถานะแอดมินรับสาย (Handover)
GET .../inbox/threads/{cid}/handover
ถ้า active เป็น true พร้อมเวลา expires_in_sec
แปลว่าตอนนี้มีแอดมินคุมสายอยู่
ตัว AI จะหยุดตอบอัตโนมัติ
จนกว่าจะหมดเวลาหรือแอดมินกดจบงาน
ครั้งที่ 3 Export ประวัติการสนทนา
GET .../inbox/export?format=xlsx&channel=line
คืนไฟล์ไบนารีกลับมาให้ดาวน์โหลดตรงๆ
สูงสุด 20,000 แถวต่อครั้ง

และสรุปรายงานประจำวันได้สะดวก
ดึงข้อความในเธรดได้ที่ .../threads/{cid}/messages
(โครงสร้างเดียวกับ Chat API ทุกประการ)
