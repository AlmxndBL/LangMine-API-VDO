# EP01 — ถามนโยบายคืนสินค้า พร้อมตรวจที่มา

> ร่างเดิมที่พักไว้: ผู้ใช้เปลี่ยน EP01 เป็น [คลิปแนะนำ API](../ep01-api-introduction/README.md) แล้ว เนื้อหาด้านล่างเป็นบริบทเดิม ยังไม่ผลิตและยังไม่กำหนดเป็น EP02

Episode ID: `ep01-return-policy`

## Brief

แสดงแอปถามคำถามเกี่ยวกับนโยบายร้านสมมติ ส่งผ่าน server ไปยัง LangMind agent ที่ผูกฐานความรู้ แล้วแสดงคำตอบกับข้อมูลอ้างอิงเท่าที่ API คืนจริง ให้ผู้ชมแยกหน้าที่ API ออกจาก UI/server ที่เราสร้างได้

ผู้ใช้เลือกหัวข้อนโยบายคืนสินค้าและแนวหน้าจอ demo ร่วมกับตัวละครแล้ว ยังไม่มี agent/dataset/demo ที่พร้อมใช้ ความยาว 2–3 นาทีเป็นข้อเสนอ ไม่ใช่ค่าที่ล็อกแล้ว ไม่รวมตรวจ order อนุมัติคืนสินค้า หรือคืนเงินจริง

อ้างอิง [Project brief กลาง](../../docs/PROJECT_BRIEF.md), [Style guide](../../docs/VIDEO_STYLE_GUIDE.md), [Workflow](../../docs/WORKFLOW.md) และ [คู่มือ API](../../langmind-api.md) ไม่คัดลอกเอกสารเหล่านี้มาสร้างอีกชุด

อัปเดต 6 พฤศจิกายน 2026 (Asia/Bangkok) การจัดเอกสารไม่ใช่การอนุญาตให้เรียก API/เริ่มผลิต

| ขั้น | สถานะ | หลักฐานหรือสิ่งที่ขาด |
|---|---|---|

| P2 สิทธิ์และเครื่องมือ | ยังไม่เริ่ม | ยังไม่ยืนยันบัญชี RAG/model/credential, งบ และ HyperFrames setup |
