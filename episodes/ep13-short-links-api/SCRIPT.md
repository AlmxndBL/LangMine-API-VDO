## 2. ข้อมูลตัวอย่างสำหรับหน้าจอและ JSON

* **ค่าจากตัวอย่างในคู่มือ (documented example)**: `target_url` = `https://shop.example.com/sale`, `title` = “โปรเดือนนี้”, `utm` = `{ "source": "line", "campaign": "oct" }` → `code` = `k7m2p9x`, `short_url` = `https://s3t.me/s/k7m2p9x`, `target_url` ที่เติม UTM แล้ว, `state` = `active`, `total_clicks` = 0 (ในคลิปตัด `id` ออกเพื่อประหยัดที่)
* **ค่าจำลอง (illustrative)**: `alias` = `sale-oct`, `tags` = `["line","promo"]`, `max_clicks` = 5000, `password` = `••••`, `expires_at` = `"…"` (คู่มือไม่ระบุรูปแบบ), `q` = โปร, `limit` = 20, `offset` = 0, ช่วงวันที่ `2026-11-01` ถึง `2026-11-07`, ค่าแก้ title “โปรเดือนนี้ (ต่อเวลา)”
* **ข้อมูลในภาพหน้าจอ**: ร้านกาแฟสมมติ, ชื่อลิงก์อื่น, จำนวนคลิก (1,284 / 642 / 318 / 97), โควตา “ใช้ไป 12 จาก 50”, กราฟคลิกรายวัน — ข้อมูลจำลองทั้งหมด
* ภาพหน้าจอทั้งหมดติดป้าย “ภาพจำลอง” · ไม่ใช้โลโก้ LINE

## 4. ข้อกำหนดซับไตเติลและจังหวะเสียง

* ซับ 35 ท่อน (ท่อนละ 1–2 บรรทัด) ขึ้นตรงกับเสียงพูดทีละท่อน
* เมื่อมีเสียงจริง จุดตัดซับมาจาก `assets/voice/<beat>.segments.json` ถ้าไม่มีจะหาจากช่วงเงียบ
* เว้นจังหวะระหว่างท่อน 0.35 วินาที · ค้างฉากเพิ่ม (`hold`): b5 และ b7 1.5 วินาที, b6 1.0 วินาที (โค้ดหลายบรรทัด ให้อ่านทัน)
* ซับเขียนชื่อ API ตามจริง (`short_links:write`, `target_url`, `total_clicks`) แต่บทพูดอ่านเป็นภาษาพูด · ซับ b9 ย่อชื่อ error เหลือ `LIMIT_EXCEEDED` ฯลฯ เพื่อไม่ให้เกิน 2 บรรทัด ชื่อเต็มอยู่บนการ์ดในจอ
* เสียง: `th-TH-NiwatNeural` rate −16% (เหมือน EP04/EP12) สร้างด้วย `video/make-voice-samples.py` บนเครื่องผู้รับผิดชอบ
