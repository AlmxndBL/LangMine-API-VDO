# EP13 Short Links API — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` (สร้างเสียงทีละประโยคจาก timing.json) แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
ร้านส่งโปรโมชันให้ลูกค้าทาง LINE แต่ลิงก์ยาวเหยียด เต็มไปด้วยตัวแปร UTM แถมยังไม่รู้ว่า มีลูกค้ากดลิงก์ไปกี่คน ถ้าอยากย่อเป็นลิงก์สั้น และดูจำนวนคลิกจากระบบของร้านเอง ต้องเตรียมอะไร เชื่อมตรงไหน และใช้ผลยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ระบบหลังบ้านของร้าน ส่งลิงก์ยาวไปที่ Short Links API ของ LangMind แล้วได้ลิงก์สั้นกลับมา ร้านส่งลิงก์สั้นนี้ให้ลูกค้า พอลูกค้ากด ก็ไปถึงหน้าโปรของร้าน ระหว่างนั้นระบบนับคลิกไว้ ให้ร้านดึงสถิติกลับมาดูได้

## b3 → assets/voice/b3.wav
สิ่งที่ต้องเตรียม อย่างแรกคือ API Key ที่มีสิทธิ์ short links write ไว้สร้าง แก้ไข ปิดใช้งาน และลบลิงก์ และสิทธิ์ short links read ไว้ดูลิงก์ ดูโควตา และดูสถิติการคลิก อย่างที่สอง ระบบหลังบ้านของร้าน ไว้เก็บ Key และเป็นคนเรียก API อย่างที่สาม รู้แผนของบัญชี เพราะลิงก์ที่สร้างผ่าน API นับโควตาเดียวกับหน้าลิงก์ย่อในเว็บ

## b4 → assets/voice/b4.wav
มาดูการเชื่อม ครั้งที่หนึ่ง เช็กโควตาก่อน ด้วย short links usage จะได้รู้ว่าใช้ไปแล้วเท่าไร เทียบกับเพดานของแผน และแผนเปิดฟีเจอร์อะไรให้บ้าง

## b5 → assets/voice/b5.wav
ครั้งที่สอง สร้างลิงก์ ส่ง target url คือหน้าโปรของร้าน ใส่ชื่อลิงก์ และ UTM บอกว่ามาจาก LINE ได้ short url กลับมาพร้อมใช้ state เป็น active และ total clicks เริ่มที่ศูนย์ สังเกตว่า ระบบเติม UTM ต่อท้ายลิงก์ปลายทางให้แล้ว

## b6 → assets/voice/b6.wav
ตอนสร้าง ยังใส่ตัวเลือกเพิ่มได้ เช่น alias ตั้งชื่อลิงก์เอง และ tags ไว้จัดกลุ่มลิงก์ expires at กำหนดวันหมดอายุ max clicks จำกัดจำนวนคลิก และ password ตั้งรหัสผ่าน แต่ชื่อลิงก์ที่ตั้งเอง วันหมดอายุ จำกัดคลิก และรหัสผ่าน ใช้ได้ตามแผน เช็กได้จาก usage

## b7 → assets/voice/b7.wav
ครั้งที่สาม จัดการลิงก์ ดึงรายการ ค้นด้วย q กรองด้วย tag หรือ state และเรียงตามจำนวนคลิกได้ ใช้ limit กับ offset เพื่อแบ่งหน้า จะแก้ลิงก์ไหน ใช้ PATCH ส่งเฉพาะช่องที่จะแก้ ถ้าส่ง null คือล้างตัวเลือกนั้นออก และใช้ DELETE เพื่อลบลิงก์

## b8 → assets/voice/b8.wav
ครั้งที่สี่ ดูสถิติของลิงก์เดียว ระบุช่วงวันที่ด้วย from date และ to date แบบ ปี เดือน วัน หรือดูภาพรวมของทุกลิงก์ ในช่วงวันที่เดียวกัน และถ้าแผนมีสถิติแบบละเอียด ก็ export สถิติรายวันเป็นไฟล์ CSV ได้

## b9 → assets/voice/b9.wav
ถ้าเกินโควตา จะได้ short link limit exceeded รหัสสี่ร้อยยี่สิบสอง หรือ short link rate exceeded รหัสสี่ร้อยยี่สิบเก้า ถ้าลิงก์ปลายทาง ไม่ผ่านการตรวจความปลอดภัย จะได้ short link target blocked รหัสสี่ร้อยยี่สิบสอง พร้อมข้อความบอกเหตุผล

## b10 → assets/voice/b10.wav
เอาผลไปทำหน้าลิงก์โปรของร้าน แถบโควตามาจาก usage และรายการลิงก์ เรียงตามจำนวนคลิก แต่ละแถวมีลิงก์สั้น ปุ่มคัดลอก สถานะ และจำนวนคลิกรวม กดเข้าไปดูกราฟคลิกรายวัน และปุ่มดาวน์โหลด CSV

## b11 → assets/voice/b11.wav
สรุปครับ เตรียม API Key สิทธิ์ short links read และ write ระบบหลังบ้าน และรู้แผนของบัญชี เชื่อมสี่แบบ เช็กโควตา สร้างลิงก์ จัดการลิงก์ และดูสถิติ แล้วเอาไปทำหน้าลิงก์โปร ที่รู้ว่าโปรไหนมีคนกดมากที่สุด

## b12 → assets/voice/b12.wav
คลิปนี้สนับสนุนโดย LangMind สร้างลิงก์สั้นพร้อมสถิติคลิก ได้ที่ LangMind ดอท อิน ดอท ทีเอช
