2เชื่อมครั้งที่ 1 · เช็กโควตา

หลังบ้านร้าน 1 · เช็กโควตา ลิงก์ย่อ

GETสิทธิ์ short_links:read
/api/short-links/usage
Authorization: Bearer $LM_TOKEN
นับโควตาเดียวกับหน้า “ลิงก์ย่อ” ในเว็บ
ใช้ไปเท่าไร เทียบเพดานของแผน+ ฟีเจอร์ที่แผนเปิดให้คู่มือไม่ได้แสดงตัวอย่าง response ของ usage

2เชื่อมครั้งที่ 2 · สร้างลิงก์

หลังบ้านร้าน 2 · สร้างลิงก์ ลิงก์ย่อ

2เชื่อมตัวเลือกตอนสร้าง

หลังบ้านร้าน 2 · สร้างลิงก์ ลิงก์ย่อ
POSTสิทธิ์ short_links:write
/api/short-links
{ "target_url": "https://shop.example.com/sale",
  "alias": "sale-oct", // ตั้งชื่อลิงก์เองตามแผน
  "tags": ["line", "promo"], // จัดกลุ่ม
  "expires_at": "…", // วันหมดอายุตามแผน
  "max_clicks": 5000, // จำกัดคลิกตามแผน
  "password": "••••" } // รหัสผ่านตามแผน
alias? title? tags? utm? expires_at? max_clicks? password? — ไม่บังคับทั้งหมด
ป้าย “ตามแผน” = ใช้ได้ตามแผนของบัญชีเช็กก่อนจาก /short-links/usage
ค่าในตัวอย่างเป็นภาพจำลอง · คู่มือไม่ได้ระบุรูปแบบค่า expires_at

2เชื่อมครั้งที่ 3 · จัดการลิงก์

หลังบ้านร้าน 3 · จัดการลิงก์ ลิงก์ย่อ
GETสิทธิ์ short_links:read
/api/short-links
?q=โปร&tag=line&state=active
&sort=clicks // created | clicks
&limit=20&offset=0 // แบ่งหน้า
รายการลิงก์ · ค่าที่ใส่เป็นตัวอย่าง
PATCHสิทธิ์ short_links:write
/api/short-links/{id}
{ "title": "โปรเดือนนี้ (ต่อเวลา)" } // ส่งเฉพาะช่องที่แก้
{ "max_clicks": null } // null = ล้างตัวเลือก
DELETE /api/short-links/{id} // ลบลิงก์
GET /short-links/{id} อ่านทีละลิงก์ได้ด้วย

2เชื่อมครั้งที่ 4 · ดูสถิติ

หลังบ้านร้าน 4 · ดูสถิติ ลิงก์ย่อ
GETสิทธิ์ short_links:read
/api/short-links/{id}/analytics
?from_date=2026-11-01&to_date=2026-11-07
ลิงก์เดียว · วันที่แบบ YYYY-MM-DD
GETสิทธิ์ short_links:read
/api/short-links/analytics
?from_date=2026-11-01&to_date=2026-11-07
ภาพรวมทุกลิงก์
GETสิทธิ์ short_links:read
/api/short-links/{id}/analytics/export
CSV รายวันเฉพาะแผนที่มีสถิติแบบละเอียด

ข้อควรระวังerror ที่ต้องรับมือ

เกินโควตานับตามโควตาลิงก์ย่อในแผนของบัญชี
422SHORT_LINK_LIMIT_EXCEEDED429SHORT_LINK_RATE_EXCEEDED
ปลายทางไม่ผ่านการตรวจความปลอดภัยระบบตรวจลิงก์ปลายทาง (target_url)
422SHORT_LINK_TARGET_BLOCKED
มีข้อความบอกเหตุผลมาด้วย · เช็กที่ code ไม่ต้องอ่านข้อความ

3ใช้ผลหน้าลิงก์โปรของร้าน

/short-links/usageแถบโควตา + ฟีเจอร์ของแผน
?sort=clicksเรียงลิงก์ตามคลิก
short_urlลิงก์สั้น + ปุ่มคัดลอก
stateป้ายสถานะ
total_clicksจำนวนคลิกรวม
tagsตัวกรองแท็ก
/{id}/analyticsกราฟคลิกรายวัน
/{id}/analytics/exportปุ่ม ⬇ CSV รายวัน
