## 1. เกณฑ์การคัดเลือกตามหน้าที่ของซีน

EP13 มี 5 หน้าที่หลักที่ต้องใช้แอนิเมชันช่วยอธิบาย:
1. **แสดงหน้าจอแอปจำลอง (Device Hosting)** — ให้เห็นปัญหาลิงก์ยาวใน LINE และหน้าลิงก์โปรของร้าน
2. **แสดงเส้นทางข้อมูล (Data Flow)** — ระบบหลังบ้าน → API → ลิงก์สั้น → ลูกค้า → สถิติ
3. **แสดง request / response ทีละส่วน (Code & JSON)** — 10 endpoint, body ตอนสร้าง, ฟิลด์ใน response
4. **บอกข้อจำกัดตามแผน (Plan gating)** — ตัวเลือกไหนใช้ได้ตามแผน
5. **บอกตำแหน่งในเรื่อง (Wayfinding)** — อยู่การเชื่อมแบบไหนจาก 4 แบบ และอยู่ขั้นไหน

## 3. ข้อจำกัดทางเทคนิคที่ต้องรักษา

* **Seek-safe**: ใช้เฉพาะ GSAP tween/set ห้าม tween `className`
* Timeline ลงทะเบียนที่ `window.__timelines['ep13-short-links']`
* ป้าย “ภาพจำลอง” มุมขวาบนใช้ selector `#film > .note` — **ห้ามกลับไปใช้ `.note` เปล่า** เพราะชนกับ `.chip.note` (เคยทำให้ชิปใน b3 ซ้อนกัน; แก้ใน EP12 ด้วยแล้ว)
* ภาพมือถือใช้ `data-layout-allow-overflow` · ซับใช้ `data-layout-allow-caption-zone`
* ตัวอักษรขั้นต่ำ 28px (คอมเมนต์ในโค้ด ป้าย “ตามแผน” และป้าย DELETE ปรับขึ้นเป็น 28px แล้ว)

## 4. สิ่งที่ต้องทดสอบหลังมีเสียงจริง

* ป้าย “ตามแผน” ใน b6 ขึ้นตรงคำว่า “ใช้ได้ตามแผน” หรือไม่
* b7 บรรทัด `null` และ DELETE ตรงกับคำพูดหรือไม่ เมื่อเวลาสั้นลง
* callout b10 ทันอ่านหรือไม่ (อาจต้องเพิ่ม `hold`)
