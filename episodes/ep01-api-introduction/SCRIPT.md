# EP01 — บทร่าง v1

ผู้ชม: ผู้เริ่มต้นที่ยังไม่รู้จัก API ตาม W3 ที่ผู้ใช้อนุมัติ
เวลาเป้าหมายสำหรับทดลอง: ประมาณ 80–100 วินาที เป็นการประมาณจากข้อความ ยังไม่ได้อ่านออกเสียงจับเวลา ไม่ใช่ระยะเวลาที่ผู้ใช้กำหนด
ภาษาไทย เสียงโทนคุย อธิบายหนึ่งเรื่องต่อวลี ไม่เร่งศัพท์ท้ายประโยค

## ซับและเสียง
ซับถ่ายทอดบทเต็ม แบ่งตามวลี ไม่เกินสองบรรทัดต่อจังหวะ ไม่ขึ้นข้อความทั้งแถวพร้อมกัน เลือกจุดตัดจริงหลังมีเสียงร่าง
เว้นจังหวะก่อนเรียกชื่อ API และก่อนเปลี่ยนจากส่งคำถามเป็นรับผล ไม่ใส่เลขเวลาแฝงเพื่อให้ดูเหมือนผล live
เสียงประกอบเสนอเป็นเสียงกระดาษ/เส้นขีดเบาเฉพาะการเปิดเส้นทาง หากไม่มี asset สิทธิ์ชัดให้เว้นใน sample ห้ามเรียกบริการเสียงแบบเสียเงินโดยอัตโนมัติ

## ข้อมูลตัวอย่างสำหรับคำตอบในภาพ (illustrative)
บริการสมมติ: บริการปรึกษาออนไลน์ ไม่มีความเกี่ยวข้องกับนโยบายหรือ UI ของ LangMind
ข้อมูลตั้งต้นที่ผู้เขียนกำหนด: ผู้เริ่มใช้เตรียมอีเมลสำหรับติดต่อและหัวข้อที่อยากปรึกษา
คำถามบนภาพ: “เริ่มใช้บริการต้องเตรียมอะไร?”
คำตอบบนภาพ: “เตรียมอีเมลและหัวข้อที่อยากปรึกษา”
นี่คือข้อความสำหรับอธิบาย flow ไม่ใช่ผลจาก API ไม่อ้างว่าตั้งค่า agent หรือ knowledge สำเร็จแล้ว ไม่ใส่ citation คะแนน ความเร็ว หรือราคา

## ตรวจบทก่อน sample
อ่านทวนเชิงข้อความแล้ว: แต่ละคำศัพท์มีบริบทก่อนใช้ ใช้คำถามเดียวต่อเนื่อง แยกหน้าที่แอปกับ API และไม่เพิ่มขั้นฐานความรู้โดยไม่มีหลักฐาน
ยังไม่ได้ลองอ่านออกเสียงจับเวลาและไม่ได้ทดสอบผู้ชมจริง ต้องใช้เสียงร่างใน W5 เพื่อตัดคำซ้ำ/ปรับเวลาที่ภาพต้องนิ่งก่อนล็อก timing
