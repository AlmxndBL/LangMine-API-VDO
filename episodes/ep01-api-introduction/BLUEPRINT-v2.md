# EP01 blueprint v2: แอปถามตอบและ API เบื้องหลัง

เอกสารรอบก่อน เก็บเป็นประวัติ ทิศทางปัจจุบันใช้ [BLUEPRINT-v3](BLUEPRINT-v3.md) และ [ผลตรวจ](video/v3-preview/REVIEW.md)

สถานะ: มี HyperFrames preview 20 วินาทีแล้ว แต่รอบตรวจพบ layout และ contrast errors ยังไม่ผ่านคุณภาพ ผู้ใช้แก้ทิศทางให้เจนภาพ demo แล้วนำภาพมาใช้แทนการสร้างหน้าจอด้วย HTML

## ข้อแก้ไขที่มีผลเหนือรายละเอียดเดิม
- สร้างหน้าจอ demo เป็นภาพ raster ด้วย image generation ตรวจภาษาไทยก่อนนำเข้า assets
- HTML ใช้เป็น host สำหรับภาพ การครอป การเคลื่อนกล้อง และ Catalog เท่านั้น ห้ามสร้างเนื้อหา UI demo ขึ้นใหม่เป็น DOM
- ตรวจภาพต้นทาง ภาพเมื่อย่อบนมือถือ และช่วงเปลี่ยนภาพ แยกจากการตรวจ runtime
- ผลเดิม: runtime errors 0, layout errors 14, contrast errors 6, lint warnings 4 ยังไม่ถือว่าผ่าน Delivery Gate

ติดตั้ง browser-device-stage จาก Catalog แล้ว หลังจากคำสั่งแรกใน sandbox พบ ENOTFOUND และเรียกใหม่โดยได้รับสิทธิ์เครือข่ายสำเร็จ ส่วน chat-message มีไฟล์อยู่แล้ว ทั้งสองยังไม่ได้ประกอบเข้าฉาก v2 จึงยังไม่ถือว่าใช้งานจริง

## เป้าหมายและทิศทาง
ผู้ชมเห็นคำถามเดินทางจากแอปผ่าน API และคำตอบกลับมา พร้อมเข้าใจว่า LangMind มี API ให้ต่อยอด ตัวอย่างร้านและนโยบายเป็นเรื่องสมมติทั้งหมด ใช้โลโก้ที่ผู้ใช้ให้ สีเดิม และภาษาไทย ภาพแนวสมุดอธิบายพร้อมผู้ช่วย ENERGY 2 / RHYTHM 3 / MOTION 2

## Catalog ที่เลือกก่อนผลิต
| จังหวะ | รายการ | หน้าที่ | สถานะ |
|---|---|---|---|
| หน้าจอ demo | browser-device-stage | กรอบหน้าจอที่ใส่ HTML ของเรา | เลือกจากคำอธิบาย ยังต้องดู preview และทดลอง mount |
| บทสนทนา | message-thread-reveal หรือ chat-message | แสดงข้อความส่งและรับ | chat-message มีใน video/compositions/components แล้ว ต้องทดสอบใช้งานจริง |
| รอผล | typing-indicator | บอกว่ารอคำตอบ | เลือกเบื้องต้น ต้องดู preview |
| คลิกส่ง | agent-cursor | สาธิตการกด | ปรับป้ายไม่ให้สื่อว่า LangMind ควบคุม UI |
| จุดสำคัญ | inline-highlight | เน้นคำหรือข้อมูล | ใช้เฉพาะจุดที่กำลังพูด |

## ลำดับภาพ
1. เปิดด้วยแอปร้านค้า ลูกค้าถามเรื่องคืนสินค้า ตัวละครชวนสงสัย (0–5s)
2. กดส่ง แสดงการรอ แล้วผลจำลองปรากฏ (5–10s)
3. ขยายคำถามให้เดินทางจากแอป ไป server ผ่าน LangMind API และกลับเป็นคำตอบ (10–17s)
4. กลับมาเห็นคำตอบและประโยชน์ผู้ใช้ (17–20s)
5. คลิปเต็มต่อด้วย API คืออะไร ตัวอย่าง knowledge และ voice ตามเอกสาร แล้วมุม developer และสรุป

## Prompt สำหรับผลิต
สร้างคลิปแนวตั้งภาษาไทยใน HyperFrames ให้ดูเหมือนผู้ช่วยพาชม demo แอปร้านค้าจำลอง ใช้ลำดับการกระทำจริง พิมพ์ กดส่ง รอ เห็นผล แล้วเปิดภาพเบื้องหลังแสดง app → server → LangMind API → response ให้หน้าจอเป็นจุดเด่น สลับภาพใกล้และภาพรวม ให้ตัวละครตั้งคำถามหรือชี้เฉพาะเมื่อช่วยอธิบาย เปลี่ยน composition ตามเนื้อหา ใช้สีเดิมและโลโก้จริง เลือกและทดลอง Catalog ตามตารางก่อนสร้าง motion ระบุภาพและคำตอบสมมติให้ชัด อย่าสร้างสถิติ citations หรืออ้างผล API จริง ใช้เสียงผู้ชายไทยโทนคุยเข้าใจง่ายเมื่อมีเสียงที่ได้รับสิทธิ์ ตรวจภาษาไทย ความอ่านง่ายบนมือถือ ความเปรียบต่าง ระยะเวลาถือภาพ ซับ และภาพ render จริง

## เกณฑ์ตรวจ
- ผู้ชมเห็น input, การส่ง, ผล และประโยชน์ได้ แม้ปิดเสียง
- ภาพหลักแต่ละช่วงมีจุดสนใจเดียว ตัวละครไม่บังข้อความ
- ทดสอบ contrast ด้วยเครื่องมือ และดูภาพบนมือถือจริงก่อนยืนยัน
- UI ที่โต้ตอบได้ต้องมี keyboard, focus และสถานะว่าง กำลังโหลด ผิดพลาด ส่วน MP4 ตรวจความอ่านง่ายตามสื่อ
- ห้ามอ้างว่าใช้ Catalog จริงจากการเลือกชื่ออย่างเดียว บันทึกชิ้นส่วนที่ mount และผลตรวจ
- เสียงจริงและข้อมูล API จริงยังต้องเตรียมแยก ตรวจสิทธิ์และค่าใช้จ่ายก่อนใช้
