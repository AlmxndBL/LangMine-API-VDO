## Catalog plan
ใช้ browser-device-stage ที่ติดตั้งแล้วเป็นต้นแบบกรอบแสดงภาพจริง ปรับ source ของ episode ให้ใส่ img ที่เขียนไว้ใน template โดยตรง ไม่ใช้ skeleton; คง settle entrance แล้ว hold เพื่ออ่าน ปรับกรอบให้รับภาพ portrait โดยไม่ crop ข้อความ ติด provenance ว่าดัดแปลงจาก Catalog ใต้โฟลเดอร์ compositions/components

เลือก inline-highlight เป็น motion สำหรับเน้นข้อความ/เส้นทาง ถ้าติดตั้งสำเร็จใช้ source จริงและบันทึกการปรับ ถ้าติดตั้งไม่ได้รายงาน ไม่อ้างว่าใช้จริง ไม่ใช้ chat-message สร้าง bubble HTML เพราะผู้ใช้กำหนดให้หน้าจอเป็นภาพ

Composition variation: 01 screen-led, 02 diagram-led, 03 brand-to-app, 04 close-up demo, 05 full screen/source close-up, 06 screen + four-step emphasis, 07 code + server boundary, 08 screen montage. ตัวละครไม่จำเป็นต้องปรากฏทุกฉากและไม่บัง demo

## Production prompt
ผลิตตามตาราง shot และ inventory นี้เท่านั้น เจนและตรวจภาพทุกไฟล์ก่อนเริ่มเขียน composition ใช้ภาพ screenshot เป็นสินทรัพย์จริง ห้ามสร้างหน้าจอใน HTML กล้องและ motion ต้องชี้เหตุและผล ไม่ขยับเพื่อเติมเวลา ไม่แสดงหัวข้อ ซับ และคำพูดตัวละครที่ซ้ำกันหลายชั้น ซับเป็นข้อความช่วยเข้าใจช่วง visual preview บทพากย์เก็บครบแต่ไม่อ้างว่ามีเสียงแล้ว ใช้ raster ที่ได้รับอนุมัติให้สร้างได้ตามคำสั่งล่าสุด สร้างตัวละครต้นฉบับ ไม่ดัดแปลงโลโก้ LangMind

## Verification gate
1. Asset gate: ไฟล์ภาพครบ เปิดตรวจทุกภาพ ภาษาไทยหลักสะกดถูก และมี provenance ก่อนประกอบ
2. Technical: lint/runtime/layout/contrast errors 0; ตรวจ transition boundaries และเฟรมตัวอย่างทุกฉาก
3. Human: captions อ่านได้ที่ 360px, สถานะไม่ได้สื่อด้วยสีล้วน, ไม่มี flash/กล้องรุนแรง; ข้อความ raster ตรวจด้วยตาและ sampling สี ไม่ใช้ DOM check อ้างว่าภาพผ่าน WCAG ทั้งหมด
4. Preview: Play/Pause/seek/replay ใน browser จริง ไม่มี frame ว่างหรือ API calls; ไม่ถือการดู screenshot แทนการทดสอบ playback
5. Sound: visual-only ตาม scope นี้ ไม่มีเสียง ยังต้องอัดเสียงจริงและปรับเวลาอีกครั้งก่อนผลิตคลิปพร้อมเผยแพร่
6. ไม่ export MP4 ตามคำสั่งผู้ใช้ เก็บ snapshot สำหรับ QA ได้
