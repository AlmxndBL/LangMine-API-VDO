## แบบภาพและ continuity
APP-Q/APP-A ใช้ raster v1 ที่มีอยู่ ไม่เปลี่ยนข้อความ; APP-FOLLOWUP ออกแบบในแผนก่อนเจน ใช้ APP-A เป็น reference คง header/service/palette เปลี่ยนการจัดพื้นที่เพื่อมี 4 ข้อความตาม SCRIPT-v2 ไม่มี user avatar หรือเลขเวลา. เจนแล้วตรวจภาพจริง คำถามทั้งสอง คำตอบทั้งสอง และภาพจำลองถูกต้อง หัวข้อ/ขนาดจอยังสัมพันธ์กับภาพเดิม แต่ไม่รับรอง pixel identity

knowledge-v2: conceptual illustration 1536×1024 เอกสาร/แฟ้ม/หน้าต่างว่าง ไม่มีข้อความ/คน/โลโก้; ไม่รับรองสถานะ API จากภาพ ไม่เพิ่ม UI ข้างใน blank window ให้ดูเป็น product screenshot

## Catalog และขอบเขตปรับ
ใช้ source ของ hw-pipeline เป็นฐานกรอบ/เส้นวาด และ browser-device-stage เป็นกรอบ host raster. ค้น candidate marker-highlight/zoom-through-transition แล้ว แต่ไม่ได้ตรวจ preview ครบจึงไม่อ้างว่า integrate ทั้งสองรายการ; marker และ camera framing ที่จำเป็นเป็นการปรับ composition ฐานเดิม ไม่ใช้ cinematic zoom shader ที่ทำให้อ่านยาก. ต้องตรวจ playback/seek ของ v2 ใหม่

## เสียงและการอ่าน
สร้างเสียงต่อย่อหน้าทั้ง scene ใช้ word-boundary timestamps ทำซับ ไม่เอาบรรทัดซับไปกำหนดวลีเสียง; trim เฉพาะ padding เติมพักท้ายฉาก 0.55s (ท้ายคลิป 1s) เป็นค่าเริ่มทดลอง ไม่ตัดความเงียบกลางคำอธิบายอัตโนมัติ. ภาพเน้นเหตุการณ์ 1–2 ชิ้นต่อเวลา ไม่ทำ loop แก้ dead_stretch

ไม่มีเพลง/SFX จากแหล่งที่มีสิทธิ์และพร้อมใช้รอบนี้ จึงเน้นเสียงบรรยาย ไม่สังเคราะห์ดนตรีในโค้ดเพื่อกลบคุณภาพเสียง
