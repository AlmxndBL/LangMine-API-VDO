# EP01 บท v2

บทพากย์ฉบับปรับอยู่ใน `narration` ของ [story.json](video-v2/story.json) อ่านต่อเนื่องทีละย่อหน้า ข้อความเน้นอยู่ใน `title` และ `emphasis` ส่วน `captionText` เป็นข้อความอ่านของ animatic ฉบับตรวจภาพ หลังเลือกเสียงให้ทำซับตามคำพากย์จริงและผูกเวลากับเสียง

## เส้นเรื่อง
1. ผู้ใช้ถามว่าต้องเตรียมอะไร แอปขอให้ผู้ช่วยตอบ
2. API ให้สองระบบรู้ว่าจะติดต่อที่ไหน ส่งอะไร และอ่านผลอย่างไร
3. ระบบแอปประกอบคำถาม ข้อมูลผู้ช่วย และกุญแจยืนยันสิทธิ์
4. ตามคำขอจากหน้าจอ ผ่านระบบแอป ไปยัง LangMind
5. ข้อความคำตอบและรหัสบทสนทนากลับมาที่ระบบแอป ก่อนแสดงข้อความในหน้าจอ
6. ใช้รูปแบบเดียวกันกับคู่มือบริการหรือเอกสารทีม
7. นำข้อมูลเข้า รอประมวลผล และเชื่อมกับผู้ช่วย
8. ใช้รหัสที่รับมากับคำถามต่อ และตรวจว่าเป็นของผู้ใช้คนนี้
9. แอปประกอบการถอดเสียง การสนทนา และการอ่านออกเสียง
10. แอปดูแลสถานะรอและเรียกไม่สำเร็จ ส่วนคนพัฒนาทดสอบคำตอบกับคู่มือ
11. สรุปเส้นแบ่งงานของ LangMind, API และแอป

## ข้อมูลสมมติ
บริการปรึกษาออนไลน์ให้เตรียมอีเมลและหัวข้อปรึกษา การเลือกเวลาปรึกษาต้องติดต่อเจ้าหน้าที่ คำตอบบน APP-A และ APP-FOLLOWUP สร้างจากข้อมูลนี้ ไม่ใช่ผล AI จริง

## เสียง
### ย่อหน้าเดียวสำหรับเทียบเสียง

> ผู้ใช้ถามว่า เริ่มใช้บริการต้องเตรียมอะไรคะ แอปส่งคำถามไปหาแลงมายด์ผ่านเอพีไอ เพราะเราอยากให้ผู้ช่วยตอบจากคู่มือที่เตรียมไว้ พอได้ข้อความกลับมา แอปก็แสดงคำตอบในหน้าจอเดิมค่ะ

ให้ฟังการออกเสียง LangMind และ API จังหวะตั้งคำถาม น้ำหนักคำว่า “เพราะ” และจุดพักก่อนคำตอบ ใช้ย่อหน้าเดียวกันทุกตัวเลือก เมื่อเลือกเสียงแล้วจึงอัดบทเต็ม ตรวจ padding ที่หัวท้ายโดยฟังควบคู่กับการวัด และวางซับกับ motion ตามเสียงจริง

ยังไม่มี user comprehension test หรือการยอมรับคุณภาพเสียง v2
