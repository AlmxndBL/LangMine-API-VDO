# EP01 บท v2

คำสั่งล่าสุดให้ขยายคำอธิบายและผลิตใหม่ ไม่ล็อกเวลาคลิป บทจริงสำหรับเสียงอยู่ [story.json](video-v2/story.json) แบ่ง 14 ช่วง อ่านต่อเนื่องเป็นย่อหน้าต่อช่วง ไม่แยก TTS ตามบรรทัดซับ

## เส้นเรื่อง
1. คำตอบที่เห็นในแอปอาจมาจากบริการอื่น
2. ทำไมแอปถึงขอใช้ความสามารถภายนอก
3. API เป็นช่องทางพร้อมกติกา ใช้ได้กับบริการหลายชนิด
4. คำขอระบุผู้ช่วย คำถาม และสิทธิ์ โดยไม่สอน JSON
5. LangMind ให้บริการผู้ช่วยที่ตั้งค่าไว้
6. ฐานความรู้: นำเข้า ประมวลผลพร้อมใช้ และผูกกับผู้ช่วย
7. บทสนทนา: ใช้รหัสเดิมคุยต่อ และแยกผู้ใช้
8. เสียง: ถอดเสียง/อ่านออกเสียง ต้องเตรียม feature และสิทธิ์
9. ตั้งต้นข้อมูลบริการสมมติ
10. ส่งคำถามจากหน้าจอผ่านระบบแอป
11. รับข้อมูลกลับก่อนแอปแสดงคำตอบ
12. ข้อมูลกับรูปแบบแสดงผลเป็นคนละส่วน
13. developer ดูแลสิทธิ์ สถานะ ความล้มเหลว และทดสอบคำตอบ
14. สรุปและให้จุดเริ่มจากงานที่อยากให้ AI ช่วย

## Claim ledger
แหล่งคือ langmind-api.md ส่วนต้นฉบับครบทุกหมวด เป็น documented snapshot ไม่ใช่ live verification

| ประเด็น | ส่วนต้นฉบับที่รองรับ | ขอบเขต |
|---|---|---|
| คุยกับผู้ช่วย/รับ answer | Chat API, /chat/message/blocking | ไม่เรียกจริง ไม่รับรองความถูกต้องคำตอบ |
| ระบุผู้ช่วยและ query/สิทธิ์ | Chat request, Authentication/Scopes | ภาพใช้ภาษาธรรมดา ไม่แสดง key |
| นำเข้าเอกสาร/URL/ข้อความ | Knowledge API /datasets และ /documents | ต้อง indexed และผูก dataset กับ agent ก่อนใช้งาน ไม่อ้าง upload เท่ากับ ready |
| บทสนทนาและประวัติ | /chat/conversations, /messages, conversation_id | developer ต้องแยก ownership; ไม่ใส่ user_id โดยสมมติ |
| STT/TTS | /v1/agents/{id}/voice/transcribe และ /speech | ต้องเปิดใน published agent และมี voice:invoke; ไม่ใช้ API นี้ทำเสียงคลิป |
| app UI, นโยบายตัวอย่าง, คำตอบ | illustrative ที่ผู้เขียนกำหนด | ไม่ใช่ official UI/ผล API |

## ข้อมูลสมมติ
บริการปรึกษาออนไลน์ให้เตรียมอีเมลและหัวข้อปรึกษา การเลือกเวลาปรึกษาต้องติดต่อเจ้าหน้าที่ คำตอบบน APP-A และ APP-FOLLOWUP สร้างจากข้อมูลนี้ ไม่ใช่ผล AI จริง

## เสียง
ผู้ใช้เลือกทดลอง Edge TTS ภาษาไทยผู้หญิง และอนุญาตส่งบทไป Microsoft Edge TTS โดยเฉพาะ ใช้ PremwadeeNeural rate +0%, เขียนคำอ่าน แลงมายด์/เอ พี ไอ ในเสียง แต่ใช้ LangMind/API ในข้อความเน้น เก็บ timestamps จาก provider trim padding เฉพาะหัวท้าย normalize หลังรวม ไม่ถือว่าชื่อเสียงใหม่รับรองคุณภาพ ต้องให้ผู้ใช้ฟัง draft

ยังไม่มี user comprehension test หรือการยอมรับคุณภาพเสียง v2
