# EP01 v2 draft พร้อมเสียง

ใช้เสียงจาก LangMind Voice Studio เสียง Kore 11 ช่วง ช่วงแรกเป็น audition แบบที่ 2 ที่ผู้ใช้เลือก ช่วง 02–11 ใช้บทที่เสนอในแชต ต้นฉบับ WAV อยู่ใน assets โดยคงความเร็วเดิม แต่ละฉากยาวเท่าเสียงจริงบวกเวลาต่อท้ายประมาณ 0.35 วินาที

ข้อความบนจอเป็นข้อความสรุปจาก animatic r2 กำหนดเวลาภายในฉากตามสัดส่วนความยาวข้อความ ยังไม่ใช่การจับเวลาแบบคำต่อคำและอาจไม่ตรงกับเสียง ต้นฉบับ `story.json` สืบทอดบท r2 ก่อนย่อเป็นบทที่ส่ง Voice Studio ส่วนเสียงจริงยึดตาม WAV ไม่ใช้ข้อความนี้รับรอง transcript

รอบนี้ยังไม่ได้ฟังการออกเสียง จังหวะ จุดพัก หรือคุณภาพเสียงตลอดทั้งคลิป และยังไม่มีการทดสอบความเข้าใจกับผู้ชม

## ผลตรวจ

- `hyperframes check --at 5,25,45,65,85,105,125,145,165 --max-transition-samples 0 --json` และ `hyperframes render --quality draft --workers 4` ผ่าน exit 0, render 5,169 เฟรม
- Browser review ตรวจฟอนต์ รูป และข้อความสรุปครบ 11 ฉาก ไม่พบ overflow, page error หรือ external request และ seek timeline ไป/ย้อนตรงกัน
- `ffprobe` และ FFmpeg decode ทั้งไฟล์ผ่าน MP4 ยาว 172.3 วินาที H.264 1080×1920 30 fps และ AAC 48 kHz stereo ดู contact sheet ที่ถอดจาก MP4 จริง
- FFmpeg เปรียบเทียบ seek ไป/ย้อน 12 จุดกับ sequential decode ผ่านเมื่อเลือกเฉพาะ video stream การตรวจครั้งแรกใช้สคริปต์จากไฟล์ไม่มีเสียงและอ่าน audio hashes ปนด้วยจึงไม่ผ่าน จากนั้นแก้การเลือก stream แล้วตรวจใหม่
- `volumedetect` บน WAV รวมวัด mean -15.8 dBFS, sample peak 0.0 dBFS ค่า peak ถึงเพดานจึงต้องฟังตรวจการแตกพร่า การวัดไม่รับรองคุณภาพเสียง
- SHA-256 ของ MP4 คือ `5534845CF01D1B63A381B0EFA2CD571F526D5539522DDEA5DC1D4498312AF976`
