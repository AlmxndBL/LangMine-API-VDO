# ทางเลือกเรื่อง

## A. คำถามหนึ่งข้อเดินทางจากแอปไปหาคำตอบ (เลือกทำเป็น prototype)

เริ่มด้วยผู้ใช้พิมพ์คำถามในเว็บ ตัวละครพาเปิดเบื้องหลังให้เห็นการส่งคำขอและรับผล แล้วใช้หน้าจอจำลองชนิดต่าง ๆ แสดงสิ่งที่ต่อยอดได้ เหมาะกับผู้ชมใหม่เพราะอธิบายจากสิ่งที่เคยใช้ก่อนศัพท์เทคนิค

สองวินาทีแรก: ข้อความใหญ่ “แอปของเรา คุยกับ AI ได้ยังไง?” และบับเบิลคำถามที่กำลังส่ง

เรื่อง: คำถาม → API คือข้อตกลงการสื่อสาร → request/response → LangMind → ความสามารถ → ต่อใช้อย่างไร → ผลที่ผู้ใช้ได้

ภาพ: กระดาษอุ่น กรอบหมึกเข้ม สีน้ำเงินอมเขียวกับเขียวจากโลโก้ ใช้เหลืองเน้นคำสำคัญ ตัวละครต้นฉบับพาชี้วัตถุ

เสียง: วางบทผู้ชายไทยแบบคุยเข้าใจง่าย; prototype รอบแรกเป็น visual animatic ยังไม่มีเสียงพากย์/เพลง

## B. นักพัฒนาเปิดกล่องเครื่องมือ

โลกเป็นโต๊ะทำงาน developer กล่อง LangMind เปิดเป็นช่อง API แต่ละแบบ ไล่ตัวอย่าง input/output เหมาะกับผู้มีพื้นฐาน แต่ผู้ชมใหม่ต้องรับคำศัพท์หลายคำเร็วกว่า A

สองวินาทีแรก: หน้าจอแอปว่างและคำถาม “จะเพิ่มฟีเจอร์ AI เริ่มตรงไหน?” ภาพตัดเข้าเครื่องมือหนึ่งชิ้นต่อการใช้งาน

## C. ข้อความเดียว หลายช่องทาง

โลกเป็นศูนย์รับส่งข้อมูล คำถามเดียวเปลี่ยนเป็นข้อความ เสียง และผลค้นความรู้ ตัวละครถือซอง request ผ่านแต่ละสถานี เหมาะกับการสื่อความเชื่อมโยง แต่เสี่ยงให้เข้าใจผิดว่าทุกอย่างทำด้วย endpoint เดียว

เลือก A เพื่อเริ่มจากโจทย์ที่ทุกคนเข้าใจ ตัวเลือก B/C ยังไม่ผลิต ไม่ใช้ Pro style templates หรือสื่อจาก creator คนอื่น
