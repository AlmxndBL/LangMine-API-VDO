## แบบหน้าจอ sample ก่อนเจน
ต้นทางสองภาพขนาด 1440×1800 (4:5) แสดงในเฟรมแนวตั้งผ่าน host ไม่รวมกรอบ browser ซ้อนอีกชั้นใน raster
UI เป็นหน้าจอแอปสมมติของผู้พัฒนา ไม่ใช่หน้า LangMind รูปแบบเดียวกันทั้งสองสถานะ ไม่มี navigation ที่ไม่ช่วยเรื่อง

### APP-Q v1 — ส่งคำถามแล้ว ยังไม่มีคำตอบ
- ใช้ B01, B04 และจุดเริ่ม B05; B01 reuse ภาพเดียว ไม่เจนซ้ำ
- ข้อความครบ: หัวจอ “ถามผู้ช่วย”, ป้าย “บริการปรึกษาออนไลน์”, คำถาม “เริ่มใช้บริการต้องเตรียมอะไร?”, ข้อความสถานะ “ส่งคำถามแล้ว”, ป้ายถาวร “ภาพจำลอง”
- Layout normalized: header x=0.08–0.92,y=0.06–0.14; ป้ายบริการ y=0.17–0.22; กล่องคำถาม x=0.10–0.90,y=0.30–0.43; สถานะ y=0.48–0.53; พื้นที่คำตอบว่าง y=0.57–0.78; ป้ายภาพจำลอง x=0.10–0.42,y=0.86–0.91
- พื้นเกือบขาว ตัวอักษรหมึกเข้ม กล่องคำถามเขียวอ่อน เส้นขอบอ่านง่าย คำถามเป็นจุดเด่น ไม่มี avatar หรือภาพตกแต่งใหม่ ไม่มีคำตอบหลอกในพื้นที่ว่าง
- raster รวมทุกข้อความและ UI; HTML ทำได้เฉพาะ host, crop, ซับ และ annotation นอกภาพ ไม่พิมพ์ UI ทับแก้คำผิด
- จุด crop: คำถาม x=0.08–0.92,y=0.26–0.55 พร้อมป้ายภาพจำลองนอก crop ที่ host เมื่อ crop ทำให้ป้ายในภาพหาย; ไม่อ้าง crop นี้เป็น source แยก

### APP-A v1 — คำตอบถูกนำมาแสดง
- ใช้ B05; แก้จาก APP-Q เป็น reference เดียวกัน ไม่สร้างหน้าจออิสระ
- เพิ่มกล่องคำตอบ x=0.10–0.90,y=0.57–0.78 ข้อความ “เตรียมอีเมลและหัวข้อที่อยากปรึกษา”; เปลี่ยนสถานะเป็น “ได้รับคำตอบแล้ว”
- คงชื่อ ป้ายบริการ คำถาม กล่องคำถาม header พื้น สี รูปทรง ขนาดตัวอักษร และป้ายภาพจำลองทุกตำแหน่งจาก APP-Q; อนุญาตเปลี่ยนเฉพาะสองบริเวณข้างต้น
- ห้ามเพิ่มเครื่องหมาย verified, citations, score, latency, badge official หรือปุ่มใหม่
- crop ผลลัพธ์ x=0.08–0.92,y=0.53–0.82; ภาพเต็มแสดงกว้างสูงสุด 864×1080px; อ่านผลจาก crop โดยไม่ขยายเกิน 1.25 เท่าของขนาดแสดงปกติ
- หลักฐานข้อความตามบริการสมมติใน SCRIPT ไม่ใช่ API run

### Prompt เจน APP-Q v1 (ฉบับใช้เมื่อเริ่ม W5)
สร้าง raster UI หน้าจอแอปสมมติภาษาไทย ขนาด 1440×1800 ตาม APP-Q v1 ในเอกสารนี้ ไม่ใช่ official LangMind UI ใช้พื้นเกือบขาว หมึกเข้ม เขียวอ่อนเฉพาะกล่องคำถาม จัดพื้นที่ตาม normalized layout ที่ระบุด้านบน คัดลอกข้อความทั้งห้ารายการให้ตรงทุกตัวอักษร ไม่เพิ่มข้อความอื่น ให้คำถามเด่นและมีพื้นที่คำตอบว่าง ไม่มี browser chrome ไม่มีโลโก้ ไม่มีคนหรือหุ่นยนต์ ไม่มีคำตอบหรือเครื่องหมายรับรอง คงขอบและตัวอักษรคมพอให้ดูที่ขนาดแสดง 864px กว้างได้ ผลลัพธ์หนึ่งไฟล์ภาพเท่านั้น

### Prompt แก้เป็น APP-A v1
ใช้ APP-Q v1 ที่ตรวจรับจริงเป็นภาพอ้างอิง แก้เฉพาะสถานะใน y=0.48–0.53 เป็น “ได้รับคำตอบแล้ว” และเพิ่มกล่องคำตอบใน x=0.10–0.90,y=0.57–0.78 ข้อความ “เตรียมอีเมลและหัวข้อที่อยากปรึกษา” คง geometry สี ฟอนต์ header ป้ายบริการ กล่องคำถาม คำถาม และป้ายภาพจำลองทุกตำแหน่งเดิม ห้ามเพิ่มข้อความ ไอคอน avatar โลโก้ citations คะแนน เวลา หรือปุ่ม ผลลัพธ์ขนาด 1440×1800 หนึ่งภาพ

Prompt นี้ยังไม่เคยส่งเจน เมื่อใช้จริงต้องเก็บ prompt เต็มที่ประกอบ layout/ข้อความแล้ว input reference และไฟล์ผลลัพธ์ที่เลือก ไม่ใช้เพียงลิงก์มายังเอกสารแทน prompt ใน log

## ตรวจแผนและเงื่อนไข W5
ตรวจเชิงเอกสาร: ใช้คำถามเดียวครบวงจร เริ่มจากหน้าจอก่อนศัพท์ มี owner ของแต่ละฝั่ง และแบบภาพ sample ครบสองสถานะ ไม่ถือว่า visual หรือ storytelling ผ่าน
ก่อน W5: ลองอ่านบทร่างจริง แก้เวลาซ้ำซ้อน; ตรวจและติดตั้ง Catalog จากต้นทาง; ทำ APP-Q ก่อนแล้ว APP-A; ดูภาพคู่สถานะเต็มและ crop ที่ 360×640 ก่อน motion
ทดสอบ sample พร้อมเสียงร่าง/ซับ: คำถามไปถึงบริการก่อนผลกลับ คำตอบขึ้นจอหลังผลถึงแอป ผู้ชมแยก API/แอปได้ และไม่มีข้อความสำคัญอ่านแข่งกับซับ
หลัง sample ค่อยแก้รายละเอียด B01–B03/B06 และฟอนต์/สีจากผลตรวจ ไม่ต้องเจน assets เพิ่มหาก reuse คู่ภาพเดิมได้
ยังไม่มีการอ่านออกเสียงจริง ผลทดสอบผู้ชม ภาพ generated หรือ Catalog integration รอบนี้

## จังหวะที่ใช้จริงใน sample v1

ให้ภาพเต็มของคำถามนิ่งประมาณ 5 วินาที เพราะอ่านได้ที่ 360×640 แล้ว ช่วงส่งแยกหน้าจอ ระบบของแอป และ LangMind เป็นสามกรอบแนวตั้ง วาดเส้นขาไปจากบนลงล่างและใช้เส้นอีกด้านสำหรับขากลับ หัวลูกศรเป็นตัวบอกทิศทางร่วมกับสี

| วินาที | เหตุการณ์ |
|---|---|
| 0.000–4.884 | เปิดผู้ช่วย AI และโลโก้ ให้ robot ชี้ขึ้นเข้าหาแผ่นโลโก้ |
| 4.884–9.912 | ถือ APP-Q ให้ทันอ่านคำถามเดิม |
| 9.912–13.752 | หน้าจอ → ระบบของแอป → LangMind |
| 13.752–17.930 | LangMind → ระบบของแอป (ถึง 15.750) → หน้าจอ (ถึง 17.280) |
| 17.930–20.700 | กลับมาที่ APP-Q แล้วสลับเป็น APP-A ที่ 18.244 |
| 20.700–23.892 | ค้าง crop คำตอบและป้ายภาพจำลองภายนอก |
| 23.892–33.167 | เน้นฝั่งแอปแล้วฝั่งบริการตามวลี ก่อนถือภาพรวม |
