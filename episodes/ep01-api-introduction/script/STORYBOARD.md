## หน้าจอที่ต้องทำ

1. เว็บถาม–ตอบร้านสมมติ: input, pending, answer, คำอธิบายแหล่งความรู้ ไม่สร้าง live controls ใน composition
2. Knowledge finder: คำค้นกับข้อความที่พบ ไม่มีคะแนนความแม่นยำแต่ง
3. Voice flow: ถอดเสียง → chat → speech แสดงว่าเป็นหลายความสามารถที่แอปต่อกัน
4. Usage overview: หมวด metric ไม่มีค่าการใช้งานสมมติที่ดูเหมือนจริง
5. Integration view: endpoint และ body ตัวอย่างที่ไม่ใส่ secret
