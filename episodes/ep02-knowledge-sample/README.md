# AI รู้คำตอบของร้านเราได้ยังไง?

ตัวอย่างแนวตั้ง 18 วินาทีสำหรับดูทิศทางคลิป LangMind ฉากแชทและคู่มือเป็นภาพจำลอง ตรงกับคำถามเดิมจาก EP01

| ช่วง | สิ่งที่เห็น |
|---|---|
| 0–6.094 วินาที | แชท EP01 สถานะส่งคำถาม ใช้ APP-Q ครอปเฉพาะบริเวณคำถาม |
| 6.094–11.784 วินาที | คู่มือสมมติหนึ่งหน้า ไฮไลต์บรรทัดที่ตอบคำถาม |
| 11.784–18.08 วินาที | แชท EP01 สถานะได้รับคำตอบ ใช้ APP-A ครอปคำถามกับคำตอบ ป้ายชื่อคู่มือเป็นคำอธิบายนอกภาพแชท |

[MP4](langmind-knowledge-sample.mp4) · [เฟรมขนาดมือถือ](preview.jpg) · [ซอร์ส HyperFrames](index.html)

ใช้ภาพ APP-Q / APP-A และสื่อกลางที่มีอยู่ เสียงร่างจาก Edge TTS, th-TH-NiwatNeural มีซับไทยสามช่วงตามไฟล์เสียงที่วัดจริง อ้างอิงความสามารถใช้เอกสารและแสดงที่มาจาก [ฟีเจอร์ LangMind](https://langmind.in.th/features)

ส่งออกจาก paused GSAP timeline ผ่าน Edge และ FFmpeg โดยใช้สคริปต์เรนเดอร์ของ EP01 ปรับเฉพาะพอร์ตและชื่อ composition

ตรวจไฟล์ส่งมอบด้วย FFmpeg โดยถอดรหัสวิดีโอและเสียงครบ 542 เฟรม ได้ H.264 1080×1920 ที่ 30 fps และ AAC mono 24 kHz ความยาว 18.08 วินาที ตรวจภาพจาก MP4 ที่วินาที 2, 9 และ 16 ขนาด 360×640 ต่อเฟรม เห็นคำถาม บรรทัดในคู่มือ คำตอบ และป้ายที่มาครบ เสียงตรวจระดับสัญญาณได้ peak −4.4 dBFS และยังไม่ได้ประเมินการออกเสียงด้วยการฟัง
