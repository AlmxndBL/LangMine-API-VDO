# EP08 — Chat Conversations & History API: ทำระบบประวัติแชท โหลดข้อความเก่า และจัดการห้องสนทนา

สถานะ: ออกแบบ W3–W4 เสร็จสมบูรณ์ รอเริ่มสร้าง Sample (W5) และการผลิต (W6)  
อ้างอิง: [Workflow](../../docs/WORKFLOW.md), [ข้อกำหนด Storyboard](../../docs/STORYBOARD_GUIDELINES.md) และคู่มือ [langmind-api.md](../../langmind-api.md)

## 1. โจทย์จากมุมคนดู (Audience & Purpose)

* **ผู้ชมเป้าหมาย**: Developer ที่ทำหน้าเว็บแชทเบื้องต้นได้แล้ว (จาก EP02/EP03) และต้องการทำระบบ **"ประวัติการสนทนา (Chat History)"** ให้ผู้ใช้กลับมาเปิดอ่านแชทเก่า เปลี่ยนชื่อหัวข้อแชท ปิดงาน หรือลบแชทได้เหมือนแอปแชทมาตรฐาน
* **พื้นฐานเดิมของผู้ฟัง**: รู้วิธีส่งข้อความและรับ `conversation_id` จาก Chat API แล้ว แต่ยังไม่รู้วิธีดึงรายการห้องแชท ดึงข้อความย้อนหลัง และจัดการสถานะของห้องสนทนา
* **ความต้องการหลัก**: อยากสร้างแถบรายการประวัติแชท (Sidebar) ที่โหลดหน้าถัดไปได้ (Cursor Pagination), กดดูข้อความเก่า–ใหม่ในห้องแชท, และเปลี่ยนชื่อหรือปิดบทสนทนาได้
* **จุดติดขัด (Friction)**:
  * ลืมส่ง `?agent_id=` ตอนเรียก endpoint ของ conversation/messages ทำให้เรียกไม่ผ่าน (เพราะเป็น query param บังคับทุกตัวในหมวดนี้)
  * ไม่รู้ว่ารายการประวัติแชทแบ่งหน้าอย่างไร (ใช้ `next_cursor` ไม่ใช่ `page/total`)
  * ไม่รู้ว่าข้อความในห้องแชทเรียงลำดับอย่างไร และฟิลด์ไหนมีค่าเฉพาะฝั่ง `assistant`
* **เหตุผลที่ดู**: เห็นท่อการจัดการประวัติแชท 3 ขั้นตอน (**ดึงรายการบทสนทนา → ดึงข้อความในบทสนทนา → เปลี่ยนชื่อ/ปิด/ลบห้องสนทนา**)
* **สิ่งที่ดูจบแล้วนำไปทำต่อได้**: สร้างระบบประวัติแชทในเว็บหรือแอปของตัวเองได้ครบวงจร รวมถึงรู้วิธีสั่งหยุดข้อความ (`stop`) และดาวน์โหลดไฟล์ที่ AI สร้าง (`generated-files`)

## 2. แกนคำอธิบายและ Use Case ตัวอย่าง

* **Use Case ตัวแทน**: **"ระบบประวัติการสนทนาและจัดการเคสในเว็บแชทร้านกาแฟ (Cafe Chat History & Session Manager)"**
  * *เหตุการณ์*: ลูกค้าหรือพนักงานเปิดหน้าเว็บแชท เห็นรายการหัวข้อที่เคยคุยไว้ เช่น `"ราคาสินค้า A"` กดเข้าไปอ่านข้อความย้อนหลังพร้อมดูแหล่งอ้างอิง (`citations`) แล้วกดเปลี่ยนชื่อหัวข้อเป็น `"สอบถามราคาสินค้า A"` พร้อมปรับสถานะเป็นปิดงาน (`status: "closed"`)
* **ท่อการทำงาน 3 ครั้ง (เตรียม → เชื่อม 3 ครั้ง → ใช้ผล)**:
  1. **ครั้งที่ 1: ดึงรายการบทสนทนา (`GET /api/chat/conversations?agent_id=...&limit=50`)**: รับรายการ `items` และ `next_cursor` สำหรับดึงหน้าถัดไป
  2. **ครั้งที่ 2: ดึงข้อความในบทสนทนา (`GET /api/chat/conversations/{id}/messages?agent_id=...`)**: รับข้อความเรียงจากเก่าไปใหม่ (`user` → `assistant`) พร้อม `citations`, `tokens_in/out`, `latency_ms`
  3. **ครั้งที่ 3: เปลี่ยนชื่อ ปิด หรือลบบทสนทนา (`PATCH` / `DELETE /api/chat/conversations/{id}?agent_id=...`)**: ส่ง partial update เช่น `{ "title": "...", "status": "closed" }` หรือสั่งลบถาวร (`204`)
* **การแบ่งหน้าที่ชัดเจน (Separation of Concerns)**:
  * **LangMind API ทำหน้าที่**: จัดเก็บประวัติบทสนทนาและข้อความตาม `agent_id`, แบ่งหน้าด้วย cursor, และอัปเดตชื่อ/สถานะหรือลบถาวร
  * **แอปพลิเคชัน (Developer) ทำหน้าที่**: ผูกสิทธิ์เจ้าของห้องแชทในฝั่งแอปตัวเอง, ส่ง `?agent_id=` ทุกครั้งที่เรียก และเก็บ API Key ไว้ที่ระบบหลังบ้าน

## 3. โครงเรื่อง 9 ช่วง (9-Beat Outline แบบ EP04 v3)

| Beat | คำถามคนดู | สิ่งที่เห็นในจอ |
|---|---|---|
| **b1** | มีหน้าแชทแล้ว ถ้าลูกค้าปิดเว็บไป แล้วกลับเข้ามาใหม่ จะดึงประวัติแชทเก่ามาแสดงและเปลี่ยนชื่อห้องแชทยังไง | หน้าจอเว็บแชทแสดงแถบประวัติแชทด้านซ้ายและข้อความย้อนหลัง · ตั้ง 3 คำถาม: เตรียมอะไร · เชื่อมตรงไหน · เอาผลไปใช้ยังไง |
| **b2** | ภาพรวมทั้งหมดทำงานยังไง | แผนผัง: หน้าเว็บแชท ⇄ ระบบหลังบ้าน ⇄ LangMind Chat API · เรียก 3 ขั้น: **1. ดึงรายการห้องแชท → 2. โหลดข้อความในห้อง → 3. เปลี่ยนชื่อ/ปิด/ลบห้อง** |
| **b3** | ต้องเตรียมอะไรบ้าง | 1. `agent_id` (บังคับส่งเป็น query param ทุก endpoint ในหมวดนี้) และ `conversation_id` · 2. API Key (`lmpat_`) สิทธิ์ `chat:invoke` · 3. ระบบหลังบ้านเก็บ Key และเช็กสิทธิ์เจ้าของแชท |
| **b4** | ครั้งที่ 1: ดึงรายการบทสนทนามาแสดงในแถบด้านข้างยังไง | เรียก `GET /api/chat/conversations?agent_id=01J8...&limit=50` ได้รายการ `items` (`id`, `title`, `status`, `message_count`) และ `next_cursor` (ส่งกลับไปเป็น `?cursor=` เพื่อโหลดหน้าถัดไป ถ้า `null` แปลว่าหมดแล้ว) |
| **b5** | ครั้งที่ 2: กดเลือกห้องแล้วโหลดข้อความเก่ามาแสดงยังไง | เรียก `GET /api/chat/conversations/{id}/messages?agent_id=01J8...&limit=50` ได้ข้อความเรียงจากเก่าไปใหม่เสมอ (`role: user` และ `assistant` พร้อม `citations`, `tokens_in`, `tokens_out`, `latency_ms`) |
| **b6** | ครั้งที่ 3: เปลี่ยนชื่อหัวข้อ ปิดบทสนทนา หรือลบแชททำยังไง | เรียก `PATCH /api/chat/conversations/{id}?agent_id=...` ส่งเฉพาะฟิลด์ที่จะแก้ เช่น `{"title": "สอบถามราคาสินค้า A", "status": "closed"}` หรือเรียก `DELETE` (ไม่มี body คืน `204` ลบถาวร กู้คืนไม่ได้) |
| **b7** | เอาผลไปใช้ยังไงและมีฟีเจอร์เสริมอะไรอีก | ฟิลด์ `tokens_in/out` และ `latency_ms` มีค่าจริงเฉพาะข้อความฝั่ง `assistant` (ฝั่ง `user` เป็น `0`/`null`) · นอกจากนี้ยังมี `POST /chat/messages/{id}/stop` สำหรับหยุด stream ที่กำลังวิ่ง และ `GET /chat/messages/{id}/generated-files/{file_id}` สำหรับดาวน์โหลดไฟล์ที่ Agent สร้าง |
| **b8** | สรุป | เตรียม `agent_id` + Key `chat:invoke` → เชื่อม 3 จุด (`conversations` · `messages` · `PATCH/DELETE`) → ได้ระบบประวัติแชทครบเหมือนแอปมาตรฐาน |
| **b9** | ผู้สนับสนุน | โลโก้ LangMind · `langmind.in.th` |
