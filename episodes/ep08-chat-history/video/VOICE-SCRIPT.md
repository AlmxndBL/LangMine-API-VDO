# EP08 — บทสำหรับสร้างเสียง

## b1 → assets/voice/b1.wav
พอเราทำหน้าเว็บแชทให้คุยกับ AI ได้แล้ว คำถามถัดมาคือ ถ้าผู้ใช้ปิดหน้าเว็บไป แล้วเปิดกลับมาใหม่ จะดึงรายการแชทเก่ามาแสดงด้านข้าง กดอ่านข้อความย้อนหลัง หรือเปลี่ยนชื่อห้องแชทได้อย่างไร ถ้าอยากทำระบบประวัติแชทให้ครบแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ภาพรวมของฟีเจอร์นี้เชื่อมระหว่างหน้าเว็บแชท ระบบหลังบ้านของคุณ และ Chat API ของ LangMind โดยระบบหลังบ้านจะเรียกใช้งานสามขั้นตอนหลัก คือหนึ่ง ดึงรายการบทสนทนาทั้งหมด สอง ดึงข้อความย้อนหลังในห้องที่เลือก และสาม เปลี่ยนชื่อ ปิด หรือลบบทสนทนาครับ

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือรหัส agent ID ซึ่งสำคัญมาก เพราะทุก endpoint ของการจัดการบทสนทนาและข้อความ บังคับให้ส่ง agent ID เป็น query parameter เสมอ เพื่อยืนยันว่าเป็นบทสนทนาของ Agent ตัวนั้นจริง อย่างที่สองคือ API Key ที่มีสิทธิ์ chat invoke เพียงตัวเดียวก็ใช้ทั้งอ่านและเปลี่ยนชื่อห้องแชทได้เลย อย่างที่สามคือระบบหลังบ้านสำหรับเก็บ Key และเช็กสิทธิ์เจ้าของแชทครับ

## b4 → assets/voice/b4.wav
มาดูการเชื่อมครั้งที่หนึ่ง การดึงรายการบทสนทนา เรียก GET ไปที่ chat conversations พร้อมส่ง agent ID และจำนวน limit ระบบจะคืนรายการบทสนทนาในชื่อ items ซึ่งมีทั้งรหัสห้อง ชื่อหัวข้อ สถานะ จำนวนข้อความ และคืนค่า next cursor กลับมา ถ้ามีหน้าถัดไปก็นำค่านั้นส่งกลับไปเป็น cursor ได้เลย แต่ถ้าเป็น null แปลว่าครบทุกรายการแล้วครับ

## b5 → assets/voice/b5.wav
ครั้งที่สอง การดึงข้อความในบทสนทนา เมื่อผู้ใช้กดเลือกห้องแชท ให้เรียก GET ไปที่ chat conversations ตามด้วยรหัสห้อง และ messages พร้อมส่ง agent ID ระบบจะคืนข้อความเรียงจากเก่าไปใหม่เสมอ แยก role เป็น user และ assistant พร้อมแหล่งอ้างอิง citations จำนวนโทเค็นขาเข้าขาออก และเวลาประมวลผล latency ms ครับ

## b6 → assets/voice/b6.wav
ครั้งที่สาม การเปลี่ยนชื่อ ปิด หรือลบบทสนทนา ถ้าต้องการเปลี่ยนชื่อหัวข้อหรือปิดห้องแชท ให้ส่ง PATCH ไปที่ chat conversations ตามด้วยรหัสห้องและ agent ID โดยส่งเฉพาะฟิลด์ที่จะแก้ เช่น title เป็น สอบถามราคาสินค้า A และ status เป็น closed ส่วนถ้าต้องการลบทิ้ง ให้ส่ง DELETE ไปที่เส้นเดียวกันโดยไม่ต้องมี body ระบบจะตอบกลับสองศูนย์สี่และลบถาวรทันทีครับ

## b7 → assets/voice/b7.wav
นอกจากนี้ยังมีรายละเอียดที่ช่วยให้ทำหน้าแชทได้สมบูรณ์ขึ้น คือค่าโทเค็นและ latency บนข้อความย้อนหลัง จะมีค่าจริงเฉพาะฝั่ง assistant ส่วนฝั่ง user จะเป็นศูนย์และ null เสมอ และถ้าระหว่างคุยต้องการปุ่มกดหยุดข้อความที่กำลังไหลอยู่ ก็ส่ง POST ไปที่ chat messages ตามด้วย message ID และ stop ได้เลย รวมถึงดาวน์โหลดไฟล์ที่เอเจนต์สร้างผ่าน generated files ได้ด้วยครับ

## b8 → assets/voice/b8.wav
สรุปครับ เตรียม agent ID และ API Key สิทธิ์ chat invoke เชื่อมสามจุด คือดึงรายการห้องที่ conversations โหลดข้อความที่ messages และแก้ไขหรือลบด้วย PATCH และ DELETE เพียงเท่านี้เว็บแชทของคุณก็มีระบบประวัติการสนทนาที่ครบถ้วนแล้วครับ

## b9 → assets/voice/b9.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้างเว็บแชทและเชื่อมต่อ Agent ของคุณได้ที่ LangMind ดอท อิน ดอท ทีเอช
