### Beat b2: ภาพรวมสถาปัตยกรรม (Architecture Flow)
* **หัวข้อ**: `ภาพรวมทั้งหมด` / `3 ส่วนสำคัญและการไหลของข้อมูล`
* **ภาพหลัก**:
  * กล่องด้านบน: **แอปพลิเคชันมือถือ / เว็บไซต์ (Client)**
  * กล่องกลาง: **เซิร์ฟเวอร์หลังบ้าน (Backend Server)** พร้อมป้ายกุญแจ `lmpat_` (Key ฝั่งเซิร์ฟเวอร์)
  * กล่องล่าง: **LangMind Platform & Agent Engine** พร้อมโลโก้ LangMind
  * ลูกศรไป-กลับพร้อม Dot แอนิเมชันวิ่งรับส่งข้อมูล
  * ป้ายลำดับ 3 จังหวะ: `1 เริ่มห้องใหม่`, `2 สตรีมคำตอบ`, `3 ถามต่อในห้องเดิม`
* **การเคลื่อนไหว**: โหนดทั้ง 3 โผล่ตามลำดับ, เส้นเชื่อมและจุดวิ่งไหลผ่านระหว่างโหนด

### Beat b3: 1. สิ่งที่ต้องเตรียม (Prerequisites)
* **หัวข้อ**: `1. เตรียม` / `ต้องมี 3 อย่างให้พร้อม`
* **ภาพหลัก**:
  * การ์ดใบที่ 1: **Agent ใน LangMind** — ระบุ `agent_id`, สัญลักษณ์ Active พร้อมกล่องเตือนหากไม่ได้เปิดใช้งาน
  * การ์ดใบที่ 2: **API Key (ระบุสิทธิ์)** — แสดงตัวอย่างกุญแจ `lmpat_••••••••` พร้อมชิป Scope `chat:invoke`
  * การ์ดใบที่ 3: **เซิร์ฟเวอร์หลังบ้าน** — เน้นย้ำข้อความความปลอดภัย "เก็บ Key บน Server เท่านั้น ห้ามใส่ในหน้าเว็บ"
* **การเคลื่อนไหว**: การ์ดซ้อนกันเลื่อนขึ้นมาทีละใบ มีประกายไฮไลต์บนชิปสิทธิ์

### Beat b4: 2. เชื่อมครั้งที่ 1 (เริ่มห้องใหม่)
* **หัวข้อ**: `2. เชื่อม` / `ครั้งที่ 1 · เริ่มห้องแชตใหม่`
* **แถบ Minimap ด้านบน**: สัญลักษณ์สีเขียว (`#38815A`) `หลังบ้าน ⇄ 1 · เริ่มห้องแชตใหม่ ⇄ LangMind API`
* **ภาพหลัก**:
  * ช่อง Input Data: ชิปคำขอ `POST /api/chat/message`
  * กล่องโค้ดคำขอ (Request Code Box):
    * Header: `Authorization: Bearer $LM_TOKEN`
    * Body JSON:
      * `"agent_id": "01J8XM..."`
      * `"query": "สินค้าชิ้นนี้มีของไหมครับ"`
      * `"conversation_id": null` *(ไฮไลต์สีเขียว: เปิดห้องใหม่)*
  * ลูกศรไหลลงมายังกล่อง Response
  * กล่อง Event แรก: `message_start` คืนค่า `conversation_id: "conv_8892"`
  * Mascot หุ่นยนต์โปรแกรมเมอร์ (`20-laptop.png`) ทำงานอยู่มุมจอ
* **การเคลื่อนไหว**: กล่องโค้ดเลื่อนเข้าซ้าย บรรทัดไฮไลต์กระพริบเบา ๆ แล้วกล่องผลลัพธ์คลี่ออก

### Beat b5: 2. เชื่อมครั้งที่ 2 (รับสตรีมคำตอบสด)
* **หัวข้อ**: `2. เชื่อม` / `ครั้งที่ 2 · สตรีมคำตอบสด`
* **แถบ Minimap ด้านบน**: สัญลักษณ์สีทอง (`#8d732c`) `หลังบ้าน ⇄ 2 · สตรีมคำตอบสด ⇄ LangMind Core`
* **ภาพหลัก**:
  * กล่องจำลอง Event Stream (SSE):
    * `data: {"event": "message", "answer": "สินค้าชิ้นนี้..."}`
    * `data: {"event": "message", "answer": "มีพร้อมส่ง 5 รายการค่ะ"}`
    * `data: {"event": "message_end", "answer": "...", "usage": {"tokens": 120}}`
  * หน้าจอมือถือจำลอง (`app-chat-2.jpg`) แสดงฟองแชตที่ตัวหนังสือคลี่ออกทีละคำ
  * แถบด้านล่าง: แนะนำทางเลือก `POST /api/chat/message/blocking` สำหรับสคริปต์หลังบ้านที่ไม่สะดวกอ่าน SSE
* **การเคลื่อนไหว**: ข้อความทยอยพิมพ์ขึ้นมาในจอจำลองแบบ Real-time

### Beat b6: 2. เชื่อมครั้งที่ 3 (ถามต่อเรื่องเดิม)
* **หัวข้อ**: `2. เชื่อม` / `ครั้งที่ 3 · ถามต่อในบทสนทนาเดิม`
* **แถบ Minimap ด้านบน**: สัญลักษณ์สีเขียวน้ำทะเล (`#1E7578`) `หลังบ้าน ⇄ 3 · ถามต่อในห้องเดิม ⇄ LangMind Agent`
* **ภาพหลัก**:
  * ลูกค้าพิมพ์ถามต่อในแอป: `"ถ้าสั่ง 2 ชิ้น มีส่วนลดไหมครับ"`
  * กล่องโค้ดคำขอที่ 2:
    * `"query": "ถ้าสั่ง 2 ชิ้น มีส่วนลดไหมครับ"`
    * `"conversation_id": "conv_8892"` *(ไฮไลต์สีเขียวน้ำทะเล: รหัสเดิม)*
  * หน้าจอมือถือจำลอง (`app-chat-3.jpg`) แสดงคำตอบ AI ที่จำได้ว่าคือสินค้าชิ้นเดิมและคำนวณส่วนลดให้ทันที
  * หุ่นยนต์ Mascot (`10-thumbs-up.png`) ชูนิ้วโป้งแสดงความสำเร็จ
* **การเคลื่อนไหว**: ลูกศรไหลส่งรหัสห้องแชตเดิม และหน้าจอมือถือสลับภาพแสดงบทสนทนาที่ต่อเนื่อง

### Beat b7: 3. นำผลไปใช้ & ข้อควรระวัง
* **หัวข้อ**: `3. ใช้ผล` / `นำไปต่อยอด & ข้อควรระวัง`
* **ภาพหลัก**: การ์ดไอคอน 4 ใบ จัดเรียงเป็นระเบียบ:
  1. **สถิติผู้ใช้จริง**: แนบ `user_id` ของ End-user ทุกครั้งเพื่อให้นับผู้ใช้ตามจริง
  2. **ควบคุมการตอบ**: ใช้ `POST /chat/messages/{id}/stop` เพื่อสั่งยกเลิกสตรีมกะทันหัน
  3. **ดึงประวัติย้อนหลัง**: ใช้ `GET /chat/conversations/{id}/messages` แสดงประวัติในแอป
  4. **ความสมบูรณ์ & ปลอดภัย**: เช็ก `message_end` ก่อนถือว่าจบ และเก็บ Key บนเซิร์ฟเวอร์เสมอ
* **การเคลื่อนไหว**: การ์ดแต่ละใบปรากฏขึ้นพร้อมไอคอนขยับเบา ๆ

---

### Beat b8: สรุปเนื้อหา (3 เสาหลัก)
* **หัวข้อ**: `สรุป` / `3 เสาหลักสู่ความสำเร็จ`
* **ภาพหลัก**: การ์ดสรุปตัวเลข 1-2-3 ชัดเจน:
  * **1. เตรียม**: Agent พร้อมใช้ + API Key (`chat:invoke`) + เซิร์ฟเวอร์เก็บกุญแจ
  * **2. เชื่อม**: เริ่มห้องใหม่ (`null`) → สตรีมสด (`message`) → คุยต่อด้วย `conversation_id`
  * **3. ใช้ผล**: สลับ Blocking ได้, ใส่ `user_id`, และควบคุมแชตผ่าน API ได้เต็มรูปแบบ
* **การเคลื่อนไหว**: ตัวเลข 1-2-3 ปรากฏพร้อมเส้นขีดเชื่อมความสัมพันธ์
