# EP03 v4.4 — Script: Chat API ใน LangMind

## ใจความที่อยากให้จำ
Chat API ช่วยให้แอปส่งข้อความคุยกับ AI แบบสตรีมมิ่งพิมพ์สดทีละคำได้ และหากต้องการคุยต่อเนื่อง ให้เก็บ `conversation_id` แล้วส่งกลับไปในคำถามถัดไป

## คำศัพท์ทางเทคนิคเมื่อใช้ครั้งแรก

- `agent_id`: รหัสประจำตัวของผู้ช่วย AI ในระบบ LangMind
- API Key (`lmpat_`): กุญแจยืนยันตัวตนสำหรับเรียกใช้ API ต้องเก็บรักษาไว้ฝั่งเซิร์ฟเวอร์
- `chat:invoke`: สิทธิ์ (Scope) ที่ต้องเปิดใน API Key เพื่อใช้งาน Chat API
- `POST /api/chat/message`: Endpoint สำหรับส่งข้อความและรับคำตอบแบบสตรีมมิ่ง
- Server-Sent Events (SSE): วิธีการส่งข้อมูลแบบ Real-time ทางเดียวจากเซิร์ฟเวอร์มายังไคลเอนต์
- `conversation_id`: รหัสประจำห้องแชต หากส่งค่า `null` แปลว่าเริ่มห้องใหม่ หากส่งรหัสเดิมแปลว่าคุยต่อเนื่อง
- `message_start`: Event แรกสุดจากสตรีมที่คืนรหัส `conversation_id` และ `message_id`
- `message`: Event ที่ทยอยส่งตัวอักษรของคำตอบออกมาเป็นท่อน ๆ (Chunks)
- `message_end`: Event สุดท้ายที่ยืนยันว่าคำตอบเสร็จสมบูรณ์ พร้อมสรุปข้อมูลการใช้โทเค็น (Usage)
- Blocking (`/chat/message/blocking`): ทางเลือกการเรียกแชตแบบรอรับคำตอบเต็มในรูปแบบ JSON ครั้งเดียวจบ
