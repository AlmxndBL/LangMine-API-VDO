# EP03 video-v4.4 — บทสำหรับสร้างเสียง

## b1 → assets/voice/b1.wav
อยากต่อแชตบอต AI เข้ากับแอปของตัวเอง ที่ตอบไวและจำเรื่องที่คุยได้ใช่ไหมครับ แชตบอตทั่วไปมักตอบช้าเพราะรอโหลดทั้งก้อน หรือพอถามต่อก็ลืมเรื่องที่คุยไปแล้ว วันนี้มาดูวิธีต่อ Chat API ของ LangMind กันครับ เตรียมอะไร เชื่อมตรงไหน และใช้ผลยังไง

## b2 → assets/voice/b2.wav
ภาพรวมมีสามส่วน แอปมือถือรับคำถาม แล้วส่งต่อไปยังเซิร์ฟเวอร์หลังบ้าน เซิร์ฟเวอร์จะยิงคำขอไปยัง LangMind Chat API เพื่อแยกหน้าที่กันชัดเจน เชื่อมต่อสามขั้นตอน หนึ่งเริ่มห้องใหม่ สองสตรีมคำตอบ และสามถามต่อในห้องเดิม

## b3 → assets/voice/b3.wav
สิ่งที่ต้องเตรียม อย่างแรกคือรหัส agent id ของผู้ช่วยที่ตั้งค่าเรียบร้อยใน LangMind อย่างที่สองคือ API Key ที่มีสิทธิ์ chat:invoke สำหรับเรียกคุยกับผู้ช่วย และสามคือเซิร์ฟเวอร์หลังบ้านสำหรับเก็บกุญแจ ห้ามใส่กุญแจในหน้าเว็บเด็ดขาดครับ

## b4 → assets/voice/b4.wav
เชื่อมครั้งที่หนึ่ง คือเริ่มห้องแชตใหม่ เซิร์ฟเวอร์ส่ง POST ไปที่ chat/message ส่ง agent id คำถามลูกค้า และกำหนด conversation id เป็น null เพื่อบอกว่าเป็นห้องใหม่ ระบบจะตอบ event แรก message start ซึ่งส่งรหัส conversation id ประจำห้องกลับมาทันที

## b5 → assets/voice/b5.wav
เชื่อมครั้งที่สอง คือรับคำตอบสตรีมมิ่ง ระบบทยอยส่งชิ้นข้อความผ่าน event message แอปคลี่ตัวหนังสือพิมพ์สดทันที และ event message end บอกว่าคำตอบครบแล้วครับ หากเขียนสคริปต์หลังบ้าน ก็สลับไปใช้ endpoint blocking เพื่อรับก้อนเดียวจบได้เช่นกัน

## b6 → assets/voice/b6.wav
เชื่อมครั้งที่สาม คือถามต่อในเรื่องเดิม เช่นลูกค้าถามต่อว่า ถ้าสั่ง 2 ชิ้น มีส่วนลดไหม ให้ส่ง conversation id เดิมที่ได้จากรอบแรก แนบไปกับคำถามใหม่ AI จะจดจำบริบทเดิมได้ทันที โดยที่ลูกค้าไม่ต้องพิมพ์ชื่อสินค้าซ้ำครับ

## b7 → assets/voice/b7.wav
ข้อแนะนำในการนำไปใช้ ให้ส่ง user id ของผู้ใช้จริงเพื่อให้นับสถิติแม่นยำ สามารถสั่งหยุดสตรีมด้วย endpoint stop และดึงประวัติย้อนหลังมาแสดงได้ และต้องเช็ก message end เสมอ พร้อมเก็บ API Key ไว้บนเซิร์ฟเวอร์เท่านั้นครับ

## b8 → assets/voice/b8.wav
สรุปสามเสาหลัก หนึ่งเตรียม Agent กุญแจ API Key และเซิร์ฟเวอร์ สองเชื่อมด้วยการเปิดห้องใหม่ รับสตรีมสด และถามต่อด้วย conversation id และสามนำผลลัพธ์ไปต่อยอดในแอปของคุณได้อย่างปลอดภัยและรวดเร็วครับ

## b9 → assets/voice/b9.wav
เท่านี้แอปของคุณก็มีแชตบอต AI ที่ตอบไวและคุยต่อเนื่องได้แล้วครับ คลิปนี้สนับสนุนโดย LangMind เริ่มต้นใช้งานได้ที่ langmind.in.th ครับ
