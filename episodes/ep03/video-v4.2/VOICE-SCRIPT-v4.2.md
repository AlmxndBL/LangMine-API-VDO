# EP03 v4.2 — บทพากย์ร่างและซับ

บทนี้เป็น draft สำหรับอ่านและ timing โดยประมาณ ยังไม่มีไฟล์เสียง และยังไม่ sync กับเสียงจริง

## B1 · จากแชทที่คุ้นเคย

เคยขอให้ผู้ช่วยช่วยร่างข้อความ แล้วอยากให้แก้ต่ออีกนิดไหม?  
ตัวอย่างนี้เริ่มจากแชทที่คุ้นเคย: ขอร่าง แล้วถามให้สั้นลงในเรื่องเดิม

## B2 · สิ่งที่อยู่หลังแชท

หน้าจอแชทคือสิ่งที่ผู้ใช้เห็น ส่วน API คือทางเชื่อมของระบบ  
แอปส่งคำถามให้ระบบหลังบ้าน แล้วระบบหลังบ้านเรียก Chat API; แอปของคุณเป็นผู้แสดงคำตอบ

## B3 · เตรียมก่อนเชื่อม

เตรียม Agent ที่เผยแพร่แล้ว และใช้ agent ID ของ Agent นั้น  
สร้าง Personal API Key ที่มีสิทธิ์ chat:invoke แล้วเก็บ Key ไว้ฝั่ง server

## B4 · ส่งคำถามแรก

ส่งคำถามผ่าน POST /api/chat/message ซึ่งตอบกลับเป็น SSE โดยค่าเริ่มต้น  
ระบบหลังบ้านใส่ Bearer Key และข้อมูลคำขอ; conversation_id เป็น null เพื่อเริ่มบทสนทนาใหม่

## B5 · อ่าน SSE ให้จบ

SSE หรือ Server-Sent Events ส่งข้อมูลจาก server มาเป็นลำดับ  
message_start ส่ง ID ก่อน; message ทยอยส่งเนื้อหา; citations อาจมี; message_end ส่งคำตอบเต็มและ usage

## B6 · ถามต่อในห้องเดิม

เมื่อถามต่อ ให้นำ conversation_id ที่ได้รับจาก stream เดิมมาใส่ในคำขอใหม่  
จึงส่งข้อความใหม่ในบทสนทนาเดิม; ใช้ null เมื่อเริ่มบทสนทนาใหม่

## B7 · เส้นทาง Chat API อื่น

ยังมี endpoint สำหรับพรีวิว รอคำตอบเต็มแบบ JSON และหยุด stream  
อ่านหรือแก้ประวัติ ให้คะแนนคำตอบ และดาวน์โหลดไฟล์ที่ Agent สร้างได้; DELETE เป็นการลบถาวร

## B8 · สรุปลำดับใช้งาน

เก็บ Key ที่ server ส่งคำถาม อ่าน stream จน message_end แล้วเก็บ conversation_id เพื่อถามต่อ  
API ส่งข้อมูลกลับมา ส่วนแอปของคุณเลือกวิธีแสดงผลบนหน้าจอ
