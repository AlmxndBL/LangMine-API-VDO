# แบบภาพหน้าจอ EP03 v4.2

## Shared geometry

- ID ของหน้าจอแชท: `CHAT-01` และ `CHAT-02`; source 1440×1800 px, RGB PNG, portrait.
- ใช้ card header “LangMind Assistant” พร้อมป้าย `ภาพจำลอง`; พื้นขาวนวล, ตัวอักษรเข้ม, bubble ผู้ใช้สีเขียวเข้ม และ Agent สีเทาเขียว.
- Crop ในวิดีโอ: รักษาสัดส่วนทั้งหมด; fit ในกรอบมือถือสูงไม่เกิน 920 px โดยไม่ตัด header, label หรือเนื้อหาสนทนา.
- ตัวอักษรฝังอยู่ใน raster ที่สร้างด้วย Sarabun; ไม่มีการแปลข้อความสำคัญโดย image generator.
- สถานะทั้งคู่ใช้ geometry, ฟอนต์, สี, title bar, label, avatar และตำแหน่งปุ่มเหมือนกัน เปลี่ยนได้เฉพาะข้อความสนทนาและ scroll offset.

## CHAT-01 — ผู้ใช้ขอร่าง

- ใช้ใน B1 ก่อนการถามต่อ.
- ข้อความจริงในภาพ: user “ช่วยร่างข้อความขอเลื่อนประชุมเป็นบ่ายสามให้หน่อย”; assistant “ขอเลื่อนเวลาประชุมเป็น 15:00 น. ได้ไหมครับ”.
- แสดงป้ายเล็ก `ตัวอย่างบทสนทนาสมมติ`; ไม่แสดง score, citations, usage หรือผลจาก backend.
- Layout: header 170 px; ป้าย demo ใต้ header; พื้นที่บทสนทนาใช้ bubble แยกซ้าย/ขวา; แถบ composer ไม่แสดงปุ่มส่งที่ดูเหมือนใช้งานจริง.

## CHAT-02 — ขอให้สั้นลง

- ใช้ใน B1 หลัง state แรก.
- คงข้อความแรกและคำตอบไว้ แล้วเพิ่ม user “ช่วยย่อให้สั้นลงอีก”; assistant “ขอเลื่อนประชุมเป็นบ่ายสามได้ไหมครับ”.
- ข้อความเป็นบทสนทนาสมมติ ไม่อ้างว่าเป็นคำตอบของ Agent จริง.
- เลื่อนภาพขึ้นเพียงพอให้ข้อความถามต่อกับคำตอบล่าสุดเห็นพร้อมกัน; ไม่มีชื่อผู้ใช้จริง.
