อยากเลื่อนประชุม แต่คิดคำสุภาพไม่ออก? ผู้ใช้ขอร่าง แล้วขอให้ย่ออีกครั้ง

แอปของคุณแสดงหน้าจอ server ส่งคำถามผ่าน Chat API ไปยัง Agent

เตรียม agent_id กับ API key ที่มีสิทธิ์ chat:invoke; เก็บ key ไว้ฝั่ง server ไม่ใส่ browser

เริ่มด้วย POST /api/chat/message แบบ SSE ที่ทยอยส่งข้อมูล; ส่ง agent_id, query และ conversation_id: null เพื่อเริ่มใหม่

message_start แจ้ง ID ของบทสนทนาและข้อความ message ส่งคำตอบทีละช่วง; citations อาจมี message_end ส่งคำตอบฉบับเต็ม

เก็บ conversation_id ไว้; เมื่อถามต่อ ส่ง ID เดิมเพื่อกลับไปยังบทสนทนาเดิม

ยังเลือกแบบรอคำตอบเต็มหรือพรีวิวใน Agent Builder หยุด stream และอ่านหรือจัดการประวัติได้ รวมถึงให้คะแนนคำตอบและดาวน์โหลดไฟล์จาก Agent

server ส่งคำถาม; แอปรับ stream และแสดงคำตอบ ส่ง conversation_id เดิมเมื่อถามต่อ

หน้าจอและคำตอบเป็นภาพจำลอง ไม่ได้เรียก API จริง. ดูคู่มือ Chat API ที่ langmind.in.th
