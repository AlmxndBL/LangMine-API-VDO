# EP03 v4.3 — Screen designs

ภาพทั้งหมดเป็น mockup ที่สร้างด้วยสคริปต์ใน workspace ไม่ใช่ screenshot official UI และไม่ใช่ผลเรียก API. ต้นฉบับทุกภาพ 1440×1800 px; composition ใช้ crop ด้านบน 1440×1400 แล้วแสดงที่ 840×817 px เพื่อให้ข้อความขนาด 48–50 px ในต้นฉบับไม่เล็กกว่า 28 px บนเฟรมแนวตั้ง.

## CHAT-01 · คำถามและคำตอบแรก

- **ใช้ที่:** B1; ส่วน header, avatar, bubble shape และระยะขอบต้องคงเดิมใน CHAT-02
- **สถานะ:** หลังผู้ใช้ถามและ Agent ตอบ; ไม่แสดง loading หรือ error
- **ข้อความจริงบนภาพ:** หัว `ตัวอย่างแชต` และป้าย `ภาพจำลอง`; ชื่อ `ผู้ช่วยงาน`; ผู้ใช้ `ช่วยร่างข้อความเลื่อนประชุมจาก 14:00 เป็น 15:00 ให้สุภาพหน่อย`; คำตอบ `ขอเลื่อนประชุมวันนี้จาก 14:00 เป็น 15:00 นะคะ`
- **Layout:** top bar สูง 150 px; ป้ายภาพจำลอง 44 px ใต้ header; ผู้ใช้ชิดขวาในพื้นที่ 900×340 px; คำตอบชิดซ้ายในพื้นที่ 1050×330 px; เหลือช่องว่างด้านล่าง;ไม่มีรายชื่อ agent, avatar ที่สื่อถึงบัญชีจริง หรือ branding ที่อ้างว่าเป็น official UI
- **Framing:** 1440×1800; crop `x=0..1440, y=0..1400`; แสดง 840×817 px ที่ `x=120, y=280`; เก็บคำถามและคำตอบเต็ม ไม่ crop ข้อความ; composer ที่อยู่ใต้ crop ไม่ปรากฏในช็อต
- **Layer/motion:** raster ทั้ง UI; HTML ใช้เคลื่อน raster เป็นชิ้นเดียว; robot เป็น PNG แยกและไม่บังข้อความ
- **Continuity:** สีเขียวเข้ม/เขียวอ่อน, header, font, bubble geometry และเวลา 14:00/15:00 คงเดิมใน CHAT-02; เพิ่มเฉพาะข้อความถามต่อและคำตอบย่อ
- **Source/prompt:** deterministic Pillow renderer `build_screens.py`; Sarabun local; ไม่มี generative image prompt
- **ตรวจรับ:** อ่านคำถาม/คำตอบที่ขนาดแสดงจริง 720×900 และ crop 90%; ตรวจคำไทยกับบทก่อนนำเข้า

## CHAT-02 · คำถามต่อ

- **ใช้ที่:** B6 และ B8; เป็นสถานะต่อเนื่องจาก CHAT-01 ไม่สร้าง UI ใหม่
- **สถานะ:** มีคำถามเดิมกับคำตอบเดิม แล้วเพิ่มคำถาม `ขอย่อให้เหลือประโยคเดียว` และคำตอบ `ขอเลื่อนประชุมวันนี้เป็น 15:00 นะคะ`
- **Layout:** คง header และ geometry ของ CHAT-01; ลดระยะระหว่างบทสนทนาก่อนหน้าอย่างเดียว เพื่อเพิ่ม bubble คู่ที่สอง; คำถามใหม่อยู่ใต้คำตอบเดิม และคำตอบใหม่อยู่ล่างสุด
- **Framing:** ใช้ crop และ display size เดียวกับ CHAT-01; คำถามใหม่/คำตอบใหม่ยังอยู่ใน crop; composer ไม่ปรากฏ
- **Layer/motion:** raster ทั้ง UI; reveal raster ชิ้นเดียว; เส้น `conversation_id` อธิบายอยู่นอก UI เป็น HTML overlay
- **Continuity:** คงตำแหน่ง/ขนาด/ตัวอักษรของ bubble คู่แรกเท่ากับ CHAT-01; เพิ่ม bubble คู่ที่สองในพื้นที่ด้านล่าง โดยไม่แก้ header, สี หรือ input bar
- **Source/prompt:** `build_screens.py`; ไม่ใช้ AI เจนรูปและไม่คัดลอกหน้าจอเว็บจริง
- **ตรวจรับ:** เทียบ CHAT-01/02 เคียงกัน; ตรวจข้อความเพิ่ม, การเรียงลำดับ และความอ่านได้บนมือถือ
