# EP03 v4.3 — Storylines

ผู้ชม: ผู้ใช้ทั่วไปที่รู้จักการคุยกับ Agent ใน LangMind และนักพัฒนาที่ต้องการต่อยอดเป็นแชตในแอป

## ตัวเลือก

1. **ข้อความเดียวเดินทางจากผู้ใช้ถึง Agent (แนะนำ)** — ผู้ใช้ขอร่างข้อความเลื่อนประชุม แล้วขอให้ย่ออีกครั้ง ภาพตามเหตุการณ์เดียวจากหน้าแชต ไปยัง server, Chat API, event stream และการถามต่อด้วย `conversation_id`. เปิดด้วยข้อความที่คุ้นเคยและจบด้วยคำตอบที่นำกลับไปแสดงในแอปได้
2. **หลังเวทีของหนึ่งคำตอบ** — เริ่มจากคำตอบในหน้าจอ แล้วถอยไปดูว่าแอป, server, Chat API และ Agent รับส่งข้อมูลกันอย่างไร ก่อนกลับมาที่ผู้ใช้ เหมาะกับผู้ชมที่อยากเห็นการแบ่งความรับผิดชอบมากกว่าติดตามบทสนทนา
3. **เส้นทางของ conversation_id (ตัวเลือกกล้าแตกต่าง)** — ใช้เส้นสายเดียวแทน ID ที่เริ่มว่าง รับค่าจาก stream แล้ววนกลับไปยังคำถามที่สอง ภาพจะเป็นแผนเส้นทางข้อมูลตลอดทั้งคลิป และลดเวลาที่อยู่กับหน้าจอแชต

## แนวที่เลือกผลิต

เลือกข้อ 1 เพราะเหตุการณ์เล็กและคุ้นเคยพาคนดูจากมุมผู้ใช้ไปถึงตัวอย่าง developer ได้โดยไม่เปิดด้วยชื่อ endpoint. การเลือกนี้เป็นการตัดสินใจผลิตตามคำขอให้สร้าง v4.3 ไม่ใช่การรับรองเนื้อหาจากผู้ใช้

**สองวินาทีแรก:** คำถาม “อยากเลื่อนประชุม แต่คิดคำสุภาพไม่ออก?” ปรากฏเหนือภาพแชตจำลองที่เห็นคำขอแล้ว

**ลำดับ:** คำขอของผู้ใช้ → ใครแสดงหน้าจอ → สิ่งที่ต้องเตรียม → request ใหม่ → SSE events → ถามต่อด้วย ID เดิม → เส้นทาง Chat API อื่น → สรุปหน้าที่ของแอป → LangMind API

**ภาพและเสียง:** ภาพหน้าจอเป็น raster จำลอง ข้อความบนจอและซับร่างพาเรื่องในฉบับไม่มีเสียง ไม่มีเสียงบรรยายหรือดนตรีในรอบนี้
