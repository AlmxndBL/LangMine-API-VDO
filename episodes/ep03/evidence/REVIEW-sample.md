## 2. ข้อกำหนดสำหรับ Voice Audition (คัดเลือกเสียงพากย์)

ตามข้อกำหนดในแผนทบทวน:
> "ทำ motion sample ประกอบภาพกับเสียงร่างต่อเนื่องหนึ่งย่อหน้า ซึ่งมีคำถาม ชื่อ LangMind และศัพท์ SSE/event พร้อมเหตุผล ไม่สร้างเสียงแยกตามบรรทัดซับโดยอัตโนมัติ ให้ผู้ใช้ฟังเสียงตัวอย่างเพื่อเลือกก่อนผลิตเสียงทั้งตอน; จนกว่าจะมีการเลือก ให้สถานะเสียงเป็น pending"

### 2.1 ย่อหน้าตัวแทนสำหรับ Audition (Audition Passage)
คัดเลือกข้อความต่อเนื่องจาก Beat 2 และ Beat 3 ซึ่งมีชื่อผลิตภัณฑ์ คำถาม และศัพท์ Event ครบถ้วน:

> *"ใน LangMind API มีทางเลือกการเชื่อมต่อสองรูปแบบหลัก รูปแบบแรกคือการรับผลครบก่อนแสดง และอีกรูปแบบหนึ่งคือการใช้ Streaming API ผ่าน Endpoint chat/message เมื่อใช้ Streaming ระบบจะเริ่มทยอยส่งชิ้นส่วนข้อความออกมาเป็นระยะ ผ่าน Server-Sent Events ตามลำดับ เริ่มจาก message_start ตามด้วย message และปิดท้ายด้วย message_end เพื่อยืนยันว่าคำตอบสมบูรณ์แล้วครับ"*

### 2.2 จุดกำกับการออกเสียงเฉพาะ (Pronunciation Guidelines)
- `LangMind` ➜ ออกเสียงว่า **"แลง-มายด์"**
- `Streaming API` ➜ ออกเสียงว่า **"สตรีม-มิ่ง เอ-พี-ไอ"**
- `chat/message` ➜ ออกเสียงว่า **"แชท สแลช เมส-เซจ"** หรือ **"แชท เมส-เซจ"**
- `Server-Sent Events` ➜ ออกเสียงว่า **"เซิร์ฟ-เวอร์-เซนต์-อี-เวนต์ส"**
- `message_start` ➜ **"เมส-เซจ-สตาร์ต"**
- `message` ➜ **"เมส-เซจ"**
- `message_end` ➜ **"เมส-เซจ-เอ็นด์"**
- `chunk` ➜ **"ชังก์"** (ชิ้นส่วนข้อความ)

### 2.3 สถานะปัจจุบันของเสียง
- **สถานะ:** `Pending` (ยังไม่มีการยืนยันการเลือกเสียงพากย์จากผู้ใช้)
- **หมายเหตุ:** ผลการตรวจภาพนิ่งตัวแทนที่ผ่านแล้ว ไม่ถือว่าเป็นการอนุมัติเสียงพากย์ และไม่ใช้ตัวอย่างนี้ไปสรุปว่าความเร็ว latency ดีขึ้นจริง

## 3. เกณฑ์ก่อนก้าวเข้าสู่ W6 (Gate to W6)
1. ภาพนิ่งตัวแทนผ่านการตรวจความอ่านได้และความต่อเนื่องแล้ว (เสร็จสิ้น)
2. ผู้ใช้ฟังตัวอย่างเสียง Audition และเลือกเสียงที่ต้องการ (ยังรอผู้ใช้เลือก)
3. เมื่อผู้ใช้เลือกเสียงแล้ว จึงจะนำไฟล์เสียงจริงมาเป็นฐาน Timing ของไทม์ไลน์ใน HyperFrames
