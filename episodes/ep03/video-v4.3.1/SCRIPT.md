# EP03 v4.3.1 — Script

## ใจความที่อยากให้จำ

Chat API ช่วยให้แอปส่งคำถามไปยังผู้ช่วยและรับคำตอบกลับมาได้ หากจะถามต่อในบทสนทนาเดิม ให้เก็บ `conversation_id` แล้วส่งกลับไปด้วย

## บทพากย์และข้อความบนจอ

| Beat | บทพากย์ | ซับ/ข้อความหลัก |
|---|---|---|
| B1 | ใน LangMind เราพิมพ์สิ่งที่อยากได้ แล้วผู้ช่วยช่วยร่างคำตอบให้ เช่น ขอข้อความเลื่อนประชุม | พิมพ์สิ่งที่อยากได้ · ผู้ช่วยช่วยร่างคำตอบ |
| B2 | ถ้าอยากให้แชตนี้อยู่ในแอปของเรา แอปเป็นคนแสดงหน้าจอ ส่วน server ส่งคำถามไปที่ Chat API | แอปแสดงหน้าจอ · server ส่งคำถามไปที่ Chat API |
| B3 | ก่อนเรียก API ต้องรู้ว่าจะคุยกับผู้ช่วยตัวไหน และให้ server เก็บ API key ที่มีสิทธิ์ใช้ Chat API ไว้ ห้ามใส่ key ในหน้าเว็บ | `agent_id` เลือกผู้ช่วย · API key เก็บไว้ที่ server |
| B4 | ฝั่ง server เรียก POST `/api/chat/message` แล้วแนบ API key ในส่วนหัว ส่ง `agent_id` กับคำถามในข้อมูลคำขอ ส่วน `conversation_id: null` คือเริ่มบทสนทนาใหม่ในตัวอย่างนี้ | `Authorization: Bearer $LM_TOKEN` อยู่ฝั่ง server · `conversation_id: null` = เริ่มใหม่ |
| B5 | SSE คือการส่งคำตอบเป็นช่วง ๆ แอปอ่านข้อมูลแล้วทยอยแสดงได้ เมื่อได้รับ `message_end` จึงรู้ว่าคำตอบครบแล้ว | SSE ส่งคำตอบเป็นช่วง ๆ · `message_end` บอกว่าครบแล้ว |
| B6 | ตอนเริ่ม API ส่ง `conversation_id` กลับมา ให้นึกว่าเป็นรหัสห้องแชตของบทสนทนานี้ เก็บไว้สำหรับคำถามถัดไป | API ส่ง `conversation_id` กลับมา · เก็บรหัสนี้ไว้ถามต่อ |
| B7 | ถ้าอยากคุยต่อเรื่องเดิม ให้ส่ง `conversation_id` เดิมไปพร้อมคำถามใหม่ ผู้ช่วยจะต่อในบทสนทนาเดิม | ส่ง `conversation_id` เดิม แล้วถามต่อในห้องเดิม |
| B8 | นอกจากส่งข้อความ ยังดูหรือจัดการประวัติ หยุด stream ให้คะแนนคำตอบ และดาวน์โหลดไฟล์ได้ ถ้าต้องการผลทีเดียวก็มีแบบรอคำตอบเต็ม และมีพรีวิวใน Agent Builder | ส่ง/ควบคุม · ดูประวัติ · ให้คะแนน/ดาวน์โหลดไฟล์ · พรีวิว |
| B9 | สรุปสามอย่าง เลือกผู้ช่วย ส่งคำถาม แล้วเก็บรหัสบทสนทนาไว้เมื่อต้องถามต่อ อ่านคู่มือ Chat API ได้ที่ langmind.in.th | เลือกผู้ช่วย → ส่งคำถาม → เก็บรหัสไว้ถามต่อ · langmind.in.th |

## คำศัพท์เมื่อใช้ครั้งแรก

- `agent_id`: รหัสที่เลือกว่าจะคุยกับผู้ช่วยตัวไหน
- API key: กุญแจที่ให้ server เรียก API ได้ เก็บไว้ฝั่ง server
- `chat:invoke`: ขอบเขตสิทธิ์สำหรับเรียก Chat API
- SSE: วิธีรับข้อมูลจากคำตอบเป็นช่วง ๆ
- `conversation_id`: รหัสของบทสนทนาที่ใช้ส่งกลับเมื่อต้องการคุยต่อ
- `message_end`: event ที่บอกว่าคำตอบครบแล้ว

ไม่มีเสียงพากย์ใน Silent Draft; บทนี้เป็นข้อความสำหรับทำ voice sample และปรับ timing หลังเลือกเสียงตาม workflow.
