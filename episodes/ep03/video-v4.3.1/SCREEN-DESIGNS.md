# EP03 v4.3.1 — Screen designs

## CHAT-01 — แชตเริ่มต้น

- ไฟล์: `assets/screens/CHAT-01.png`; raster RGB 1440×1800
- กรอบอุปกรณ์สีหมึกเข้มบนกระดาษขาวนวล; ป้าย “ภาพจำลอง” ที่มุมบน
- ข้อความผู้ใช้: “ช่วยร่างข้อความเลื่อนประชุม จาก 14:00 เป็น 15:00 ให้สุภาพหน่อย”
- คำตอบตัวอย่าง: “ขอเลื่อนประชุมวันนี้จาก 14:00 เป็น 15:00 นะคะ”
- ด้านล่างมีช่องพิมพ์เพื่อสื่อหน้าตาแชต แต่ไม่มีการเคลื่อนไหวหรือสถานะจาก API จริง
- วางในฉาก B1 ที่ x=120, y=300, w=840, h=1050; ใช้ภาพต้นฉบับครบสัดส่วน

## CHAT-02 — ถามต่อในห้องเดิม

- ไฟล์: `assets/screens/CHAT-02.png`; raster RGB 1440×1800
- คงคำถามและคำตอบแรกจาก CHAT-01 แล้วเพิ่มคำถาม “ขอย่อให้เหลือประโยคเดียว” และคำตอบ “ขอเลื่อนประชุมวันนี้เป็น 15:00 นะคะ”
- ใช้ใน B7 ขนาด 800×1000 พร้อมป้าย `conversation_id เดิม + คำถามใหม่`

## ข้อความที่ต้องคงไว้บนภาพ

- ทุกหน้าจอมีคำว่า “ภาพจำลอง” ชัดเจน และไม่ใช้โลโก้หรือส่วนติดต่อผู้ใช้จริงของ LangMind
- ไม่แสดง ID จริง, API key, citations, usage, ราคา หรือ latency
- ตัวอย่าง request แยกจากหน้าจอแชต; ใช้ `YOUR_AGENT_ID`, `conversation_id: null` และ `$LM_TOKEN` เป็น placeholder ใน Authorization header ฝั่ง server
- ออกแบบสำหรับ portrait 1080×1920; ตรวจ raster ที่ขนาดจริงก่อนนำเข้า timeline
