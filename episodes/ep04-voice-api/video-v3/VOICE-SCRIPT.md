# EP04 video-v3 — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` (สร้างเสียงทีละประโยคจาก timing.json) แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
ลองนึกภาพแอปร้านกาแฟ ที่ลูกค้ากดไมค์ แล้วพูดสั่งได้เลย แอปฟังออก แล้วตอบกลับเป็นเสียง แถมถามต่อว่ารับหวานกี่เปอร์เซ็นต์ ถ้าอยากทำฟีเจอร์นี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
API คือช่องทางที่แอปส่งงานไปให้ LangMind ทำ แล้วรับผลกลับมา เหมือนส่งออร์เดอร์เข้าครัว แล้วรอรับจาน ภาพรวมของฟีเจอร์นี้มีสามส่วน แอปมือถือ ระบบหลังบ้านของคุณ และ LangMind ทุกออร์เดอร์ ระบบหลังบ้านเรียก LangMind สามครั้ง คือ ฟัง คิด และพูด

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือ Agent ใน LangMind ที่ใส่ข้อมูลร้านไว้ เช่น เมนูและราคา แล้วเปิดสนทนาด้วยเสียง ในแท็บสื่อและเสียง และกด publish อย่างที่สอง API Key ที่มีสิทธิ์ voice invoke และ chat invoke อย่างที่สาม ระบบหลังบ้านของแอป ไว้เก็บ Key และเป็นคนเรียก API แทนแอปมือถือ

## b4 → assets/voice/b4.wav
มาดูการเชื่อมทีละครั้ง ครั้งที่หนึ่ง ฟัง ระบบหลังบ้านส่งไฟล์เสียง ขนาดไม่เกินสี่เมกะไบต์ ไปที่ Voice Transcribe แล้วได้ข้อความที่ถอดจากเสียงกลับมา

## b5 → assets/voice/b5.wav
ครั้งที่สอง คิด ส่งข้อความนี้เข้า Chat API ของ Agent พร้อมระบุ input mode เป็น voice Agent จะตอบสั้น กระชับ เป็นภาษาพูด และส่ง conversation ID กลับมาด้วย

## b6 → assets/voice/b6.wav
ครั้งที่สาม พูด ส่งคำตอบเข้า Voice Speech ได้ไฟล์เสียงกลับมา เป็น MP3 หรือ WAV ระบบหลังบ้านส่งไฟล์เสียงกลับไป ให้แอปเปิดให้ลูกค้าฟัง

## b7 → assets/voice/b7.wav
ผลที่ได้ เอาไปใช้ได้หลายแบบ ไฟล์เสียง เอาไปเล่นให้ลูกค้าฟัง ข้อความที่ถอดได้ และคำตอบ เอาไปแสดงบนจอเป็นแชท เก็บ conversation ID ไว้ส่งไปรอบถัดไป Agent จะคุยต่อในบทสนทนาเดิม และถ้าถอดเสียงได้ข้อความว่าง แปลว่าไม่ได้ยิน ให้แอปชวนลูกค้าพูดใหม่

## b8 → assets/voice/b8.wav
สรุปครับ เตรียม Agent ที่เปิดเสียงและ publish, API Key ที่มีสิทธิ์ voice และ chat, และระบบหลังบ้านที่เก็บ Key เชื่อมสามครั้ง ฟัง คิด พูด แล้วเอาผลไปเล่นเสียง แสดงข้อความ และคุยต่อ

## b9 → assets/voice/b9.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้าง Agent ที่คุยด้วยเสียงได้ ที่ LangMind ดอท อิน ดอท ทีเอช
