# EP04 video-v3 — ผสม v1 + v2 และปิดท้ายด้วยผู้สนับสนุน

อัปเดต 8 พฤศจิกายน 2026 (Asia/Bangkok) · v1 (`../video/`) และ v2 (`../video-v2/`) เก็บไว้ตามเดิม ไม่ได้แก้

## v3 ต่างจาก v2 อย่างไร
- ใช้โครงเรื่องของ v2 (เตรียม → เชื่อม → ใช้ผล) เป็นแกน
- **ภาพรวมทั้งหมด** (b2): แอป ⇄ LangMind แบบเข้าใจง่าย แล้วขยายเป็นแผนผัง 3 ส่วน (แอปมือถือ → ระบบหลังบ้าน → LangMind) พร้อมการเรียก 3 ครั้ง
- **ช่วงเชื่อมใช้ของจริงจาก v1** (b4–b6): กล่อง endpoint + สิทธิ์ + บรรทัดสำคัญ, ข้อมูลวิ่งตามลูกศร, ไฮไลต์ `input_mode` และ `conversation_id`, มือถือเปลี่ยนหน้า Q → A — โดยมีแถบภาพรวมย่อด้านบนบอกว่ากำลังอยู่ครั้งไหน
- เช็กลิสต์จาก v1 รวมไว้ในช่วงเตรียม (`403 VOICE_DISABLED`, publish) และสรุป
- **ปิดท้ายด้วยโลโก้ LangMind ในฐานะผู้สนับสนุน** (b9) พร้อม langmind.in.th

## ทำไมต้องมี v2
v1 เล่าแบบ "API มี endpoint อะไร" ซึ่งเหมาะกับคนที่เขียนโค้ดเป็นแล้ว v2 เริ่มจากคำถามของคนดูที่ยังไม่เข้าใจ API: **"อยากให้แอปคุยกับลูกค้าด้วยเสียง ต้องทำอะไรบ้าง"** แล้วตอบเป็น 3 ช่วงที่เอาไปทำงานต่อได้ทันที: **เตรียมอะไร → เชื่อมตรงไหน → เอาผลไปใช้ยังไง**

## คนดูและเหตุผลที่ดู
- เจ้าของร้าน / product owner / dev มือใหม่ ที่อยากเพิ่มฟีเจอร์สั่งงานด้วยเสียง แต่ไม่รู้ว่าต้องเตรียมอะไร และส่วนไหนต่อกับส่วนไหน
- ดูจบแล้วต้องตอบได้: ต้องมีอะไรบ้าง 3 อย่าง, ข้อมูลวิ่งผ่านใครบ้าง, ได้อะไรกลับมาแต่ละครั้ง และเอาผลไปทำอะไรในแอป

## โครงเรื่อง 9 ช่วง
| Beat | คำถามคนดู | สิ่งที่เห็น |
|---|---|---|
| b1 | ฟีเจอร์นี้หน้าตาเป็นยังไง | แอปร้านกาแฟ กดไมค์พูด → ตอบกลับเป็นเสียง แล้วตั้ง 3 คำถาม |
| b2 | ภาพรวมทั้งหมด / API คืออะไร | แอป ⇄ LangMind (หน้าร้าน/ครัว) → แผนผัง แอปมือถือ · ระบบหลังบ้าน · LangMind · 3 ครั้ง |
| b3 | ต้องเตรียมอะไร | Agent + ข้อมูลร้าน + สนทนาด้วยเสียง + publish (ไม่เปิด = 403) · API Key 2 สิทธิ์ · ระบบหลังบ้าน |
| b4 | ครั้งที่ 1 ฟัง | order.wav → `voice/transcribe` (voice:invoke, ≤ 4 MB) → `{ "text": … }` |
| b5 | ครั้งที่ 2 คิด | ข้อความ → `chat/message/blocking` (chat:invoke, `input_mode: voice`) → `answer` + `conversation_id` |
| b6 | ครั้งที่ 3 พูด | คำตอบ → `voice/speech` (voice:invoke, ≤ 4,000 ตัวอักษร) → audio/mpeg หรือ audio/wav → มือถือเล่นเสียง |
| b7 | เอาผลไปใช้ยังไง | เล่นเสียง · แสดงเป็นแชท · เก็บ `conversation_id` คุยต่อ · `text` ว่าง = ชวนพูดใหม่ |
| b8 | สรุป | เตรียม → เชื่อม → ใช้ผล |
| b9 | ใครสนับสนุน | โลโก้ LangMind · langmind.in.th |

บทพูดและซับทั้งหมดอยู่ใน [timing.json](timing.json) / [VOICE-SCRIPT.md](VOICE-SCRIPT.md)

## วิธีทำงาน
1. แก้บทใน `timing.json` (say = เสียง, cap = ซับ)
2. `python make-voice-samples.py` → `assets/voice/<beat>.wav` + `.segments.json` (Edge TTS `th-TH-NiwatNeural`, −16%)
3. `node build.mjs` → `index.html` + `VOICE-SCRIPT.md`
4. `npx hyperframes check` / `snapshot` / `render --quality draft`
