# EP04 video-v2 — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` (สร้างเสียงทีละประโยคจาก timing.json) แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
ลองนึกภาพแอปร้านกาแฟ ที่ลูกค้ากดไมค์ แล้วพูดสั่งได้เลย แอปฟังออก แล้วตอบกลับเป็นเสียง แถมถามต่อว่ารับหวานกี่เปอร์เซ็นต์ ถ้าอยากทำฟีเจอร์นี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ก่อนอื่น API คือช่องทางที่แอปของเรา ส่งงานไปให้ LangMind ทำ แล้วรับผลกลับมา เหมือนพนักงานหน้าร้าน ส่งออร์เดอร์เข้าครัว แล้วรอรับจานกลับมา ฟีเจอร์สั่งด้วยเสียง ต้องส่งงานสามครั้ง คือ ฟัง คิด และพูด

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือ Agent ใน LangMind ที่ใส่ข้อมูลร้านไว้ เช่น เมนูและราคา แล้วเปิดสนทนาด้วยเสียง ในแท็บสื่อและเสียง และกด publish อย่างที่สอง API Key ที่มีสิทธิ์ voice invoke และ chat invoke อย่างที่สาม ระบบหลังบ้านของแอป ไว้เก็บ Key และเป็นคนเรียก API

## b4 → assets/voice/b4.wav
ต่อมาคือการเชื่อม แอปมือถือมีหน้าที่แค่อัดเสียง และเล่นเสียง แอปส่งไฟล์เสียงไปที่ระบบหลังบ้าน แล้วระบบหลังบ้านเรียก LangMind สามครั้ง API Key อยู่ที่ระบบหลังบ้านเท่านั้น ไม่ฝังไว้ในแอป

## b5 → assets/voice/b5.wav
ครั้งที่หนึ่ง ส่งไฟล์เสียงไปถอดความ ได้ข้อความกลับมา ครั้งที่สอง ส่งข้อความนั้นให้ Agent ได้คำตอบแบบภาษาพูด ครั้งที่สาม ส่งคำตอบไปอ่านออกเสียง ได้ไฟล์เสียงกลับมา สังเกตว่า ผลของแต่ละครั้ง คือของที่ส่งต่อในครั้งถัดไป

## b6 → assets/voice/b6.wav
สุดท้ายคือการใช้ผล ไฟล์เสียง เอาไปเล่นให้ลูกค้าฟัง ข้อความที่ถอดได้ และคำตอบ เอาไปแสดงบนจอเป็นแชทได้ด้วย เก็บ conversation ID ไว้ พอลูกค้าตอบว่าหวานห้าสิบ ก็ส่งไปพร้อมกัน Agent จะคุยต่อในบทสนทนาเดิม และถ้าถอดเสียงได้ข้อความว่าง แปลว่าไม่ได้ยิน ให้แอปชวนลูกค้าพูดใหม่

## b7 → assets/voice/b7.wav
สรุปครับ เตรียม Agent API Key และระบบหลังบ้าน เชื่อมสามครั้ง ฟัง คิด พูด แล้วเอาผลไปเล่นเสียง แสดงข้อความ และคุยต่อ เท่านี้ แอปของคุณก็คุยกับลูกค้าด้วยเสียงได้แล้วครับ
