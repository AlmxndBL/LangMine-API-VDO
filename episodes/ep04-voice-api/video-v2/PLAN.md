# EP04 video-v2 — แผนเล่าเรื่องจากมุมคนดู

อัปเดต 7 พฤศจิกายน 2026 (Asia/Bangkok) · v1 (`../video/`) เก็บไว้ตามเดิม ไม่ได้แก้

## ทำไมต้องมี v2
v1 เล่าแบบ "API มี endpoint อะไร" ซึ่งเหมาะกับคนที่เขียนโค้ดเป็นแล้ว v2 เริ่มจากคำถามของคนดูที่ยังไม่เข้าใจ API: **"อยากให้แอปคุยกับลูกค้าด้วยเสียง ต้องทำอะไรบ้าง"** แล้วตอบเป็น 3 ช่วงที่เอาไปทำงานต่อได้ทันที: **เตรียมอะไร → เชื่อมตรงไหน → เอาผลไปใช้ยังไง**

## คนดูและเหตุผลที่ดู
- เจ้าของร้าน / product owner / dev มือใหม่ ที่อยากเพิ่มฟีเจอร์สั่งงานด้วยเสียง แต่ไม่รู้ว่าต้องเตรียมอะไร และส่วนไหนต่อกับส่วนไหน
- ดูจบแล้วต้องตอบได้: ต้องมีอะไรบ้าง 3 อย่าง, ข้อมูลวิ่งผ่านใครบ้าง, ได้อะไรกลับมาแต่ละครั้ง และเอาผลไปทำอะไรในแอป

## โครงเรื่อง 7 ช่วง
| Beat | คำถามคนดู | สิ่งที่เห็น |
|---|---|---|
| b1 | ฟีเจอร์นี้หน้าตาเป็นยังไง | แอปร้านกาแฟ กดไมค์พูด → ตอบกลับเป็นเสียง แล้วตั้ง 3 คำถามของคลิป |
| b2 | API คืออะไร | แอป ⇄ LangMind (ส่งงาน / รับผล) เทียบกับส่งออร์เดอร์เข้าครัว · ฟีเจอร์นี้ส่งงาน 3 ครั้ง |
| b3 | ต้องเตรียมอะไร | Agent + ข้อมูลร้าน + เปิด "สนทนาด้วยเสียง" + publish · API Key (`voice:invoke` + `chat:invoke`) · ระบบหลังบ้าน |
| b4 | เชื่อมส่วนไหน | แอปมือถือ (อัด/เล่นเสียง) → ระบบหลังบ้าน (มี Key) → LangMind 3 ครั้ง · แอปไม่มี Key |
| b5 | ส่งอะไรไป ได้อะไรกลับ | 3 ครั้ง: ไฟล์เสียง → ข้อความ → คำตอบ → ไฟล์เสียง · ผลครั้งก่อน = ของที่ส่งครั้งถัดไป |
| b6 | เอาผลไปใช้ยังไง | เล่นเสียง · แสดงเป็นแชท · เก็บ `conversation_id` คุยต่อ · `text` ว่าง = ไม่ได้ยิน ให้ชวนพูดใหม่ |
| b7 | สรุป | เตรียม → เชื่อม → ใช้ผล |

บทพูดและซับทั้งหมดอยู่ใน [timing.json](timing.json) / [VOICE-SCRIPT.md](VOICE-SCRIPT.md)

| Key ขึ้นต้น `lmpat_` · เก็บ key ฝั่ง server เท่านั้น ไม่ใส่ใน client | documented | หัวข้อเริ่มต้นและการยืนยันตัวตน |
| 1 รอบ = transcribe → chat/message/blocking (`input_mode: voice`) → speech | documented | บรรทัด 931–935 |
| ไฟล์เสียงตอบกลับ MP3 หรือ WAV | documented | บรรทัด 888 |

| Agent ตอบราคาได้เพราะใส่ข้อมูลร้าน (เมนู/ราคา) | illustrative | คำตอบตัวอย่าง ไม่ได้เรียก API จริง |

## วิธีทำงาน
1. แก้บทใน `timing.json` (say = เสียง, cap = ซับ)
2. `python make-voice-samples.py` → `assets/voice/<beat>.wav` + `.segments.json` (Edge TTS `th-TH-NiwatNeural`, −16%)
3. `node build.mjs` → `index.html` + `VOICE-SCRIPT.md`
4. `npx hyperframes check` / `snapshot` / `render --quality draft`
