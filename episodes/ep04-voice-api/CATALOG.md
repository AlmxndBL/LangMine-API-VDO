# EP04 — ทะเบียนคัดเลือก Catalog (Voice API)

อ้างอิง: [CATALOG_USAGE_MAP](../../docs/CATALOG_USAGE_MAP.md), [PLAN](PLAN.md), และ [Workflow](../../docs/WORKFLOW.md)  
สถานะ: แผนการเลือกบล็อก Motion ก่อนทำ Storyboard ละเอียดและ Sample (ยังไม่ใช่การติดตั้งถาวรทุกรายการ)

---

## 1. เกณฑ์การคัดเลือกตามหน้าที่ของซีน

ในคลิป EP04 เรามี 3 หน้าที่หลักที่ต้องการแอนิเมชันช่วยอธิบาย:
1. **แสดงหน้าจอมือถือจำลอง (Device Hosting)**: เพื่อให้เห็นแอป Cafe Assistant ในบริบทการใช้งานจริง
2. **แสดงท่อและทิศทางข้อมูล (Data Pipeline & Flow)**: เพื่อให้เห็นท่อ 3 สเต็ป (เสียงพูด -> ข้อความ -> คำตอบ -> เสียง AI)
3. **แสดงคลื่นเสียงและการพูด (Audio Waveform & Voice Activity)**: เพื่อให้เห็นสถานะขณะอัดเสียงไมค์ และขณะ AI เปล่งเสียงตอบกลับ

---

## 2. รายการ Catalog ที่เลือกใช้ตามหน้าที่

| รหัส / ชื่อ Catalog | หน้าที่ในซีน | Beat ที่ใช้ | เหตุผลและข้อจำกัด |
|---|---|---|---|
| **#hf-195 Browser Device Stage** | ใช้แสดงกรอบมือถือ (Mobile Device Frame) ครอบภาพหน้าจอจำลอง | B01, B03, B05 | ใช้ host ภาพ raster หน้าจอแอปสั่งกาแฟ ทำให้ตัวหนังสือและปุ่มไมค์เด่น ไม่หลอกตาว่าเป็น native app |
| **hw-pipeline (Adaptation จาก v1)** | แผนภาพท่อข้อมูล 3 สเต็ป (ฟัง -> คิด -> พูด) | B02, B03, B04, B05 | แสดงกล่อง Endpoint 3 จุด และใช้เส้น connector ชี้การส่งต่อข้อมูลแบบทีละสเต็ป ไม่ขึ้นพรวดพราดพร้อมกัน |
| **#hf-188 Oscilloscope Trace (หรือ Soundwave Component)** | แสดงเส้นคลื่นเสียง (Audio Waveform) ขยับตามจังหวะพูด | B01, B05 | ช่วยให้เห็นว่าแอปกำลัง "ฟังเสียง" (ใน B01) และ "เปล่งเสียง" (ใน B05) ชัดเจนโดยไม่ต้องพึ่งคำอธิบายยาว |
| **#hf-122 Code Snippet - Dark Modern** | แสดงบล็อกคำสั่ง cURL และ JSON Request / Parameter สำคัญ | B03, B04, B05 | ใช้แสดงกล่อง Request สั้นๆ เช่น `POST /voice/transcribe` และ `"input_mode": "voice"` ไม่แสดงโค้ดทั้งไฟล์ |
| **#hf-072 Marker Highlight** | ไฮไลต์เน้นคำหรือพารามิเตอร์สำคัญ | B04, B06 | ใช้ป้ายสีเขียวเน้นคำว่า `"input_mode": "voice"` และ Scope `voice:invoke` เพื่อดึงสายตาคนดู |

## 3. สิ่งที่ต้องทดสอบใน Sample (W5)

* **ความเข้ากันได้ของ Oscilloscope Trace กับภาพพื้นหลัง**: ต้องทดสอบว่าคลื่นเสียงแสดงบนพื้นหลังกระดาษสีสว่าง (#F5F1E7) แล้วเส้นคมชัดและอ่านง่ายหรือไม่
