# EP04 B03–B05 — บทสำหรับสร้างเสียง

อ่านต่อเนื่องเป็นย่อหน้าเดียวต่อ beat แล้วบันทึกเป็นไฟล์ตาม path ที่ระบุ จากนั้นรัน `node build.mjs`

## b03 → assets/voice/b03.wav
สเต็ปแรกคือการฟัง ผู้ใช้กดไมค์แล้วพูดว่า ขอสั่งอเมริกาโน่เย็นหนึ่งแก้วครับ ระบบหลังบ้านของแอป ส่งไฟล์เสียงขนาดไม่เกินสี่เมกะไบต์ ไปที่ Voice Transcribe ของ LangMind แล้วได้ข้อความที่ถอดจากเสียงกลับมา

## b04 → assets/voice/b04.wav
สเต็ปที่สองคือการคิด ส่งข้อความนี้เข้า Chat API ของ Agent พร้อมระบุ input mode เป็น voice Agent ที่ใส่ข้อมูลเมนูร้านไว้ จะตอบสั้น กระชับ เป็นภาษาพูด และส่ง conversation ID กลับมา ไว้ใช้คุยต่อในรอบถัดไป

## b05 → assets/voice/b05.wav
สเต็ปสุดท้ายคือการพูด ส่งคำตอบเข้า Voice Speech ของ LangMind จะได้ไฟล์เสียงกลับมา เป็น MP3 หรือ WAV ตามที่ตั้งค่าไว้ แล้วแอปก็เปิดเสียงนั้นให้ผู้ใช้ฟัง
