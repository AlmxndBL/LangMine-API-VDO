# EP14 Errors / Rate Limit & Quota — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` (สร้างเสียงทีละประโยคจาก timing.json) แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
ระบบหลังบ้านของร้าน เรียก API ของ LangMind ทุกวัน แต่วันหนึ่ง หน้ากล่องแชทก็ขึ้นว่า เกิดข้อผิดพลาด ทีมไม่รู้ว่าพังเพราะอะไร ต้องแก้ตรงไหน หรือแค่รอแล้วลองใหม่ มาดูกันครับ ว่า error ของ LangMind หน้าตาแบบไหน แต่ละรหัสแปลว่าอะไร และระบบควรรับมือยังไง

## b2 → assets/voice/b2.wav
ทุก error ของ LangMind หน้าตาเดียวกัน เป็น JSON ที่มี status เป็น error code บอกว่าเป็นกรณีไหน ส่วน message กับ message en คือข้อความภาษาไทย และภาษาอังกฤษ และ request id ประจำคำขอนั้น คู่มือแนะนำให้เช็กที่ code เพื่อจัดการแต่ละกรณี ไม่ต้องไปแกะข้อความ

## b3 → assets/voice/b3.wav
รหัสแรก 401 UNAUTHORIZED แปลว่า API Key ขาด หมดอายุ หรือถูกเพิกถอน หรือไปเรียก endpoint ที่ปิดไว้สำหรับ API Key เช่น การจัดการ API Key หรือการตอบลูกค้าใน Inbox ซึ่งต้องเข้าสู่ระบบผ่านเว็บเท่านั้น ทางแก้ เช็กว่าส่ง Authorization Bearer ถูกต้อง ถ้า Key หมดอายุหรือถูกเพิกถอน ให้สร้าง Key ใหม่ในหน้า Personal API Key

## b4 → assets/voice/b4.wav
403 FORBIDDEN แปลว่า Key ไม่มี scope ที่ endpoint นี้ต้องการ หรือ role ไม่พอ เช่น Key ที่มีแค่ chat invoke แต่ไปเรียกรายการแชทใน Inbox ซึ่งต้องใช้ inbox read ทางแก้ ใช้ Key ที่มี scope ตรงกับ endpoint และให้ scope เท่าที่จำเป็นเท่านั้น

## b5 → assets/voice/b5.wav
404 NOT FOUND แปลว่าไม่พบสิ่งที่ขอ หรือสิ่งนั้นเป็นของบัญชีอื่น 422 VALIDATION ERROR แปลว่า body หรือ query ไม่ผ่านการตรวจรูปแบบ เช่น ขาดช่องที่บังคับ ทั้งสองแบบ ส่งซ้ำแบบเดิมก็ได้ผลเหมือนเดิม ต้องแก้คำขอก่อน

## b6 → assets/voice/b6.wav
429 RATE LIMIT EXCEEDED แปลว่าเรียกถี่เกินลิมิต รับมือด้วยการรอสักพักแล้วลองใหม่ และเว้นให้นานขึ้นทุกครั้งที่ยังเจอ คู่มือไม่ได้บอกว่าต้องรอนานเท่าไร แต่ 429 ไม่ได้มีแบบเดียว VOICE QUOTA EXCEEDED คือโควตาเสียงไม่พอ ต้องดูยอดคงเหลือ ไม่ใช่แค่รอ

## b7 → assets/voice/b7.wav
ฝั่ง Voice API มี code เฉพาะ VOICE DISABLED คือ agent ยังไม่เปิดสนทนาด้วยเสียง ในเวอร์ชันที่เผยแพร่ และ VOICE NOT IN PLAN คือแพ็กเกจของเจ้าของ agent ไม่รวมงานเสียง NO CREDENTIAL คือยังไม่ได้ตั้ง API key ให้โมเดลของ agent และ VOICE AUDIO FORMAT UNSUPPORTED คืออ่านไฟล์เสียงไม่ได้ ให้แปลงเป็น WAV แล้วส่งใหม่ ส่วน VOICE QUOTA EXCEEDED ถอดเสียงนับเป็นนาที อ่านออกเสียงนับเป็นตัวอักษร ดูยอดคงเหลือได้ที่ me voice quota

## b8 → assets/voice/b8.wav
สรุปเป็นวิธีคิดง่าย ๆ กลุ่มแรก รอแล้วลองใหม่ได้ คือ RATE LIMIT EXCEEDED กลุ่มที่สอง ต้องแก้คำขอก่อน คือ 401 403 404 422 และไฟล์เสียงผิดรูปแบบ กลุ่มที่สาม ต้องไปตั้งค่าในเว็บ หรือดูแพ็กเกจ คือ voice disabled, no credential, voice not in plan และโควตาเสียง

## b9 → assets/voice/b9.wav
เอาไปใช้ในระบบหลังบ้าน ทุกครั้งที่เจอ error ให้บันทึก HTTP status, code และ request id ไว้ใน log error ที่ลองใหม่ได้ ให้ระบบลองใหม่เอง ที่เหลือแจ้งทีม พร้อมบอกว่าต้องแก้อะไร หน้าจอของทีม ก็ขึ้นข้อความที่บอกทางแก้ แทนคำว่า เกิดข้อผิดพลาด เฉย ๆ

## b10 → assets/voice/b10.wav
เรื่องโควตา การเรียกผ่าน API Key นับรวมกับโควตาบัญชีเดียวกับตอนใช้งานผ่านเว็บ ทั้งโควตาโทเค็นของ LLM และ rate limit ของการสนทนา คิดจากผู้ใช้คนเดียวกัน เช็กโควตาที่เหลือได้จากหน้า Credentials ส่วน Voice API มีลิมิตของตัวเอง ค่าเริ่มต้นคือ ถอดเสียง 60 ครั้งต่อนาที อ่านออกเสียง 300 ครั้งต่อนาที และข้อความที่ถอดแล้วส่งเข้า chat ยังนับโควตา chat ตามปกติ

## b11 → assets/voice/b11.wav
ป้องกันไว้ก่อน ให้ scope น้อยที่สุดเท่าที่จำเป็น และแยก API Key ตามการใช้งาน จะได้เพิกถอนทีละอันได้ ตั้งวันหมดอายุถ้าทำได้ และอย่า commit Key ลง repo ใช้ environment variable หรือ secret manager แทน ถ้าสงสัยว่า Key หลุด เพิกถอนทันที มีผลในคำขอถัดไปเลย และ API Key สร้างหรือลบ Key อื่นแทนตัวเองไม่ได้

## b12 → assets/voice/b12.wav
สรุปครับ อ่าน error จาก code ไม่ใช่จากข้อความ และเก็บ request id ไว้ รับมือตามกลุ่ม รอแล้วลองใหม่ แก้คำขอ หรือไปตั้งค่าในเว็บ และป้องกันด้วย scope ที่น้อยที่สุด แยก Key และไม่ commit Key ลง repo

## b13 → assets/voice/b13.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มเชื่อม API ได้ที่ LangMind ดอท อิน ดอท ทีเอช
