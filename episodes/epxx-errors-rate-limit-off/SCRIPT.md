## 2. ข้อมูลตัวอย่างสำหรับหน้าจอและ JSON

* **ค่าจากตัวอย่างในคู่มือ**: error envelope `FORBIDDEN` / “คุณไม่มีสิทธิ์เข้าถึงข้อมูลนี้” / `request_id: "01J8XK2..."` (บรรทัด 1307–1313) · `message_en` ตัดเหลือ “You do not have permission…”
* **ตัวอย่างประกอบ (illustrative)**: Key ที่มีแค่ `chat:invoke` แล้วเรียก Inbox → 403 · เวลารอ 1 / 2 / 4 วินาที · ตัวอย่าง 401 จาก `/inbox/reply`
* **ข้อมูลในภาพหน้าจอ**: ร้านกาแฟสมมติ, เวลา, request_id ที่ตัดท้าย, รายการ 4 แถวในหน้าบันทึก error — ข้อมูลจำลองทั้งหมด · ทุกภาพติดป้าย “ภาพจำลอง”
