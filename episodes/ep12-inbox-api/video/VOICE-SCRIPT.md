# EP12 Inbox API — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` (สร้างเสียงทีละประโยคจาก timing.json) แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
ลูกค้าทักร้านทาง LINE ทุกวัน และ AI ของร้าน ก็ช่วยตอบให้แล้ว แต่ทีมหน้าร้านอยากเห็นแชททั้งหมด ในระบบหลังบ้านของร้านเอง ถ้าอยากทำหน้ากล่องแชทแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
แชทจาก LINE ที่ Agent ตอบ จะถูกเก็บไว้ในกล่องแชทของ Agent ใน LangMind Inbox API คือช่องทางให้ระบบหลังบ้านของคุณ ดึงแชทเหล่านั้นมาอ่าน แล้วเอาไปแสดงเป็นหน้ากล่องแชทของร้าน

## b3 → assets/voice/b3.wav
สิ่งที่ต้องเตรียม อย่างแรกคือ Agent ที่ต่อกับ LINE ไว้แล้ว และมีแชทจากลูกค้า อย่างที่สอง API Key ที่มีสิทธิ์ inbox read อย่างที่สาม ระบบหลังบ้านของร้าน ไว้เก็บ Key และเป็นคนเรียก API

## b4 → assets/voice/b4.wav
มาดูการเชื่อม ครั้งที่หนึ่ง ดึงรายการแชท เลือกช่องทาง LINE หน้าละยี่สิบห้ารายการ ได้รายการแชท พร้อมชื่อลูกค้า และจำนวนข้อความ ส่วน channel counts นับแชททุกช่องทางให้แล้ว เอาไปทำแท็บได้เลย ถ้าจะค้นหา ใส่คำที่ต้องการใน search เช่น อเมริกาโน่

## b5 → assets/voice/b5.wav
ครั้งที่สอง เปิดแชทหนึ่งรายการ แล้วดึงข้อความในแชทนั้น ได้ข้อความเรียงกัน บอกว่าใครพูด ลูกค้าหรือ AI พร้อมเวลา ถ้า next cursor ไม่ว่าง แปลว่ายังมีข้อความเก่าอีก ส่งค่านี้กลับไปใน cursor เพื่อดึงหน้าถัดไป

## b6 → assets/voice/b6.wav
ครั้งที่สาม เช็กว่าแชทนี้ มีแอดมินคุมสายอยู่หรือไม่ ถ้า active เป็น true แปลว่าแอดมินคุมอยู่ AI จะไม่ตอบ จนกว่าจะหมดเวลาหรือถูกจบ ถ้า active เป็น false แปลว่าไม่มีใครคุม AI ตอบตามปกติ

## b7 → assets/voice/b7.wav
ครั้งที่สี่ export ประวัติแชทเป็นไฟล์ xlsx หรือ csv เลือกช่องทาง และช่วงวันที่ได้ ได้ไฟล์กลับมาตรง ๆ ไม่ใช่ JSON ถ้าไม่ระบุวันที่ จะดึงทั้งหมด สูงสุดสองหมื่นแถวต่อครั้ง

## b8 → assets/voice/b8.wav
เอาผลไปทำหน้ากล่องแชท รายชื่อแชทพร้อมแท็บ นับตามช่องทาง ถ้าข้อความล่าสุดเป็นของลูกค้า ติดป้ายว่าลูกค้ารอตอบ เปิดแชทเพื่ออ่านย้อนหลัง และแสดงป้าย เมื่อแอดมินคุมสายอยู่ และปุ่มดาวน์โหลดประวัติ ก็เรียก export ที่ระบบหลังบ้าน

## b9 → assets/voice/b9.wav
สิ่งที่ต้องรู้ คือ API Key ใช้ได้แค่อ่านข้อมูล การตอบลูกค้า และการเริ่มหรือจบการคุมสาย ต้องเข้าสู่ระบบผ่านเว็บ LangMind เพราะมีผลกับสิ่งที่ลูกค้าเห็นจริง

## b10 → assets/voice/b10.wav
สรุปครับ เตรียม Agent ที่ต่อ LINE, API Key สิทธิ์ inbox read และระบบหลังบ้าน เชื่อมสี่แบบ รายการแชท ข้อความ สถานะคุมสาย และ export แล้วเอาไปทำหน้ากล่องแชทของร้าน ส่วนการตอบลูกค้า ทำในเว็บ LangMind

## b11 → assets/voice/b11.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้าง Agent ที่ต่อ LINE ได้ ที่ LangMind ดอท อิน ดอท ทีเอช
