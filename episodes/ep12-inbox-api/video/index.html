2เชื่อมครั้งที่ 1 · รายการแชท

หลังบ้านร้าน 1 · รายการแชท กล่องแชท
ขอรายการแชท LINE · หน้า 1 · 25 รายการ
GETสิทธิ์ inbox:read
/api/agents/{id}/inbox/threads
?channel=line&page=1&limit=25
&search=อเมริกาโน่
Authorization: Bearer $LM_TOKEN
คืน total และ channel_counts เสมอ
{ "items": [ { "display_name": "คุณสมชาย",
  "channel": "line", "message_count": 6,
  "last_message_role": "user" }, … ], "total": 12,
  "channel_counts": { "line": 12, "web": 3 } }
channel_counts นับทุก thread ของ agent ไม่ใช่แค่หน้านี้ · ข้อมูลตัวอย่าง

2เชื่อมครั้งที่ 2 · ข้อความในแชท

หลังบ้านร้าน 2 · ข้อความ กล่องแชท
เปิดแชทของคุณสมชาย (cid)
GETสิทธิ์ inbox:read
/api/agents/{id}/inbox/threads/{cid}
/messages
?limit=50
หน้าถัดไป: ?cursor=01J8XL…&limit=50
Authorization: Bearer $LM_TOKEN
แต่ละข้อความมี created_at บอกเวลา
{ "items": [
  { "role": "user", "content": "ร้านเปิดกี่โมง" },
  { "role": "assistant", "content": "เปิด 9 โมงถึง 5 โมงค่ะ" } ],
  "next_cursor": "01J8XL…" }
ข้อมูลตัวอย่าง (ภาพจำลอง)

2เชื่อมครั้งที่ 3 · สถานะคุมสาย

หลังบ้านร้าน 3 · คุมสาย กล่องแชท
แชทนี้มีแอดมินคุมอยู่ไหม?
GETสิทธิ์ inbox:read
/api/agents/{id}/inbox/threads/{cid}
/handover
Authorization: Bearer $LM_TOKEN
เช็กได้ทีละแชท
{ "active": true, "expires_in_sec": 1420 }
แอดมินคุมอยู่ · AI หยุดตอบ (อีกราว 23 นาที)
{ "active": false, "expires_in_sec": null }
ไม่มีใครคุม · AI ตอบตามปกติ

2เชื่อมครั้งที่ 4 · export

หลังบ้านร้าน 4 · export กล่องแชท
ดาวน์โหลดประวัติแชท LINE · 1–7 พ.ย.
GETสิทธิ์ inbox:read
/api/agents/{id}/inbox/export
?format=xlsx&channel=line
&date_from=2026-11-01&date_to=2026-11-07
Authorization: Bearer $LM_TOKEN
format = xlsx | csv · ไม่ระบุวันที่ = ดึงทั้งหมด
inbox-export.xlsxไฟล์ตรง ๆ (Content-Disposition: attachment) ไม่ใช่ JSONสูงสุด 20,000 แถวต่อครั้ง

3ใช้ผลหน้ากล่องแชทของร้าน

channel_countsแท็บนับตามช่องทาง
display_nameชื่อลูกค้า (LINE)
message_countจำนวนข้อความ
last_message_role = "user"ติดป้าย “ลูกค้ารอตอบ”
items[].role · contentข้อความ ใครพูด
created_atเวลาของแต่ละข้อความ
handover.activeป้าย “แอดมินคุมสายอยู่”
inbox/exportปุ่ม ⬇ xlsx ดาวน์โหลดประวัติ
searchช่องค้นหาชื่อหรือข้อความ

ครั้งที่ 1: ดึงรายการแชท
ช่องทาง LINE หน้าละ 25 รายการ
ได้รายการแชท พร้อมชื่อลูกค้าและจำนวนข้อความ
channel_counts นับทุกช่องทาง เอาไปทำแท็บได้เลย
อยากค้นหา ใส่คำใน search
เช่น search=อเมริกาโน่
ครั้งที่ 2: เปิดแชทหนึ่งรายการ
แล้วดึงข้อความในแชทนั้น
ได้ข้อความเรียงกัน บอกว่าใครพูด
ลูกค้าหรือ AI พร้อมเวลา
next_cursor ไม่ว่าง = ยังมีข้อความเก่า
ส่งค่านี้ไปใน ?cursor= เพื่อดึงหน้าถัดไป
ครั้งที่ 3: เช็กว่าแชทนี้
มีแอดมินคุมสายอยู่หรือไม่
active = true แปลว่าแอดมินคุมอยู่
AI จะไม่ตอบจนกว่าจะหมดเวลาหรือถูกจบ
active = false แปลว่าไม่มีใครคุม
AI ตอบตามปกติ
ครั้งที่ 4: export ประวัติแชท เป็น xlsx หรือ csv
เลือกช่องทางและช่วงวันที่ได้
ได้ไฟล์กลับมาตรง ๆ ไม่ใช่ JSON
ไม่ระบุวันที่ = ดึงทั้งหมด (สูงสุด 20,000 แถว)
เอาผลไปทำหน้ากล่องแชท
รายชื่อแชท พร้อมแท็บนับตามช่องทาง
ถ้าข้อความล่าสุดเป็นของลูกค้า
ติดป้ายว่าลูกค้ารอตอบ
เปิดแชทเพื่ออ่านย้อนหลัง
และแสดงป้ายเมื่อแอดมินคุมสายอยู่
ปุ่มดาวน์โหลดประวัติ
เรียก export ที่ระบบหลังบ้าน
