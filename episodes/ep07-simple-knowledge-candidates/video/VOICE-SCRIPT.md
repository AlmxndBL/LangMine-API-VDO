# EP07 — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
เวลาทำแชทบอทร้านค้า เรื่องแรกคือคำถามพื้นฐานอย่างร้านเปิดกี่โมง ที่อยากให้ตอบเป๊ะทันทีโดยไม่ต้องเปลืองโควตา AI เรื่องที่สองคือคำถามใหม่ๆ จากลูกค้า ที่อยากคัดกรองก่อนเติมเข้าคลังความรู้ ถ้าอยากทำทั้งสองอย่างนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ภาพรวมแบ่งเป็นสองด่าน ด่านหน้าคือ Simple Knowledge กฎคำถามคำตอบแบบ Keyword ที่ตอบทันทีก่อนถึง RAGFlow และ LLM ส่วนด่านพัฒนาคือ Knowledge Candidates ที่พักคำถามคำตอบไว้ให้ตรวจอนุมัติก่อนส่งเข้า Dataset จริง โดยระบบหลังบ้านจะเชื่อม API สามจุดหลัก คือ ตั้งกฎคำตอบด่วน ตรวจอนุมัติ และดันเข้าคลังความรู้

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือรหัส Agent ID และรหัส Dataset ID ปลายทางที่ต้องการเติมข้อมูล อย่างที่สองคือ API Key ที่มีสิทธิ์ knowledge write และ knowledge read อย่างที่สามคือระบบหลังบ้านของแอป สำหรับเก็บ Key และให้แอดมินจัดการข้อมูลผ่านหน้าจอของเราเอง

## b4 → assets/voice/b4.wav
มาดูการเชื่อมครั้งที่หนึ่ง การตั้งกฎคำตอบด่วน ส่งคำขอ POST ไปที่ simple knowledge โดยใส่ agent ID ไว้ใน body พร้อมระบุ keyword เช่น เวลาทำการ คำตอบคือ เปิดเก้าโมงถึงห้าโมง และเลือก match type เป็น exact เพียงเท่านี้ เมื่อลูกค้าถามตรงคำ ระบบจะตอบกลับทันทีโดยไม่เรียก LLM ครับ

## b5 → assets/voice/b5.wav
ครั้งที่สอง การตรวจอนุมัติคำถามที่รออยู่ จากข้อความแชท หรือสร้างเข้ามาใน Knowledge Candidates ส่ง POST ไปที่ knowledge candidates review พร้อมระบุ agent ID รายการ ID ที่เลือก และใส่ action เป็น approve เพื่ออนุมัติคำถามคำตอบที่ตรวจสอบความถูกต้องแล้ว ให้พร้อมส่งเข้าคลัง

## b6 → assets/voice/b6.wav
ครั้งที่สาม การดันคำถามเข้าคลังความรู้จริง ส่งคำขอ POST ไปที่ knowledge candidates ตามด้วย agent ID และ promote โดยระบุรายการ ID และ dataset ID ปลายทาง ระบบจะนำเฉพาะรายการที่อนุมัติแล้ว ส่งเข้า Dataset ทันที และคืนรายการที่สำเร็จในชื่อ promoted พร้อมรหัส export batch ID กลับมาครับ

## b7 → assets/voice/b7.wav
ผลที่ได้ช่วยให้จัดการความรู้อย่างมีระบบ ในฝั่ง Simple Knowledge เลือก match type ได้สามแบบคือ exact, contains และ pattern โดยถ้าใช้ pattern ต้องมีตัวแปรในปีกกา ไม่อย่างนั้นจะได้รหัสสี่สองสอง และถ้าตั้ง keyword ซ้ำจะได้รหัสสี่ศูนย์เก้า ส่วนฝั่ง Promote หากส่งรายการที่ยังไม่อนุมัติไปด้วย ระบบจะแยกไปไว้ใน skipped ให้อัตโนมัติ ไม่ปนเข้าคลังจริงครับ

## b8 → assets/voice/b8.wav
สรุปครับ เตรียม Agent ID, Dataset ID และ API Key สิทธิ์ knowledge write และ read เชื่อมสามจุด คือเพิ่มกฎด่วนที่ simple knowledge ตรวจอนุมัติที่ review และดันเข้าคลังที่ promote ช่วยให้แชทบอทตอบคำถามพื้นฐานได้ไว และฉลาดขึ้นจากคำถามจริงอย่างปลอดภัยครับ

## b9 → assets/voice/b9.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้างและดูแลคลังความรู้ให้ Agent ของคุณได้ที่ LangMind ดอท อิน ดอท ทีเอช
