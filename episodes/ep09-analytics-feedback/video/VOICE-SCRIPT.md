# EP09 — บทสำหรับสร้างเสียง

## b1 → assets/voice/b1.wav
พอเราปล่อยแชท AI ขึ้นใช้งานจริง คำถามสำคัญที่ตามมาคือ มีลูกค้าเข้ามาใช้กี่คน ใช้โทเค็นและเสียค่าใช้จ่ายไปเท่าไหร่ และคำตอบไหนที่ลูกค้าชอบหรือไม่ชอบ ถ้าอยากทำระบบวัดผลแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ภาพรวมของฟีเจอร์นี้เชื่อมระหว่างหน้าแชท ระบบหลังบ้านของคุณ และ LangMind ผ่านสามจังหวะสำคัญ คือหนึ่ง ส่งรหัสผู้ใช้ตอนเรียกแชทเพื่อนับจำนวนคน สอง ส่งคะแนนถูกใจหรือไม่ถูกใจเมื่อลูกค้ากดประเมิน และสาม ดึงข้อมูลสถิติกลับมาแสดงบน Dashboard ครับ

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือรหัสผู้ใช้ปลายทาง user ID และรหัสข้อความ message ID ที่ได้ตอนคุยกับ Agent อย่างที่สองคือ API Key ที่มีสิทธิ์สองตัว ได้แก่ chat invoke สำหรับส่งแชทและคะแนนประเมิน และ analytics read สำหรับอ่านข้อมูลสถิติ อย่างที่สามคือระบบหลังบ้านสำหรับเก็บ Key ครับ

## b4 → assets/voice/b4.wav
มาดูการเชื่อมครั้งที่หนึ่ง การส่ง user ID ตอนเรียกแชท เวลาส่งข้อความเข้า chat message ถ้าเราไม่ส่ง user ID ทุกคำขอจะถูกนับเป็นผู้ใช้คนเดียวคือเจ้าของ API Key ดังนั้นให้ส่ง user ID ของผู้ใช้ปลายทางไปด้วย สถิติจึงจะนับจำนวนผู้ใช้แยกคนได้ตามจริง โดยต้องจำไว้ว่าถ้าส่ง conversation ID เป็น null พร้อมกับ user ID ระบบอาจคุยต่อในเธรดที่ยังเปิดอยู่ของผู้ใช้คนนั้นครับ

## b5 → assets/voice/b5.wav
ครั้งที่สอง การเก็บคะแนนคำตอบ เมื่อลูกค้ากดปุ่มถูกใจหรือไม่ถูกใจใต้ข้อความ ให้ส่ง POST ไปที่ chat messages ตามด้วย message ID และ feedback โดยส่งค่า rating ซึ่งรับเฉพาะค่าหนึ่งสำหรับถูกใจ หรือลบหนึ่งสำหรับไม่ถูกใจ ไม่ใช่สเกลหนึ่งถึงห้า พร้อมใส่ข้อความ comment เพิ่มเติมได้ ระบบจะตอบกลับรหัสสองศูนย์สี่ครับ

## b6 → assets/voice/b6.wav
ครั้งที่สาม การดึงสถิติและค่าใช้จ่าย เรียก GET ไปที่ analytics agents พร้อมระบุช่วงวันที่ from และ to เพื่อดูภาพรวมของทุก Agent หรือระบุรหัส Agent ต่อท้ายเพื่อดูรายละเอียดเชิงลึก ระบบจะคืนทั้งสรุปภาพรวม ข้อมูลรายวัน แยกตามโมเดล แยกตามช่องทางอย่างเว็บหรือ LINE และแยกตามเครื่องมือ tool ที่เรียกใช้ครับ

## b7 → assets/voice/b7.wav
ผลที่ได้นำมาสร้างหน้า Dashboard ของเราเองได้ครบถ้วน ทั้งดูจำนวนบทสนทนา ผู้ใช้ที่ active จำนวนโทเค็นรวม ค่าใช้จ่ายเป็นดอลลาร์ อัตราสำเร็จของโมเดล และจำนวนคะแนนบวกและลบ ช่วยให้เราคุมงบประมาณและรู้ทันทีว่าวันไหนมีข้อผิดพลาดหรือมีคำตอบที่ต้องเข้าไปปรับปรุงครับ

## b8 → assets/voice/b8.wav
สรุปครับ เตรียมรหัสผู้ใช้และ API Key สองสิทธิ์ เชื่อมสามจังหวะ คือส่ง user ID ตอนแชท ส่งคะแนนที่ feedback และดึงสถิติที่ analytics เพียงเท่านี้คุณก็ดูแลทั้งคุณภาพคำตอบและต้นทุนของ AI ได้อย่างมั่นใจแล้วครับ

## b9 → assets/voice/b9.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้างและติดตามผลการทำงานของ Agent ได้ที่ LangMind ดอท อิน ดอท ทีเอช
