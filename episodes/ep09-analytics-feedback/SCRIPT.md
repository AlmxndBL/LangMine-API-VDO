# EP09 — บทร่างภาษาพูด 9 Beats (Analytics & Feedback API)

ผู้ชม: Developer และเจ้าของผลิตภัณฑ์ที่ต้องการวัดผลการใช้งาน AI คุมงบประมาณ และเก็บคะแนนความพึงพอใจ  
โครงสร้าง: 9 Beats (`b1–b9`) ตามแนวทาง EP04 v3 (เตรียม → เชื่อม 3 ครั้ง → ใช้ผล + ผู้สนับสนุน)  
ภาษา: ไทย โทนสนทนา กระชับ แยกบทพูด (`say`) ซับไตเติล (`cap`) และข้อความเน้นบนจอชัดเจน

---

## 1. บทเต็มและจุดแบ่งจังหวะ (Full Script & Beats)

| Beat | บทบรรยายภาษาพูด (`say`) | ข้อความเน้นบนจอ (แยกจากซับ) |
|---|---|---|
| **b1** | พอเราปล่อยแชท AI ขึ้นใช้งานจริง คำถามสำคัญที่ตามมาคือ มีลูกค้าเข้ามาใช้กี่คน ใช้โทเค็นและเสียค่าใช้จ่ายไปเท่าไหร่ และคำตอบไหนที่ลูกค้าชอบหรือไม่ชอบ ถ้าอยากทำระบบวัดผลแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ | วัดผลแชท AI คุมงบ Token & เก็บ Feedback |
| **b2** | ภาพรวมของฟีเจอร์นี้เชื่อมระหว่างหน้าแชท ระบบหลังบ้านของคุณ และ LangMind ผ่านสามจังหวะสำคัญ คือหนึ่ง ส่งรหัสผู้ใช้ตอนเรียกแชทเพื่อนับจำนวนคน สอง ส่งคะแนนถูกใจหรือไม่ถูกใจเมื่อลูกค้ากดประเมิน และสาม ดึงข้อมูลสถิติกลับมาแสดงบน Dashboard ครับ | ส่ง `user_id` → เก็บ `feedback` → ดึง `analytics` |
| **b3** | เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือรหัสผู้ใช้ปลายทาง user ID และรหัสข้อความ message ID ที่ได้ตอนคุยกับ Agent อย่างที่สองคือ API Key ที่มีสิทธิ์สองตัว ได้แก่ chat invoke สำหรับส่งแชทและคะแนนประเมิน และ analytics read สำหรับอ่านข้อมูลสถิติ อย่างที่สามคือระบบหลังบ้านสำหรับเก็บ Key ครับ | สิ่งที่ต้องเตรียม:<br>1. `user_id` + `message_id`<br>2. สิทธิ์ `chat:invoke` & `analytics:read`<br>3. ระบบหลังบ้านเก็บ Key |
| **b4** | มาดูการเชื่อมครั้งที่หนึ่ง การส่ง user ID ตอนเรียกแชท เวลาส่งข้อความเข้า chat message ถ้าเราไม่ส่ง user ID ทุกคำขอจะถูกนับเป็นผู้ใช้คนเดียวคือเจ้าของ API Key ดังนั้นให้ส่ง user ID ของผู้ใช้ปลายทางไปด้วย สถิติจึงจะนับจำนวนผู้ใช้แยกคนได้ตามจริง โดยต้องจำไว้ว่าถ้าส่ง conversation ID เป็น null พร้อมกับ user ID ระบบอาจคุยต่อในเธรดที่ยังเปิดอยู่ของผู้ใช้คนนั้นครับ | ครั้งที่ 1: ส่ง `user_id` ตอนเรียกแชท<br>นับจำนวนผู้ใช้แยกคนตามจริง (ไม่ส่ง = นับเป็นเจ้าของ Key คนเดียว) |
| **b5** | ครั้งที่สอง การเก็บคะแนนคำตอบ เมื่อลูกค้ากดปุ่มถูกใจหรือไม่ถูกใจใต้ข้อความ ให้ส่ง POST ไปที่ chat messages ตามด้วย message ID และ feedback โดยส่งค่า rating ซึ่งรับเฉพาะค่าหนึ่งสำหรับถูกใจ หรือลบหนึ่งสำหรับไม่ถูกใจ ไม่ใช่สเกลหนึ่งถึงห้า พร้อมใส่ข้อความ comment เพิ่มเติมได้ ระบบจะตอบกลับรหัสสองศูนย์สี่ครับ | ครั้งที่ 2: เก็บคะแนนคำตอบ<br>`POST /api/chat/messages/{id}/feedback`<br>`rating: 1` หรือ `-1` เท่านั้น → `204` |
| **b6** | ครั้งที่สาม การดึงสถิติและค่าใช้จ่าย เรียก GET ไปที่ analytics agents พร้อมระบุช่วงวันที่ from และ to เพื่อดูภาพรวมของทุก Agent หรือระบุรหัส Agent ต่อท้ายเพื่อดูรายละเอียดเชิงลึก ระบบจะคืนทั้งสรุปภาพรวม ข้อมูลรายวัน แยกตามโมเดล แยกตามช่องทางอย่างเว็บหรือ LINE และแยกตามเครื่องมือ tool ที่เรียกใช้ครับ | ครั้งที่ 3: ดึงสถิติและต้นทุน<br>`GET /api/analytics/agents` & `/analytics/agents/{id}`<br>คืน `summary`, `daily`, `models`, `channels`, `tools` |
| **b7** | ผลที่ได้นำมาสร้างหน้า Dashboard ของเราเองได้ครบถ้วน ทั้งดูจำนวนบทสนทนา ผู้ใช้ที่ active จำนวนโทเค็นรวม ค่าใช้จ่ายเป็นดอลลาร์ อัตราสำเร็จของโมเดล และจำนวนคะแนนบวกและลบ ช่วยให้เราคุมงบประมาณและรู้ทันทีว่าวันไหนมีข้อผิดพลาดหรือมีคำตอบที่ต้องเข้าไปปรับปรุงครับ | ข้อมูลสำคัญที่ได้:<br>`conversation_count` · `active_user_count` · `total_tokens`<br>`cost_usd` · `llm_success_rate` · `feedback_positive / negative` |
| **b8** | สรุปครับ เตรียมรหัสผู้ใช้และ API Key สองสิทธิ์ เชื่อมสามจังหวะ คือส่ง user ID ตอนแชท ส่งคะแนนที่ feedback และดึงสถิติที่ analytics เพียงเท่านี้คุณก็ดูแลทั้งคุณภาพคำตอบและต้นทุนของ AI ได้อย่างมั่นใจแล้วครับ | สรุป: เตรียม → เชื่อม (`user_id` · `feedback` · `analytics`) → ใช้ผลคุมงบ |
| **b9** | คลิปนี้สนับสนุนโดย LangMind เริ่มสร้างและติดตามผลการทำงานของ Agent ได้ที่ LangMind ดอท อิน ดอท ทีเอช | สนับสนุนโดย LangMind · `langmind.in.th` |

## 2. ข้อมูลตัวอย่างสำหรับหน้าจอและโค้ด (`illustrative` จากค่าตัวอย่างในคู่มือ)

* **หน้าจอแชท (`APP-CHAT-FEEDBACK`)**:
  * คำตอบ Agent: `"สินค้า A ราคา 590 บาทค่ะ"`
  * ปุ่มประเมิน: กด 👍 (`rating: 1`, `comment: "ตอบตรงประเด็นดี"`)
* **หน้าจอ Dashboard (`APP-ANALYTICS-DASHBOARD`)**:
  * ใช้ตัวเลขตัวอย่างตามที่มีในคู่มือ [langmind-api.md](../../langmind-api.md) บรรทัด 1190–1205 พร้อมติดป้าย `"ภาพจำลอง (ตัวเลขตัวอย่าง)"`:
    * ชื่อ Agent: `"ผู้ช่วยฝ่ายขาย"` (`range`: `2026-08-01` ถึง `2026-08-18`)
    * `conversation_count`: `42` · `active_user_count`: `30`
    * `total_tokens`: `50,400` · `cost_usd`: `"$1.2600"`
    * `feedback_positive`: `18` · `feedback_negative`: `1`
