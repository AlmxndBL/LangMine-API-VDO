# EP09 — ทะเบียนคัดเลือก Catalog (Analytics & Feedback API)

อ้างอิง: [CATALOG_USAGE_MAP](../../docs/CATALOG_USAGE_MAP.md), [PLAN](PLAN.md), และ [Workflow](../../docs/WORKFLOW.md)  
สถานะ: แผนการเลือกบล็อก Motion สำหรับ W4 ก่อนสร้าง Sample ใน W5

---

## 1. เกณฑ์การคัดเลือกตามหน้าที่ของซีน

ในคลิป EP09 มี 3 หน้าที่หลักที่ต้องการแอนิเมชันช่วยอธิบาย:
1. **แสดงหน้าจอแชทที่กดให้คะแนนและหน้าจอ Dashboard สรุปผล (Device Hosting)**: ให้เห็นจากมุมผู้ใช้ที่กด 👍 ไปจนถึงมุมผู้ดูแลที่เห็นกราฟสรุป
2. **แสดงตัวเลขสถิติและกราฟ (Data & Stat Cards)**: ให้เห็นจำนวนบทสนทนา โทเค็น ค่าใช้จ่าย และการแยกตามช่องทาง (`web` vs `line`)
3. **เน้นเงื่อนไขสำคัญของ API (Code & Parameter Highlight)**: ให้เห็น `user_id`, `rating: 1 / -1` และโครงสร้าง response ของ `/analytics/agents/{id}`

## 2. รายการ Catalog ที่เลือกใช้ตามหน้าที่

| รหัส / ชื่อ Catalog | หน้าที่ในซีน | Beat ที่ใช้ | เหตุผลและข้อจำกัด |
|---|---|---|---|
| **#hf-195 Browser Device Stage** | ครอบภาพหน้าจอจำลอง `APP-CHAT-FEEDBACK` และ `APP-ANALYTICS-DASHBOARD` | b1, b5, b6 | ใช้ host ภาพ raster หน้าแชทและหน้า Dashboard อย่างคมชัด |
| **#hf-428 Count-Up Stat Card** | แสดงการ์ดตัวเลขสรุป (`42 บทสนทนา`, `50,400 โทเค็น`, `$1.2600`) | b6, b7 | ดึงสายตาให้เห็นตัวเลขสำคัญจาก `summary` โดยระบุชัดว่าเป็นค่าตัวอย่างจากคู่มือ |
| **#hf-154 Animated Bar Chart** | แสดงสัดส่วนการใช้งานแยกตามช่องทาง (`web: 30` vs `line: 12` ตามตัวอย่างคู่มือ) | b6, b7 | ช่วยให้เห็นประโยชน์ของฟิลด์ `channels` ใน `/analytics/agents/{id}` |
| **#hf-113 Code Highlight Sweep** | ไฮไลต์ฟิลด์ `user_id`, `"rating": 1`, และ query `?from=2026-08-01&to=2026-08-18` | b4, b5, b6 | ชี้จุดสำคัญใน JSON request/response ให้อ่านง่ายบนมือถือ |
| **#hf-072 Marker Highlight** | เน้นข้อควรระวังเรื่อง `rating` รับเฉพาะ `1 / -1` และเงื่อนไขของ `user_id` | b4, b5, b8 | ป้องกันความเข้าใจผิดเรื่องสเกลคะแนนและการนับจำนวนผู้ใช้ |

## 3. สิ่งที่ต้องทดสอบใน Sample (W5)

* **ความชัดเจนของตัวเลขและป้าย `"ตัวเลขตัวอย่างจำลอง"` บน Count-Up Stat Card (`b6`)**: ตรวจสอบว่าไม่มีการเข้าใจผิดว่าเป็นผลวัดจริงจากระบบ production
* **การเปลี่ยนฉากจากหน้าแชท `APP-CHAT-FEEDBACK` ไปสู่ `APP-ANALYTICS-DASHBOARD` (`b5 → b6`)**: ทดสอบให้เห็นความเชื่อมโยงว่าคะแนน `rating: 1` ที่กดในแชท กลายเป็น `feedback_positive: 18` ในหน้า Dashboard
