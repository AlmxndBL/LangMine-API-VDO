# EP06 — บทร่างภาษาพูด 9 Beats (Knowledge & Datasets API)

ผู้ชม: Developer และผู้ดูแลระบบที่ต้องการอัปเดตคลังความรู้ให้ AI อัตโนมัติและทดสอบการค้นคืน  
โครงสร้าง: 9 Beats (`b1–b9`) ตามแนวทาง EP04 v3 (เตรียม → เชื่อม 3 ครั้ง → ใช้ผล + ผู้สนับสนุน)  
ภาษา: ไทย โทนสนทนา กระชับ แยกบทพูด (`say`) ซับไตเติล (`cap`) และข้อความเน้นบนจอชัดเจน

---

## 1. บทเต็มและจุดแบ่งจังหวะ (Full Script & Beats)

| Beat | บทบรรยายภาษาพูด (`say`) | ข้อความเน้นบนจอ (แยกจากซับ) |
|---|---|---|
| **b1** | เวลาที่ร้านมีโปรโมชันใหม่ หรือเปลี่ยนข้อมูลสินค้า ถ้าต้องคอยเข้าเว็บไปอัปโหลดไฟล์ใหม่ทุกครั้งคงไม่ทันการ จะดีกว่าไหมถ้าระบบหลังบ้านส่งไฟล์เข้าคลังความรู้ของ AI ได้อัตโนมัติ แถมเช็กได้ด้วยว่า AI ค้นเจอข้อมูลถูกจุดไหม ถ้าอยากทำแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ | อัปเดตความรู้ AI อัตโนมัติด้วย API |
| **b2** | ภาพรวมของฟีเจอร์นี้มีสามส่วน คือ ระบบหลังบ้านของคุณ คลังความรู้ของ LangMind และตัว Agent ทุกครั้งที่มีข้อมูลใหม่ ระบบหลังบ้านจะเรียก LangMind สามขั้นตอน คือ อัปโหลดเอกสารและรอจัดทำดัชนี ผูกคลังความรู้เข้ากับ Agent และทดสอบค้นคืนข้อมูล | อัปโหลดเอกสาร → ผูก Agent → ทดสอบค้นคืน |
| **b3** | เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือ Agent ใน LangMind ที่ผู้ดูแลระบบตั้งค่า RAG ไว้เรียบร้อย เพราะถ้ายังไม่ตั้งค่า ตอนเรียกใช้งานจะได้รหัสห้าศูนย์สาม อย่างที่สองคือ API Key ที่มีสิทธิ์สามตัว ได้แก่ knowledge write, knowledge read และ agents write อย่างที่สามคือระบบหลังบ้านของแอป สำหรับเก็บ Key และส่งไฟล์แทนหน้าเว็บ | สิ่งที่ต้องเตรียม:<br>1. Agent + ตั้งค่า RAG (`503` ถ้ายังไม่ตั้ง)<br>2. สิทธิ์ `knowledge:write`, `knowledge:read`, `agents:write`<br>3. ระบบหลังบ้านเก็บ Key |
| **b4** | มาดูการเชื่อมครั้งที่หนึ่ง การอัปโหลดเอกสารและเช็กสถานะ เริ่มจากสร้าง Dataset ด้วย POST datasets แล้วส่งไฟล์ เช่น โปรโมชันเดือนนี้ดอทพีดีเอฟ เข้าที่ documents upload ระบบจะตอบกลับรหัสสองศูนย์สอง และสถานะเป็น pending เพราะการจัดทำดัชนีทำงานอยู่เบื้องหลัง ให้เราเช็กสถานะที่ GET documents ตามด้วย ID จนเปลี่ยนจาก pending เป็น processing และเป็น indexed จึงจะพร้อมใช้งานครับ | ครั้งที่ 1: อัปโหลด & รอ `indexed`<br>`POST /api/datasets/{id}/documents/upload` → `202`<br>`pending → processing → indexed` |
| **b5** | ครั้งที่สอง การผูกคลังความรู้เข้ากับ Agent เมื่อเอกสารพร้อมแล้ว ให้ส่งคำขอ PUT ไปที่ agents ตามด้วย ID และ datasets พร้อมระบุ dataset ID และค่าน้ำหนัก weight เพื่อบอกให้ Agent ใช้คลังข้อมูลชุดนี้เวลาตอบคำถาม | ครั้งที่ 2: ผูกคลังเข้ากับ Agent<br>`PUT /api/agents/{id}/datasets` · สิทธิ์ `agents:write` |
| **b6** | ครั้งที่สาม การทดสอบค้นคืนโดยไม่เรียก LLM เราสามารถเช็กได้ทันทีว่า AI ค้นเจอเนื้อหาส่วนไหน ด้วยการส่ง POST ไปที่ retrieval test พร้อมระบุ agent ID และคำค้น เช่น โปรโมชันอเมริกาโน่ ระบบจะคืน segments หรือข้อความที่ค้นเจอ ชื่อไฟล์เอกสาร และค่าความคล้าย score กลับมา โดยไม่ต้องเสียโควตาเรียกโมเดลภาษาเลยครับ | ครั้งที่ 3: ทดสอบค้นคืน (ไม่เรียก LLM)<br>`POST /api/retrieval/test` · สิทธิ์ `knowledge:read`<br>คืน `segments`, `document_name`, `score` |
| **b7** | ผลที่ได้เอาไปต่อยอดได้ครบวงจร ทั้งใช้เช็กคุณภาพเอกสารก่อนเปิดให้ลูกค้าถามจริง หรือเลือกส่งข้อมูลได้หลายแบบ ทั้งอัปโหลดหลายไฟล์พร้อมกันผ่าน upload batch ขนาดรวมไม่เกินห้าสิบเมกะไบต์ ดึงจากลิงก์เว็บ ส่งข้อความตรง หรือสั่ง crawl ไล่เก็บทั้งเว็บไซต์ และข้อควรจำคือ ค่า score ที่ได้ เป็นค่าความคล้ายในการค้นคืน ไม่ใช่เปอร์เซ็นต์ความถูกต้องของคำตอบครับ | ต่อยอดได้หลายรูปแบบ:<br>• `upload-batch` (≤ 50 MB) · `/url` · `/text` · `/crawl`<br>• `score` = ค่าความคล้าย (ไม่ใช่ % ความถูกต้อง) |
| **b8** | สรุปครับ เตรียม Agent ที่ตั้งค่า RAG แล้ว พร้อม API Key สามสิทธิ์ และระบบหลังบ้าน เชื่อมสามขั้นตอน คือ อัปโหลดเอกสารรอจนเป็น indexed ผูกคลังเข้ากับ Agent และทดสอบค้นคืนด้วย retrieval test เพียงเท่านี้ AI ของคุณก็มีข้อมูลใหม่อัปเดตพร้อมใช้งานตลอดเวลาแล้วครับ | สรุป: เตรียม → เชื่อม 3 ขั้น → ใช้ผลอัปเดตคลังความรู้อัตโนมัติ |
| **b9** | คลิปนี้สนับสนุนโดย LangMind เริ่มสร้าง Agent และคลังความรู้ของคุณได้ที่ LangMind ดอท อิน ดอท ทีเอช | สนับสนุนโดย LangMind · `langmind.in.th` |

## 2. ข้อมูลตัวอย่างสำหรับหน้าจอและโค้ด (`illustrative`)

* **ระบบสมมติ**: "Cafe Backoffice — จัดการคลังความรู้ร้านกาแฟ"
* **ไฟล์ตัวอย่างที่อัปโหลด**: `โปรโมชันเดือนนี้.pdf` (ขนาดจำลอง `204,800 bytes`)
* **คำค้นที่ใช้ทดสอบ (`query`)**: `"โปรโมชันอเมริกาโน่"`
* **ผลลัพธ์ `segments` จำลอง**:
  * `document_name`: `"โปรโมชันเดือนนี้.pdf"`
  * `content`: `"อเมริกาโน่เย็น ซื้อ 2 แก้ว ลดทันที 20 บาท ตลอดเดือนนี้"`
  * `score`: `0.84` (ระบุชัดว่าเป็นค่าจำลองตามรูปแบบ contract และไม่ใช่เปอร์เซ็นต์ความถูกต้อง)
* *หมายเหตุ*: ข้อมูลทั้งหมดเป็นตัวอย่างจำลองเพื่ออธิบายการไหลของข้อมูล ไม่ใช่ผลเรียก live API จริง
