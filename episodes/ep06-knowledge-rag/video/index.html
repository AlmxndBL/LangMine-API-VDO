3ใช้ผลต่อยอดการใช้งานคลังความรู้

เช็กคุณภาพเอกสารก่อนเปิดจริงยิง retrieval/test ตรวจว่า AI ดึงถูกท่อนไหม โดยไม่ต้องเปลืองโทเค็น
นำเข้าได้หลายรูปแบบupload-batch รวมไม่เกิน 50 MB · ดึงจาก /url · /text · /crawl
เข้าใจค่า Score ให้ถูกต้องscore = ค่าความคล้ายในการค้นคืน ไม่ใช่เปอร์เซ็นต์ความถูกต้องของคำตอบ
ข้อควรจำ:
คลังข้อมูลขนาดใหญ่ควรแบ่งเป็นหมวดหมู่
และกำหนดค่าน้ำหนัก weight ให้เหมาะกับ Agent

สรุปเตรียม → เชื่อม 3 ขั้น → ใช้ผล

ถ้าต้องคอยเข้าเว็บอัปโหลดใหม่ทุกครั้งคงไม่ทันการ
จะดีกว่าไหม ถ้าระบบหลังบ้านส่งไฟล์
เข้าคลังความรู้ AI อัตโนมัติ และเช็กการค้นเจอได้
ถ้าอยากทำแบบนี้ ต้องเตรียมอะไร

ภาพรวมมี 3 ส่วน: ระบบหลังบ้านของคุณ
คลังความรู้ของ LangMind และตัว Agent
ทุกครั้งที่มีข้อมูลใหม่ ระบบหลังบ้านจะเรียก
LangMind ทั้งหมด 3 ขั้นตอน
1 อัปโหลดเอกสาร → 2 ผูก Agent
→ 3 ทดสอบค้นคืนข้อมูล
สิ่งที่ต้องเตรียม อย่างแรกคือ Agent
ที่ตั้งค่า RAG ไว้เรียบร้อย
ถ้ายังไม่ตั้งค่า RAG
ตอนเรียกใช้งานจะได้รหัส 503
อย่างที่สอง API Key ที่มีสิทธิ์
knowledge:write, read และ agents:write
อย่างที่สาม ระบบหลังบ้านของแอป
สำหรับเก็บ Key และส่งไฟล์แทนหน้าเว็บ
ครั้งที่ 1: อัปโหลดเอกสาร
POST /api/datasets/{id}/documents/upload
ระบบตอบกลับรหัส 202 สถานะ pending
การจัดทำดัชนีทำงานเบื้องหลัง
เช็กสถานะที่ GET /api/documents/{id}
รอ pending → processing → indexed
ครั้งที่ 2: ผูกคลังความรู้เข้ากับ Agent
PUT /api/agents/{id}/datasets
ระบุ dataset_id และ weight: 1.0
เพื่อให้ Agent ใช้ข้อมูลชุดนี้เวลาตอบคำถาม
ครั้งที่ 3: ทดสอบค้นคืน (ไม่เรียก LLM)
เช็กได้ทันทีว่า AI ค้นเจอเนื้อหาส่วนไหน
ส่ง POST /api/retrieval/test
ระบุ agent_id และคำค้น query
คืน segments ข้อความที่ค้นเจอ ชื่อไฟล์
และ score โดยไม่เสียโควตาโมเดลภาษา
ผลที่ได้ เอาไปเช็กคุณภาพเอกสาร
ก่อนเปิดให้ลูกค้าถามจริง
ส่งข้อมูลได้หลายแบบ: upload-batch
ขนาดรวมไม่เกิน 50 MB
ดึงจากลิงก์ /url ส่งข้อความ /text
หรือสั่ง /crawl ไล่เก็บทั้งเว็บไซต์
ข้อควรจำ: ค่า score คือค่าความคล้าย
ไม่ใช่เปอร์เซ็นต์ความถูกต้องของคำตอบ
สรุป: เตรียม Agent (ตั้งค่า RAG)
API Key (3 สิทธิ์) และระบบหลังบ้าน
เชื่อม 3 ขั้นตอน: อัปโหลด → ผูก Agent
→ ทดสอบค้นคืน (retrieval/test)
เพียงเท่านี้ AI ของคุณก็มีข้อมูลใหม่
อัปเดตพร้อมใช้งานตลอดเวลาแล้วครับ
คลิปนี้สนับสนุนโดย LangMind
เริ่มสร้าง Agent และคลังความรู้ของคุณได้
