# EP06 — บทสำหรับสร้างเสียง

รัน `python make-voice-samples.py` แล้ว `node build.mjs`

## b1 → assets/voice/b1.wav
เวลาที่ร้านมีโปรโมชันใหม่ หรือเปลี่ยนข้อมูลสินค้า ถ้าต้องคอยเข้าเว็บไปอัปโหลดไฟล์ใหม่ทุกครั้งคงไม่ทันการ จะดีกว่าไหมถ้าระบบหลังบ้านส่งไฟล์เข้าคลังความรู้ของ AI ได้อัตโนมัติ แถมเช็กได้ด้วยว่า AI ค้นเจอข้อมูลถูกจุดไหม ถ้าอยากทำแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ

## b2 → assets/voice/b2.wav
ภาพรวมของฟีเจอร์นี้มีสามส่วน คือ ระบบหลังบ้านของคุณ คลังความรู้ของ LangMind และตัว Agent ทุกครั้งที่มีข้อมูลใหม่ ระบบหลังบ้านจะเรียก LangMind สามขั้นตอน คือ อัปโหลดเอกสารและรอจัดทำดัชนี ผูกคลังความรู้เข้ากับ Agent และทดสอบค้นคืนข้อมูล

## b3 → assets/voice/b3.wav
เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือ Agent ใน LangMind ที่ผู้ดูแลระบบตั้งค่า RAG ไว้เรียบร้อย เพราะถ้ายังไม่ตั้งค่า ตอนเรียกใช้งานจะได้รหัสห้าศูนย์สาม อย่างที่สองคือ API Key ที่มีสิทธิ์สามตัว ได้แก่ knowledge write, knowledge read และ agents write อย่างที่สามคือระบบหลังบ้านของแอป สำหรับเก็บ Key และส่งไฟล์แทนหน้าเว็บ

## b4 → assets/voice/b4.wav
มาดูการเชื่อมครั้งที่หนึ่ง การอัปโหลดเอกสาร เริ่มจากสร้าง Dataset แล้วส่งไฟล์เข้าที่ documents upload ระบบจะตอบกลับรหัสสองศูนย์สอง และสถานะเป็น pending เพราะการจัดทำดัชนีทำงานอยู่เบื้องหลัง ให้เราเช็กสถานะที่ GET documents ตามด้วย ID จนเปลี่ยนจาก pending เป็น processing และเป็น indexed จึงจะพร้อมใช้งานครับ

## b5 → assets/voice/b5.wav
ครั้งที่สอง การผูกคลังความรู้เข้ากับ Agent เมื่อเอกสารพร้อมแล้ว ให้ส่งคำขอ PUT ไปที่ agents ตามด้วย ID และ datasets พร้อมระบุ dataset ID และค่าน้ำหนัก weight เพื่อบอกให้ Agent ใช้คลังข้อมูลชุดนี้เวลาตอบคำถาม

## b6 → assets/voice/b6.wav
ครั้งที่สาม การทดสอบค้นคืนโดยไม่เรียก LLM เราสามารถเช็กได้ทันทีว่า AI ค้นเจอเนื้อหาส่วนไหน ด้วยการส่ง POST ไปที่ retrieval test พร้อมระบุ agent ID และคำค้น เช่น โปรโมชันอเมริกาโน่ ระบบจะคืน segments ข้อความที่ค้นเจอ ชื่อไฟล์เอกสาร และค่าความคล้าย score กลับมา โดยไม่ต้องเสียโควตาเรียกโมเดลภาษาเลยครับ

## b7 → assets/voice/b7.wav
ผลที่ได้เอาไปต่อยอดได้ครบวงจร ทั้งใช้เช็กคุณภาพเอกสารก่อนเปิดให้ลูกค้าถามจริง หรือเลือกส่งข้อมูลได้หลายแบบ ทั้งอัปโหลดหลายไฟล์พร้อมกันผ่าน upload batch ขนาดรวมไม่เกินห้าสิบเมกะไบต์ ดึงจากลิงก์เว็บ ส่งข้อความตรง หรือสั่ง crawl ไล่เก็บทั้งเว็บไซต์ และข้อควรจำคือ ค่า score ที่ได้ เป็นค่าความคล้ายในการค้นคืน ไม่ใช่เปอร์เซ็นต์ความถูกต้องของคำตอบครับ

## b8 → assets/voice/b8.wav
สรุปครับ เตรียม Agent ที่ตั้งค่า RAG แล้ว พร้อม API Key สามสิทธิ์ และระบบหลังบ้าน เชื่อมสามขั้นตอน คือ อัปโหลดเอกสารรอจนเป็น indexed ผูกคลังเข้ากับ Agent และทดสอบค้นคืนด้วย retrieval test เพียงเท่านี้ AI ของคุณก็มีข้อมูลใหม่อัปเดตพร้อมใช้งานตลอดเวลาแล้วครับ

## b9 → assets/voice/b9.wav
คลิปนี้สนับสนุนโดย LangMind เริ่มสร้าง Agent และคลังความรู้ของคุณได้ที่ LangMind ดอท อิน ดอท ทีเอช
