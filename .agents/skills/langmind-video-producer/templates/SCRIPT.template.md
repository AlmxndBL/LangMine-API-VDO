# EPXX — Spoken Script & Caption Breakdown

Episode ID: `epXX-<slug>`  
หลักการ: ภาษาพูดธรรมชาติ อธิบายกระชับ ซับไตเติลตัดคำตามจังหวะอ่าน ไม่เกิน 2 บรรทัดต่อช่วง

---

## ตารางบทพากย์และซับไตเติล (9 Beats)

### Beat 1: ปัญหา & ตั้งคำถาม (b1)
* **problem**:
  * *เสียงพากย์ (say)*: "เวลาที่... ถ้าต้องทำด้วยมือคงไม่ทันการ"
  * *ซับไตเติล (cap)*: "เวลาที่... \nถ้าต้องทำด้วยมือคงไม่ทันการ"
* **solution**:
  * *เสียงพากย์ (say)*: "จะดีกว่าไหม ถ้าระบบหลังบ้านเชื่อมต่อกับ LangMind จัดการได้อัตโนมัติ"
  * *ซับไตเติล (cap)*: "จะดีกว่าไหม ถ้าระบบเชื่อม LangMind\nจัดการได้อัตโนมัติ"
* **questions**:
  * *เสียงพากย์ (say)*: "ถ้าอยากทำแบบนี้ ต้องเตรียมอะไร เชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ"
  * *ซับไตเติล (cap)*: "ถ้าอยากทำแบบนี้ ต้องเตรียมอะไร\nเชื่อมตรงไหน และเอาผลไปใช้ยังไง มาดูกันครับ"

### Beat 2: ภาพรวมระบบ (b2)
* **map**:
  * *เสียงพากย์ (say)*: "ภาพรวมของฟีเจอร์นี้มีสามส่วน คือ ระบบของคุณ แพลตฟอร์ม LangMind และตัว Agent"
  * *ซับไตเติล (cap)*: "ภาพรวมมี 3 ส่วน: ระบบของคุณ\nแพลตฟอร์ม LangMind และตัว Agent"
* **steps-intro**:
  * *เสียงพากย์ (say)*: "ทุกครั้งที่มีข้อมูลใหม่ ระบบจะเรียก LangMind สามขั้นตอน"
  * *ซับไตเติล (cap)*: "ทุกครั้งที่มีข้อมูลใหม่ ระบบจะเรียก\nLangMind ทั้งหมด 3 ขั้นตอน"
* **steps**:
  * *เสียงพากย์ (say)*: "คือ หนึ่งเตรียมข้อมูล สองผูกระบบ และสามทดสอบดึงผลลัพธ์"
  * *ซับไตเติล (cap)*: "1 เตรียมข้อมูล → 2 ผูกระบบ\n→ 3 ทดสอบดึงผลลัพธ์"

### Beat 3: สิ่งที่ต้องเตรียม (b3)
* **agent**:
  * *เสียงพากย์ (say)*: "เริ่มจากสิ่งที่ต้องเตรียม อย่างแรกคือ Agent ในระบบ LangMind ที่ตั้งค่าไว้เรียบร้อย"
  * *ซับไตเติล (cap)*: "สิ่งที่ต้องเตรียม อย่างแรกคือ Agent\nที่ตั้งค่าไว้เรียบร้อย"
* **warn**:
  * *เสียงพากย์ (say)*: "เพราะถ้ายังไม่ได้เปิดใช้งาน ตอนเรียกใช้จะได้รหัสข้อผิดพลาดกลับมา"
  * *ซับไตเติล (cap)*: "ถ้ายังไม่ได้เปิดใช้งาน\nตอนเรียกใช้จะได้รหัส Error กลับมา"
* **key**:
  * *เสียงพากย์ (say)*: "อย่างที่สองคือ API Key ที่มีสิทธิ์ตามที่ต้องการ"
  * *ซับไตเติล (cap)*: "อย่างที่สอง API Key ที่มีสิทธิ์ครบถ้วน"
* **server**:
  * *เสียงพากย์ (say)*: "อย่างที่สามคือระบบหลังบ้านของแอป สำหรับเก็บ Key ให้ปลอดภัย"
  * *ซับไตเติล (cap)*: "อย่างที่สาม ระบบหลังบ้านของแอป\nสำหรับเก็บ Key ให้ปลอดภัย"

### Beat 4: เชื่อมครั้งที่ 1 (b4)
* **step1-intro**:
  * *เสียงพากย์ (say)*: "การเชื่อมครั้งที่หนึ่ง เริ่มต้นส่งข้อมูลเข้าสู่ระบบ"
  * *ซับไตเติล (cap)*: "ครั้งที่ 1: ส่งข้อมูลเข้าสู่ระบบ\nPOST /api/..."
* **step1-request**:
  * *เสียงพากย์ (say)*: "ส่งคำขอพร้อม Bearer Token และพารามิเตอร์ที่จำเป็น"
  * *ซับไตเติล (cap)*: "ส่งคำขอพร้อม Bearer Token\nและพารามิเตอร์ที่จำเป็น"
* **step1-response**:
  * *เสียงพากย์ (say)*: "ระบบจะตอบกลับรหัสสถานะและ ID อ้างอิง เพื่อนำไปใช้ต่อ"
  * *ซับไตเติล (cap)*: "ระบบตอบกลับสถานะและ ID อ้างอิง\nเพื่อนำไปใช้ต่อ"

### Beat 5: เชื่อมครั้งที่ 2 (b5)
* **step2-intro**:
  * *เสียงพากย์ (say)*: "ครั้งที่สอง การผูกระบบเข้ากับ Agent"
  * *ซับไตเติล (cap)*: "ครั้งที่ 2: ผูกระบบเข้ากับ Agent\nPUT /api/..."
* **step2-action**:
  * *เสียงพากย์ (say)*: "ระบุ ID และค่าน้ำหนักเพื่อบอกให้ Agent ทราบ"
  * *ซับไตเติล (cap)*: "ระบุ ID และค่าน้ำหนัก\nเพื่อบอกให้ Agent ทราบ"

### Beat 6: เชื่อมครั้งที่ 3 (b6)
* **step3-intro**:
  * *เสียงพากย์ (say)*: "ครั้งที่สาม การทดสอบเรียกใช้งานจริง"
  * *ซับไตเติล (cap)*: "ครั้งที่ 3: ทดสอบเรียกใช้งานจริง\nPOST /api/..."
* **step3-request**:
  * *เสียงพากย์ (say)*: "ส่งคำขอทดสอบพร้อมคำค้นหาหรือข้อความตัวอย่าง"
  * *ซับไตเติล (cap)*: "ส่งคำขอทดสอบพร้อมข้อความตัวอย่าง"
* **step3-response**:
  * *เสียงพากย์ (say)*: "ระบบจะคืนผลลัพธ์กลับมาอย่างรวดเร็ว พร้อมแสดงผลบนหน้าจอทันที"
  * *ซับไตเติล (cap)*: "ระบบคืนผลลัพธ์กลับมาทันที\nพร้อมแสดงผลบนหน้าจอแอป"

### Beat 7: นำผลไปใช้ & ข้อควรระวัง (b7)
* **use-cases**:
  * *เสียงพากย์ (say)*: "ผลที่ได้สามารถนำไปแสดงในแอปหรือประมวลผลต่อได้ทันที"
  * *ซับไตเติล (cap)*: "ผลที่ได้นำไปแสดงในแอป\nหรือประมวลผลต่อได้ทันที"
* **alternatives**:
  * *เสียงพากย์ (say)*: "นอกจากนี้ยังรองรับการทำงานแบบชุด หรือการเชื่อมต่อช่องทางอื่น ๆ"
  * *ซับไตเติล (cap)*: "รองรับการทำงานแบบชุด\nหรือเชื่อมต่อช่องทางอื่น ๆ"
* **gotchas**:
  * *เสียงพากย์ (say)*: "และอย่าลืมตรวจสอบขนาดไฟล์และข้อจำกัดก่อนส่งคำขอครับ"
  * *ซับไตเติล (cap)*: "ข้อควรจำ: ตรวจสอบข้อจำกัด\nและขนาดข้อมูลก่อนส่งคำขอ"

### Beat 8: สรุป (b8)
* **summary-prep**:
  * *เสียงพากย์ (say)*: "สรุปครับ เตรียม Agent, API Key และเซิร์ฟเวอร์หลังบ้าน"
  * *ซับไตเติล (cap)*: "สรุป: เตรียม Agent, API Key\nและเซิร์ฟเวอร์หลังบ้าน"
* **summary-connect**:
  * *เสียงพากย์ (say)*: "เชื่อมสามขั้นตอน ส่งข้อมูล ผูกระบบ และทดสอบดึงผลลัพธ์"
  * *ซับไตเติล (cap)*: "เชื่อม 3 ขั้นตอน: ส่งข้อมูล → ผูกระบบ\n→ ทดสอบดึงผลลัพธ์"
* **summary-done**:
  * *เสียงพากย์ (say)*: "เพียงเท่านี้ระบบของคุณก็พร้อมทำงานร่วมกับ AI ได้อย่างสมบูรณ์แล้วครับ"
  * *ซับไตเติล (cap)*: "เพียงเท่านี้ ระบบของคุณก็พร้อมทำงาน\nร่วมกับ AI ได้อย่างสมบูรณ์แล้วครับ"

### Beat 9: ผู้สนับสนุน & CTA (b9)
* **sponsor**:
  * *เสียงพากย์ (say)*: "คลิปนี้สนับสนุนโดย LangMind"
  * *ซับไตเติล (cap)*: "คลิปนี้สนับสนุนโดย LangMind"
* **cta**:
  * *เสียงพากย์ (say)*: "เริ่มต้นสร้าง Agent และเชื่อมต่อ API ได้ที่ LangMind ดอท อิน ดอท ทีเอช"
  * *ซับไตเติล (cap)*: "เริ่มต้นสร้าง Agent และเชื่อมต่อ API\nได้ที่ langmind.in.th"
