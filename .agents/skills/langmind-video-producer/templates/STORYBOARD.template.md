## 2. Storyboard ราย Beat (b1 – b9)

### Beat 1: Hook & ปัญหา (b1)
* **ภาพ**: กรอบมือถือตรงกลางแสดง `app-feature-1.jpg` ด้านล่างซ้ายมี Robot ท่าทางสงสัย (`01-question.png`) พร้อมกล่อง Tip สีขาวขอบเขียว
* **Motion**: มือถือเลื่อนขึ้น Robot ปรากฏตัวพร้อม Tip box จากนั้นชิปคำถาม 3 ใบ (`เตรียมอะไร?`, `เชื่อมตรงไหน?`, `ใช้ผลยังไง?`) เด้งขึ้นมาทีละใบ
* **Caption**: สรุปปัญหาและชวนหาคำตอบ

### Beat 2: ภาพรวมระบบ 3 ส่วน (b2)
* **ภาพ**: แผนผังแนวตั้ง 3 โหนด: [ระบบหลังบ้านของคุณ] ⇄ [LangMind Platform] ⇄ [LangMind Agent]
* **Motion**: โหนดปรากฏขึ้นพร้อมลูกศรชี้ขึ้นลง Dot สีเขียววิ่งจำลองข้อมูล จากนั้นป้าย 3 ขั้นตอน (`1 อัปโหลด`, `2 ผูกระบบ`, `3 ทดสอบ`) เด้งขึ้นมาตรงกลาง
* **Caption**: สรุปภาพรวมและจำนวนการเชื่อมต่อ

### Beat 3: สิ่งที่ต้องเตรียม (b3)
* **ภาพ**: การ์ด 3 ใบซ้อนกันในแนวตั้ง: 1. Agent ในระบบ, 2. API Key พร้อม Scopes, 3. เซิร์ฟเวอร์หลังบ้าน
* **Motion**: การ์ดแต่ละใบเลื่อนเข้ามาพร้อมกับไอคอน ชิประบุสิทธิ์ Scopes เด้งทีละอัน กล่องคำเตือนสีส้มแดงเตือนกรณี Error
* **Caption**: ระบุสิ่งที่ต้องมี 3 อย่างให้ครบ

### Beat 4: เชื่อมครั้งที่ 1 (b4)
* **ภาพ**: แถบ Minimap สีเขียวด้านบน กล่อง Input Data ด้านบน ลูกศรชี้ลง กล่องโค้ด HTTP Request ตรงกลาง และกล่อง Response ด้านล่าง
* **Motion**: ข้อมูล Input วิ่งลงเข้าสู่กล่องโค้ด บรรทัดสำคัญไฮไลต์ กล่องผลลัพธ์ Response เด้งแสดงสถานะ
* **Caption**: Endpoint, Method และสถานะตอบกลับ

### Beat 5: เชื่อมครั้งที่ 2 (b5)
* **ภาพ**: แถบ Minimap สีทองด้านบน กล่องโค้ดผูกระบบหรือประมวลผล ไฮไลต์พารามิเตอร์สำคัญ
* **Motion**: กล่องโค้ดเลื่อนเข้าพร้อมไฮไลต์บรรทัดพารามิเตอร์หลัก
* **Caption**: Endpoint, Method และพารามิเตอร์

### Beat 6: เชื่อมครั้งที่ 3 (b6)
* **ภาพ**: แถบ Minimap สีเขียวน้ำทะเลด้านบน กล่องโค้ดยิงทดสอบ และจอมือถือด้านล่างแสดง `app-feature-2.jpg`
* **Motion**: กล่องโค้ดส่งคำขอ กล่อง Response คืนผลลัพธ์ จอมือถือเฟดแสดงผลสำเร็จ
* **Caption**: Endpoint ผลลัพธ์ และการแสดงผลจริง

### Beat 7: นำผลไปใช้ & ข้อควรระวัง (b7)
* **ภาพ**: การ์ด 3 ใบ: 1. การนำข้อมูลไปต่อในแอป, 2. ทางเลือกการส่งข้อมูล, 3. การ์ดข้อควรระวัง
* **Motion**: การ์ดเลื่อนเข้ามาตามจังหวะเสียง ไอคอนขยับเบา ๆ
* **Caption**: คำแนะนำการใช้งานจริงและข้อจำกัด

### Beat 8: สรุป (b8)
* **ภาพ**: การ์ดสรุป 3 เสาหลัก: เลข 1 เตรียม → เลข 2 เชื่อม → เลข 3 ใช้ผล
* **Motion**: ตัวเลขกลมสีเขียวเด้งขึ้นมาทีละขั้นพร้อมข้อความสรุป
* **Caption**: สรุปหัวใจสำคัญของทั้งตอน

### Beat 9: ผู้สนับสนุน & CTA (b9)
* **ภาพ**: โลโก้ LangMind ขนาดใหญ่ตรงกลาง ข้อความสนับสนุน และปุ่ม URL `langmind.in.th`
* **Motion**: โลโก้ขยายเข้า ชิป URL เรืองแสงเบา ๆ
* **Caption**: คลิปนี้สนับสนุนโดย LangMind
